## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- VM1 – Virtual machine
- storage1 – Storage account
- Workspace1 – Log Analytics workspace
- DB1 – Azure SQL database
You plan to create a data collection rule named DCR1 in Azure Monitor.
Which of the listed resources can you configure as data sources in DCR1?
Réponses:
**☑** VM1 only
☐ VM1 and storage1 only
☐ VM1, storage1, and DB1 only
☐ VM1, storage1, Workspace1, and DB1
Explication
`VM1 only` is the correct answer because Azure Monitor data collection rules (DCRs) can only collect data from specific resources, primarily virtual machines, as data sources. In this case, VM1 is a virtual machine and is eligible to be set as a data source in DCR1.
`VM1 and storage1 only` is incorrect because storage accounts, like storage1, cannot be used directly as data sources for data collection rules in Azure Monitor.
`VM1, storage1, and DB1 only` is incorrect because DB1 (an Azure SQL database) and storage1 are not supported as data sources for data collection rules in Azure Monitor.
`VM1, storage1, Workspace1, and DB1` is incorrect because Workspace1 (a Log Analytics workspace), storage1, and DB1 cannot be used as data sources in a data collection rule. Only VM1 is valid.

- https://learn.microsoft.com/en-us/azure/azure-monitor/agents/data-sources-windows-events
