## Énoncé et corrigé fourni


A Microsoft Entra tenant contains the following users:
- User1
- Member of: Group1
- Assigned license: Microsoft Entra ID P2
- User2
- Member of: Group2
- Assigned license: None
- User3
- Member of: No groups
- Assigned license: Microsoft Entra ID P2
- User4
- Member of: No groups
- Assigned license: None
The tenant also contains the following groups and group relationships:
- Group1
- Member of: No groups
- Assigned license: None
- Group2
- Member of: Group3
- Assigned license: Microsoft Entra ID P2
- Group3
- Member of: Group4
- Assigned license: None
- Group4
- Member of: No groups
- Assigned license: Microsoft Entra ID P2
Based on the tenant configuration shown above, which `users` are eligible to be deleted from Microsoft Entra ID?
Réponses:
☐ User4 only
☐ User3 and User4 only
☐ User2 and User4 only
**☑** User1, User2, User3, and User4
Explication
`User1, User2, User3, and User4` can all be deleted. In Microsoft Entra ID, users can be deleted regardless of whether they have licenses assigned directly or through group membership. When a user is deleted, any licenses assigned to them will be freed for reassignment.
Reference(s):
- https://learn.microsoft.com/en-us/entra/fundamentals/how-to-create-delete-users
