## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1.
You want to restrict access to storage1 so that it is reachable only from specific networks and from your home office. The approach must require the least amount of ongoing administrative effort.
What is the first configuration change you should make for storage1?
Réponses:
☐ Create a private endpoint for the storage account.
**☑** Update the public network access configuration for the storage account.
☐ Configure the storage account to use internet-based routing.
☐ Change the role-based access control (IAM) settings.
Explication
`Update the public network access configuration for the storage account` is the correct answer here. To allow access to storage1 from selected networks and your home office while minimizing administrative effort, you should first modify the Public network access settings. By selecting the option to allow access only from selected virtual networks and IP addresses, you can define specific networks and IP addresses, such as your home office's public IP address, without needing to configure more complex solutions like private endpoints.
`Create a private endpoint for the storage account` is incorrect because private endpoints require additional setup and would only allow access through a private network, not minimizing administrative effort.
`Configure the storage account to use internet-based routing` is incorrect because this would open the storage account to access from the internet, which doesn't fulfill the requirement of limiting access to selected networks and your home office.
`Change the role-based access control (IAM) settings` is incorrect because IAM controls user and group permissions for accessing resources but does not control network access.
