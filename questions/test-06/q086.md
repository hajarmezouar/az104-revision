## Énoncé et corrigé fourni


A Microsoft Entra hybrid environment contains the following user accounts:
- User1
- User type: Member
- On-premises synchronization enabled: No
- User2
- User type: Member
- On-premises synchronization enabled: Yes
- User3
- User type: Guest
- On-premises synchronization enabled: No
You need to modify the `UsageLocation` attribute for these users.
For which users can the attribute be updated directly within Microsoft Entra ID?
Réponses:
☐ User1 only
☐ User1 and User2 only
☐ User1 and User3 only
**☑** User1, User2, and User3
Explication
User1, User2, and User3 is the correct answer because the UsageLocation attribute is always stored and managed in Microsoft Entra ID, regardless of whether the user is cloud-only (User1 and User3) or synced from on-premises Active Directory (User2). This attribute is required for assigning Microsoft 365 licenses and can be directly edited from the Microsoft Entra portal or using PowerShell for all types of users.
Reference(s):
- https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-user-profile-info
