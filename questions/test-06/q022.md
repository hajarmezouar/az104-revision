## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1 which contains a blob used to store images.
Access to storage1 is provided to clients by using a shared access signature (SAS).
You want users to see a warning whenever they create a SAS with an expiration period longer than seven days.
What configuration should you apply to the storage account?
Réponses:
☐ Enable a read-only resource lock on the storage account.
☐ Create and configure an alert rule.
☐ Add a lifecycle management policy.
**☑** Set Allow recommended upper limit for shared access signature (SAS) expiry interval to Enabled.
Explication
`Set Allow recommended upper limit for shared access signature (SAS) expiry interval to Enabled` is the correct answer. By enabling this setting, Azure will enforce a recommended upper limit for SAS token expiry (in this case, seven days). Users will receive a warning if they try to create a SAS token that exceeds the defined limit, helping to maintain secure access practices.
`Enable a read-only resource lock on the storage account` is incorrect because locks are used to prevent modification or deletion of resources, not for configuring SAS expiry limits.
`Create and configure an alert rule` is incorrect because alert rules are used for monitoring and alerting on events, but do not directly enforce or warn about SAS expiry time.
`Add a lifecycle management policy` is incorrect because lifecycle management is used to manage blob storage tiers and deletion policies, not SAS expiry intervals.
