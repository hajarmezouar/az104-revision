## Énoncé et corrigé fourni


You have an Azure subscription that contains an Azure Container Registry named RegistryProd01, which is currently configured with the Standard pricing tier.
You need to enable support for geo-replication for RegistryProd01.
What is the first step you should perform on RegistryProd01 to meet this requirement?
Réponses:
☐ Enable the admin user for the registry.
☐ Create a scope map for the registry.
☐ Configure an automation task.
☐ Define a cache rule.
**☑** Change the registry to a higher SKU tier.
Explication
`Change the registry to a higher SKU tier` is the correct answer here. Geo-replication in Azure Container Registry is only supported in the Premium SKU. Since RegistryProd01 is currently using the Standard SKU, the first step to enable geo-replication is to upgrade the SKU to Premium. Once the SKU is upgraded, you can configure geo-replication across multiple regions.
`Enable the admin user for the registry` is incorrect because this is related to authentication and does not enable geo-replication.
`Create a scope map for the registry` is incorrect because scope maps are used for defining permissions for tokens, not for geo-replication.
`Configure an automation task` is incorrect because automation tasks are used for building and pushing images, not for geo-replication.
`Define a cache rule` is incorrect because cache rules are unrelated to geo-replication.
Reference(s):
- https://learn.microsoft.com/en-us/azure/container-registry/container-registry-geo-replication
- https://learn.microsoft.com/en-us/azure/container-registry/container-registry-skus
