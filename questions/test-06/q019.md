## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1, which stores blob data.
You must assign a role to a user named User1 so that the user can access the blob data in storage1. The role assignment must support Azure role assignment conditions.
Which two roles are suitable for assigning to User1?
Réponses (plusieurs réponses possibles)
☐ Owner
☐ Storage Account Contributor
☐ Storage Account Backup Contributor
**☑** Storage Blob Data Contributor
**☑** Storage Blob Data Owner
☐ Storage Blob Delegator
Explication
`Storage Blob Data Contributor` is the correct answer because this role allows the user to read, write, and delete blob data within a storage account. This role supports conditions, which can help control access based on specific criteria like time, IP address, or other factors.
`Storage Blob Data Owner` is the correct answer because this role grants full control over blob data, including setting access policies and modifying blob content. It also supports conditions for access.
`Owner` is incorrect because while this role gives full administrative access to the storage account, it does not allow direct blob data access, nor does it support conditions for blob-level data access.
`Storage Account Contributor` is incorrect because it grants management access to the storage account but does not provide direct access to blob data.
`Storage Account Backup Contributor` is incorrect because this role is designed for backup and recovery operations but doesn't provide direct access to blob data.
`Storage Blob Delegator` is incorrect because this role is used to delegate access through OAuth 2.0 on behalf of a user or service and is not intended for direct blob data access.
