## Énoncé et corrigé fourni


You have an Azure subscription that contains a virtual machine named VM1.
You need to configure backups for VM1. The solution must ensure that the backup data is stored across three availability zones within the primary Azure region.
Which three actions should you perform in sequence?
ACTIONS
- Configure a replication policy.
- Create a Recovery Services vault.
- Set the vault replication type to Zone-redundant storage (ZRS).
- Set the vault replication type to Locally-redundant storage (LRS).
- Create a backup policy for VM1 and enable backup for the virtual machine.
Réponses:
☐ 2-5-3
**☑** 2-3-5
☐ 5-3-2
☐ 3-5-2
Explication
`(Action 2) Create a Recovery Services vault` is the first step because the Recovery Services vault is where backup data is stored, and it supports multiple types of replication, including zone-redundant storage (ZRS) which is necessary for availability across three zones.
`(Action 3) Set the vault replication type to Zone-redundant storage (ZRS)` is the second step. After creating the vault, you must configure it to use zone-redundant storage, ensuring that the backups are replicated across three availability zones for higher availability.
`(Action 5) Create a backup policy for VM1 and enable backup for the virtual machine` is the final step. After the vault is created and configured, you need to create a backup policy and link it to VM1 to manage backup schedules and retention.
`(Action 1) Configure a replication policy` is incorrect because the backup replication type (ZRS) is set as part of the vault configuration, not a separate policy.
`(Action 4) Set the vault replication type to Locally-redundant storage (LRS)` is incorrect because LRS only replicates within a single data center, not across multiple availability zones, and thus does not meet the requirement of storing backups across three zones.
