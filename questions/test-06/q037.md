## Énoncé et corrigé fourni


You have a virtual network named VNet1 with an address space of 10.2.0.0/16 and a single subnet configured as 10.2.0.0/24.
You plan to deploy a virtual machine in VNet1 and assign it an IP address from the 192.168.1.0/24 address range.
Before the virtual machine can receive an IP address from 192.168.1.0/24, what must you do first?
Réponses:
☐ add a network interface
☐ add a subnet
**☑** add an address space
☐ delete a subnet
☐ delete an address space
Explication
`Add an address space` is correct because the existing address space of VNet1 is configured as 10.2.0.0/16. To allow virtual machines on VNet1 to receive an IP address from 192.168.1.0/24, you must first add this new address space to VNet1. Azure virtual networks support multiple address spaces, but they must be added explicitly.
`Add a network interface` is incorrect because a network interface allows a VM to connect to a subnet but does not affect the IP range available within the virtual network.
`Add a subnet `is incorrect because adding a new subnet would require an available address space in the 192.168.1.0/24 range, which is not currently defined within VNet1.
`Delete a subnet` is incorrect because deleting a subnet will not allow adding the desired IP range.
`Delete an address space` is incorrect because the action required is to add a new address space, not remove an existing one.
