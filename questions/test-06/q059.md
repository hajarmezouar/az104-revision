## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named adatum.com.
The tenant contains the following security groups:
- Group1
- Type: Security
- Member of: None
- Group2
- Type: Security
- Member of: Group1
The tenant also contains the following users:
- User1
- Member of: Group1
- User2
- Member of: Group2
You assign a Microsoft Entra ID P2 license to Group1.
The license is configured so that the Microsoft Entra ID P2 service plan is enabled.
Group2 is not directly assigned any licenses.
True or False:
`“You can remove the Microsoft Entra ID P2 license from User1.”`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because User1 received the Microsoft Entra ID P2 license through group-based licensing via Group1. Licenses assigned through a group cannot be removed directly from an individual user. To revoke the license from User1, you must either remove User1 from Group1 or unassign the license from Group1 entirely.
Group-based licensing enforces inheritance, meaning individual license removal is not possible for users who inherit their license through a group assignment.

**https://learn.microsoft.com/en-us/entra/fundamentals/concept-group-based-licensing
