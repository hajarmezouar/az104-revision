## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named adatum.com.
The tenant contains the following security groups:
- Group1
- Type: Security
- Member of: None
- Group2
- Type: Security
- Member of: Group1
The tenant also contains the following users:
- User1
- Member of: Group1
- User2
- Member of: Group2
You assign a Microsoft Entra ID P2 license to Group1.
The license is configured so that the Microsoft Entra ID P2 service plan is enabled.
Group2 is not directly assigned any licenses.
True or False:
`“User2 is assigned the Microsoft Entra ID P2 license.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because Microsoft Entra group-based licensing does not support nested group inheritance. In this scenario, although Group1 has been assigned the Microsoft Entra ID P2 license, User2 is only a member of Group2, which is a child of Group1. Because nested groups are not supported for license propagation, User2 will not receive the license via Group1 unless Group2 is directly licensed or the license is directly assigned to User2.

**https://learn.microsoft.com/en-us/entra/fundamentals/concept-group-based-licensing
