## Énoncé et corrigé fourni


You have an Azure subscription that contains 100 virtual machines.
You need to quickly identify virtual machines that are underutilized and could be moved to a lower-cost service tier.
Which Azure portal blade should you use?
Réponses:
☐ Monitor
**☑** Advisor
☐ Metrics
☐ Customer insights
Explication
`Advisor` is the correct answer because Azure Advisor provides personalized recommendations to optimize your Azure resources for cost, performance, security, and more. Specifically, it includes cost recommendations to help identify underutilized virtual machines that can be resized to a lower-cost SKU, thereby reducing unnecessary spend.
`Monitor` is incorrect because although it provides telemetry data and performance metrics, it doesn't offer built-in cost optimization recommendations.
`Metrics` is incorrect because it shows raw performance counters and charts but doesn't interpret or recommend changes based on utilization.
`Customer insights` is incorrect because it's related to customer data analytics (like Dynamics 365), and not relevant for Azure resource management or optimization.
Reference(s):
- https://learn.microsoft.com/en-us/azure/advisor/advisor-cost-recommendations
- https://learn.microsoft.com/en-us/azure/advisor/advisor-overview
