## Énoncé et corrigé fourni


You have an Azure subscription named ProdSubscription that contains the following resources:
You plan to configure Azure Backup reports for RSVault1.
While configuring diagnostic settings for the AzureBackupReports log category, you must choose a storage account as the destination.
Which `storage accounts` are eligible to store the Azure Backup reports for RSVault1?
Réponses:
☐ dataStore1 only
☐ dataStore2 only
**☑** dataStore3 only
☐ dataStore1, dataStore2, and dataStore3
Explication
`dataStore3 only` is correct because Azure Backup requires that the storage account used for diagnostic settings (like Azure Backup reports) be in the same region as the Recovery Services vault (RSVault1). Since RSVault1 is in the West Europe region, only dataStore3, located in West Europe, meets this requirement.
`dataStore1 only` is incorrect because dataStore1 is in the East US region, which does not match the West Europe region of Vault1.
`dataStore2 only` is incorrect because dataStore2 is in the West US region, which also does not match the West Europe region of Vault1.
`dataStore1, dataStore2, and dataStore3` is incorrect because only dataStore3 is in the same region as Vault1. dataStore1 and dataStore2 are in East US and West US, respectively, and therefore cannot be used.
