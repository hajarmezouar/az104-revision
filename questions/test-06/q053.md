## Énoncé et corrigé fourni


You are configuring Microsoft Entra ID–based authentication for an Azure Storage account named storage1.
You must ensure that users who are members of a security group named Group1 can upload files to the storage account by using the Azure portal.
The access configuration must follow the principle of least privilege, granting only the minimum permissions required to perform the upload operation.
Which two roles should you assign to Group1 to meet these requirements?
Réponses (plusieurs réponses possibles)
**☑** Reader
☐ Storage Blob Data Reader
**☑** Storage Blob Data Contributor
☐ Storage Account Contributor
☐ Contributor
Explication
`Reader` is correct because it grants management-plane read access to the storage account. Although this role does not allow users to upload files, it enables them to discover and navigate the storage account and its containers in the Azure portal. When using Microsoft Entra ID based authentication through the Azure portal, this role is required so users can access the storage account interface without being granted administrative permissions.
`Storage Blob Data Contributor` is correct because it grants the data-plane permissions required to read, write, modify, and delete blob data. This is the role that actually allows members of Group1 to upload files to blob storage.
`Storage Blob Data Reader` is incorrect because it only grants read access to blob data. Users can view blobs but cannot upload, modify, or delete them.
`Storage Account Contributor` is incorrect because it grants management permissions over the storage account, such as configuring storage account settings. These administrative permissions are unnecessary for uploading files and violate the principle of least privilege.
`Contributor` is incorrect because it provides broad management access to Azure resources, including the storage account. This exceeds the permissions required for uploading files and does not follow the principle of least privilege.
