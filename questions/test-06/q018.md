## Énoncé et corrigé fourni


You have an Azure subscription that contains a storage account named storage1.
You want to make sure that the access keys for storage1 are rotated automatically.
Which configuration should you set up?
Réponses:
☐ Configure a backup vault
☐ Configure redundancy settings for storage1
☐ Configure lifecycle management for storage1
**☑** Configure an Azure Key Vault
☐ Configure a Recovery Services vault
Explication
`Configure an Azure Key Vault` is the correct answer. To ensure that the access keys for storage1 rotate automatically, you should store the keys in Azure Key Vault and enable key rotation policies. Key Vault allows for the secure storage of secrets, including storage account access keys, and provides the ability to configure automatic key rotation.
`Configure a backup vault` and `Configure a Recovery Services vault` are incorrect because these are used for backing up data and managing disaster recovery, not for rotating access keys.
`Configure redundancy settings for storage1` is incorrect because this deals with the replication of storage data across different locations for high availability, not key management.
`Configure lifecycle management for storage1` is incorrect because this manages data retention policies, not access key rotation.
Reference(s):
- https://learn.microsoft.com/en-us/azure/key-vault/general/overview
- https://learn.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage?tabs=azure-portal
