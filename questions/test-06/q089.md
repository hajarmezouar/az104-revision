## Énoncé et corrigé fourni


An Azure subscription contains the following users:
- User1 – Member of Group1
- User2 – Member of Group2
- User3 – Member of Group3
The groups are configured as follows:
- Group1 – Type: Security
- Group2 – Type: Security
- Group3 – Type: Microsoft 365
All three groups are enabled for Microsoft Entra role assignments.
You also have a resource group named RG1. The access control (IAM) configuration for RG1 is shown in the exhibit.
True or False:
`"You can assign User3 the Owner role for RG1 by assigning the Owner role to Group3 for RG1."`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer because Group3 is configured to allow Microsoft Entra roles to be assigned to it (`Microsoft Entra roles can be assigned to the group: Yes`). This makes the group eligible for role-based access control (RBAC) assignments, such as assigning the Owner role for a specific resource group like RG1. Even though Group3 is a Microsoft 365 group, direct role assignments (not nested) are supported when the group is configured for role assignments. As a result, User3, a direct member of Group3, will inherit the Owner role for RG1.
Reference(s):
- https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/groups-concept#assign-azure-ad-roles-to-groups
- https://learn.microsoft.com/en-us/entra/identity/users/directory-service-limits-restrictions
