## Énoncé et corrigé fourni


You purchase a new Azure subscription named Subscription1.
Within Subscription1, you deploy a virtual machine named VM1. VM1 is currently not protected by Azure Backup.
You need to configure Azure Backup for VM1. The backups must run daily at 01:00 and be retained for a period of 30 days.
Which object should you use to configure backup protection for VM1?
Réponses:
**☑** A backup policy
☐ A batch job
☐ A batch schedule
☐ A recovery plan
Explication
`A backup policy` is the correct answer because Azure Backup uses backup policies to define the schedule and retention settings for protecting resources, such as virtual machines. To configure the protection for VM1, you would create a backup policy that specifies the backup time (01:00) and the retention period (30 days).
`A batch job` is incorrect because batch jobs are typically used in Azure Batch to execute large-scale parallel and high-performance computing tasks, not for configuring backups.
`A batch schedule` is incorrect because it is not related to Azure Backup. Batch schedules are relevant in the context of Azure Batch, not for VM backup configuration.
`A recovery plan` is incorrect because recovery plans are used in Azure Site Recovery for orchestrating failover and recovery of applications, not for scheduling and managing backups.
