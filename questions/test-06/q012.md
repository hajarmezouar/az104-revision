## Énoncé et corrigé fourni


An Azure subscription contains three Azure Container Registry (ACR) instances. Each registry is configured with a different pricing tier:
- ContReg1 – Service tier: Premium
- ContReg2 – Service tier: Standard
- ContReg3 – Service tier: Basic
You plan to use Azure Container Registry (ACR) Tasks and also require support for private endpoint connections.
Which of the container registries can be configured to use private endpoints?
Réponses:
**☑** ContReg1 only
☐ ContReg1 and ContReg2 only
☐ ContReg1, ContReg2, and ContReg3
Explication
`ContReg1 only` is the correct answer because only the Premium tier of Azure Container Registry supports private endpoints. ContReg1 is configured with the Premium tier, which allows the use of private endpoints. Standard and Basic tiers, as seen in ContReg2 and ContReg3, do not support private endpoints.
`ContReg1 and ContReg2 only` is incorrect because the Standard tier (used by ContReg2) does not support private endpoints.
`ContReg1, ContReg2, and ContReg3` is incorrect because neither the Standard nor Basic tiers (used by ContReg2 and ContReg3) support private endpoints.
Reference(s):
- https://learn.microsoft.com/en-us/azure/container-registry/container-registry-skus
