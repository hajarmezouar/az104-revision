## Énoncé et corrigé fourni


You have an Azure subscription named ProdSub1 that contains the following resources:
- RegGrp1 – A resource group
- Action1 – An action group configured to send an email notification to admin1@apexcore.com
The subscription includes an alert rule with the following configuration:
- Name: Alert1
- Scope: All resource groups in ProdSub1, including any resource groups created in the future
- Condition: All administrative operations
- Action: Action1
The subscription also includes an alert processing rule with the following settings:
- Name: Rule1
- Scope: ProdSub1
- Rule type: Suppress notifications
- Schedule:
- Start: September 10, 2024
- End: September 13, 2024
True or False:
`"If you create a resource group in ProdSub1 on September 11, 2024, Alert1 is listed in the Azure portal."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because Alert1 has a scope that includes all resource groups in ProdSub1. It also includes all future resources. This means that any resource group created in ProdSub1, regardless of when it's created, will fall under the scope of Alert1. So, if a new resource group is created in ProdSub1 on September 11, 2024, Alert1 would be listed in the Azure portal for that resource group.
