## Énoncé et corrigé fourni


An Azure subscription is associated with a Microsoft Entra tenant named contoso.com. The tenant is synchronized with an on-premises Active Directory domain.
The domain includes the following users and assigned roles:
- SecAdmin1 – Role: Security Administrator
- BillAdmin1 – Role: Billing Administrator
- User1 – Role: Reports Reader
Self-service password reset (SSPR) is enabled for all users and configured with the following settings:
- Two authentication methods are required to reset a password.
- Available authentication methods are Mobile phone and Security questions.
- Users must register three security questions.
- Users must correctly answer three security questions during password reset.
The following security questions are configured:
- What is your favorite food?
- In what city was your first job?
- What was the name of your first pet?
True or False:
`“During a self-service password reset, User1 must answer the security question ‘What was the name of your first pet?’”`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because User1 has the Reports Reader role, which is not an administrative role in Microsoft Entra. As a standard user, User1 will follow the regular self-service password reset (SSPR) policy that applies to non-admin users. Since security questions are enabled as an authentication method for SSPR, User1 can be prompted to answer questions like "What was the name of your first pet?" as part of the password reset process.

- https://docs.microsoft.com/en-us/azure/active-directory/authentication/concept-sspr-policy#administrator-reset-policy-differences
