## Énoncé et corrigé fourni


You have an Azure container registry named contoso2023 as shown below.
You want to configure contoso2023 so that it uses a dedicated data endpoint for data operations.
Which two configuration settings must you enable or modify on contoso2023 to meet this requirement?

Explication
To enable contoso2023 to use a dedicated data endpoint, you need to configure the following two settings:
`Properties`: This is where you can enable and configure the dedicated data endpoint for your Azure container registry. From this blade, you must first change the pricing plan from Standard to Premium. This setting is crucial for routing all data plane operations through a dedicated endpoint.
`Networking`: After the registry is upgraded to Premium, you must go to Networking and enable the dedicated data endpoint setting. Dedicated data endpoints provide registry-specific data endpoint URLs, such as `<registry-name>.<region>.data.azurecr.io`, for data operations.
`Overview`, `Tasks`, `Access control (IAM)`, and `Events` are NOT relevant for enabling or configuring a dedicated data endpoint.
