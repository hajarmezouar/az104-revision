## Énoncé et corrigé fourni


You have an Azure subscription named ProdSub1 that contains the following resources:
- RegGrp1 – A resource group
- Action1 – An action group configured to send an email notification to admin1@apexcore.com
The subscription includes an alert rule with the following configuration:
- Name: Alert1
- Scope: All resource groups in ProdSub1, including any resource groups created in the future
- Condition: All administrative operations
- Action: Action1
The subscription also includes an alert processing rule with the following settings:
- Name: Rule1
- Scope: ProdSub1
- Rule type: Suppress notifications
- Schedule:
- Start: September 10, 2024
- End: September 13, 2024
True or False:
`"If you create a resource group in ProdSub1 on September 12, 2024, an email message is sent to admin1@apexcore.com."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because, although Alert1 is configured to send an email to admin1@apexcore.com for all administrative operations, there is an alert processing rule (Rule1) in place that suppresses notifications between September 10, 2024 and September 13, 2024. Therefore, despite a new resource group being created in ProdSub1 on September 12, 2024, which is an administrative operation, the suppress rule will prevent the email notification from being sent to admin1@apexcore.com.

- https://docs.microsoft.com/en-us/azure/azure-monitor/platform/action-groups
- https://docs.microsoft.com/en-us/azure/azure-monitor/platform/alerts-action-rules
