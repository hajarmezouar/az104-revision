## Énoncé et corrigé fourni


An Azure subscription contains three virtual machines. Each VM has an assigned public IP address and is connected to a subnet within VNet1.
The configuration is as follows:
- VM1 – Public IP: 131.107.10.10 – Connected to VNet1/Subnet1
- VM2 – Public IP: 150.120.10.10 – Connected to VNet1/Subnet2
- VM3 – Public IP: 170.20.10.10 – Connected to VNet1/Subnet1
The subscription also contains a storage account named contoso2024, which is configured with network access restrictions as shown in the exhibit.
Based on the current firewall and virtual network settings of the storage account, evaluate the following statement.
True or False:
`"VM2 can connect to contoso2024 by using 150.120.10.10."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because VM2 has the public IP address 150.120.10.10, which is explicitly listed in the firewall rules of the contoso2024 storage account. While VM2 is connected to VNet1/Subnet2 (a different subnet than Subnet1), the public IP address being listed in the firewall allows VM2 to connect to the storage account, regardless of its subnet within VNet1.
Therefore, VM2 can still connect to contoso2024 using its public IP address.

- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-overview
