## Énoncé et corrigé fourni


You manage a Microsoft Entra tenant named ironclad.com.
The tenant contains the following groups:
- Group1
- Group type: Security
- Membership type: Dynamic user
- Rule: Users where city starts with “m”
- Group2
- Group type: Microsoft 365
- Membership type: Dynamic user
- Rule: Users whose department is not “human resources”
- Group3
- Group type: Microsoft 365
- Membership type: Assigned
- No dynamic rule configured
You then create two users with the following attributes:
- User1
- City: Montreal
- Department: Human resources
- Microsoft 365 license assigned: Yes
- User2
- City: Melbourne
- Department: Marketing
- Microsoft 365 license assigned: No
Based on the configured dynamic membership rules and user properties, which group or groups does User1 belong to?
Réponses:
**☑** Group1 only
☐ Group2 only
☐ Group3 only
☐ Group1 and Group2 only
☐ Group1 and Group3 only
☐ Group1, Group2, and Group3
Explication
`Group1 only` is correct because User1 meets the dynamic membership rule for Group1 but does not meet the membership criteria for Group2 or Group3.
- Group1 (Dynamic user): The rule specifies that users whose city starts with "m" are added to this group.
- User1's city is Montreal, which starts with "M." Therefore, User1 is a member of Group1.
- Group2 (Dynamic user): The rule excludes users whose department is "human resources."
- User1's department is "Human resources," so User1 is excluded from Group2.
- Group3 (Assigned membership): Membership is manually assigned.
- User1 is not manually assigned to Group3, so User1 is not a member of Group3.
Therefore, User1 is only a member of Group1.
