## Énoncé et corrigé fourni


You have an Azure Linux virtual machine that is protected by Azure Backup.
Two files were deleted from the virtual machine one week ago.
You need to restore the deleted files to an on-premises computer in the shortest possible time.
Which four actions should you perform in sequence?
ACTIONS
- From the Azure portal, click Restore VM from the vault.
- Mount a VHD.
- From the Azure portal, click File Recovery from the vault.
- Copy the files by using AZCopy.
- Select a restore point that contains the deleted files.
- Copy the files by using File Explorer.
- Download and run the script to mount a drive on the local computer.
Réponses:
☐ 2-3-5-7
☐ 1-5-2-6
**☑** 3-5-7-6
☐ 6-4-7-2
☐ 4-5-1-3
☐ 2-4-7-3
Explication
3-5-7-6 is the correct sequence of actions.
(Action 3) From the Azure portal, click File Recovery from the vault – To begin the file recovery process, navigate to the File Recovery option in the vault associated with the backup.
(Action 5) Select a restore point that contains the deleted files – Choose a restore point from a date prior to the deletion of the files to ensure they are available in the backup.
(Action 7) Download and run the script to mount a drive on the local computer – This step mounts the backup as a drive on the local computer, allowing access to the files in the backup.
(Action 6) Copy the files by using File Explorer – Using File Explorer provides a straightforward way to restore the files to an on-premises Windows Server computer quickly.
(Action 2) Mount a VHD is not applicable in this context, as the File Recovery option does not involve VHDs directly for individual file restoration.
(Action 4) Copy the files by using AZCopy is unnecessary as File Explorer is sufficient once the drive is mounted. Also, File explorer will be faster than AzCopy.
(Action 3) From the Azure portal, click Restore VM from the vault would initiate a full VM restore, which is not required for individual file recovery.
