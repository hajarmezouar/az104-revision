## Énoncé et corrigé fourni


An Azure subscription contains three Azure Container Registry (ACR) instances. Each registry is configured with a different pricing tier:
- ContReg1 – Service tier: Premium
- ContReg2 – Service tier: Standard
- ContReg3 – Service tier: Basic
You plan to use Azure Container Registry (ACR) Tasks and also require support for private endpoint connections.
Which of the listed container registries can be used to run ACR Tasks?
Réponses:
☐ ContReg1 only
☐ ContReg1 and ContReg2 only
**☑** ContReg1, ContReg2, and ContReg3
Explication
`ContReg1, ContReg2, and ContReg3 `is the correct answer here. ACR Tasks are supported in all service tiers: Basic, Standard, and Premium. While there are performance and feature differences across the tiers (such as the number of concurrent tasks or webhook triggers), ACR Tasks functionality is available in all three tiers, including Basic.
