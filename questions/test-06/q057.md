## Énoncé et corrigé fourni


You have an Azure subscription named ProdSub1 that contains the following resources:
- RegGrp1 – A resource group
- Action1 – An action group configured to send an email notification to admin1@apexcore.com
The subscription includes an alert rule with the following configuration:
- Name: Alert1
- Scope: All resource groups in ProdSub1, including any resource groups created in the future
- Condition: All administrative operations
- Action: Action1
The subscription also includes an alert processing rule with the following settings:
- Name: Rule1
- Scope: ProdSub1
- Rule type: Suppress notifications
- Schedule:
- Start: September 10, 2024
- End: September 13, 2024
True or False:
`“If you add a tag to RG1 on September 15, 2022, an email message is sent to admin1@apexcore.com.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer because the alert rule, Alert1, is set to monitor all administrative operations, and adding a tag to a resource is considered an administrative operation in Azure. Since the alert applies to all resource groups in ProdSub1, including future resources, and the suppression rule (which suppresses notifications) only applies between September 10, 2024, and September 13, 2024, the action group linked to Alert1 will trigger an email to admin1@apexcore.com when the tag is added on September 15, 2024.

- https://learn.microsoft.com/en-us/azure/azure-monitor/alerts/alerts-overview
- https://learn.microsoft.com/en-us/azure/azure-monitor/alerts/action-groups
