## Énoncé et corrigé fourni


You have an Azure subscription that contains a virtual machine running Windows 10.
You need to join the virtual machine to an Active Directory domain by using the below Azure Resource Manager (ARM) template.
Which value should you choose for `Code Segment B`?
Réponses:
**☑** "ProtectedSettings": {
☐ "Settings": {
☐ "Statuses": {
Explication
`"ProtectedSettings": {` is correct because in an Azure Resource Manager (ARM) template, sensitive information like passwords or secrets, such as the domainPassword, should always be placed in the ProtectedSettings section. This ensures that the sensitive values are securely encrypted and not exposed in plaintext when viewed or logged.
`"Settings": {` is incorrect because it is used for general configuration settings and does not handle sensitive information securely.
`"Statuses": {` is incorrect because it is used to report the status of an extension deployment, not for passing configuration parameters.

- https://learn.microsoft.com/en-us/azure/virtual-machines/extensions/dsc-template#domain-join
