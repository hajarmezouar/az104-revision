## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named adatum.com.
The tenant contains the following security groups:
- Group1
- Type: Security
- Member of: None
- Group2
- Type: Security
- Member of: Group1
The tenant also contains the following users:
- User1
- Member of: Group1
- User2
- Member of: Group2
You assign a Microsoft Entra ID P2 license to Group1.
The license is configured so that the Microsoft Entra ID P2 service plan is enabled.
Group2 is not directly assigned any licenses.
True or False:
`“You can assign User1 the Microsoft Defender for Cloud Apps Discovery license.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because when a license is assigned to a group, the licensing options are inherited by all members of the group, and individual users cannot modify or enable specific license features that were disabled at the group level.
- User1 is a member of Group1, which has the Microsoft Entra ID P2 license assigned.
- If specific features within the license, such as Microsoft Defender for Cloud Apps Discovery, were disabled when assigning the license to Group1, they remain disabled for all members.
- License settings inherited from a group cannot be modified at the user level.
- Group-based licensing controls all assigned features.
- Microsoft Entra ID group-based licensing ensures that individual users cannot override settings configured at the group level.
- If an admin wants to enable a feature, the change must be made at the group level, not for individual users.
- User-level modifications are restricted.
- Since User1’s license is inherited from Group1, they cannot be manually assigned the Microsoft Defender for Cloud Apps Discovery license unless Group1’s settings are updated to enable it.
Reference(s):
https://docs.microsoft.com/en-us/azure/active-directory/fundamentals/active-directory-licensing-whatis-azure-portal
https://docs.microsoft.com/en-us/cloud-app-security/manage-admins
