## Énoncé et corrigé fourni


A Microsoft Entra hybrid environment contains the following user accounts:
- User1
- User type: Member
- On-premises synchronization enabled: No
- User2
- User type: Member
- On-premises synchronization enabled: Yes
- User3
- User type: Guest
- On-premises synchronization enabled: No
You need to modify the `JobTitle` attribute for these users.
For which users can the attribute be updated directly within Microsoft Entra ID?
Réponses:
☐ User1 only
☐ User1 and User2 only
**☑** User1 and User3 only
☐ User1, User2, and User3
Explication
`User1 and User3 only` is the correct answer because their accounts are cloud-only (User1 is a member with no on-premises sync, and User3 is a guest user). This means their attributes—including JobTitle—can be modified directly in Microsoft Entra ID.
User2 is synchronized from on-premises Active Directory, so their attributes must be modified in the on-premises directory. Microsoft Entra ID does not allow attribute modification for synced users from the cloud interface.
Reference(s):
- https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-user-profile-info
