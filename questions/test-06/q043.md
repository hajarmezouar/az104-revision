## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- VM1 – Virtual machine
- storage1 – Storage account
- Workspace1 – Log Analytics workspace
- DB1 – Azure SQL database
You plan to create a data collection rule named DCR1 in Azure Monitor.
Which of the listed resources can you set as destinations in DCR1?
Réponses:
☐ storage1 only
**☑** Workspace1 only
☐ Workspace1 and storage1 only
☐ Workspace1, storage1, and DB1 only
Explication
`Workspace1 only` is the correct answer. In Azure Monitor, a Data Collection Rule (DCR) defines how data is collected from sources and where it is sent. The valid destinations for a DCR are Log Analytics workspaces, which store monitoring data for query and analysis, and are the standard supported target for the Azure Monitor Agent. Other destinations such as Azure Storage accounts or Event Hubs can be used with diagnostic settings, but they are not supported destinations when configuring a DCR directly. Similarly, Azure SQL databases are not valid targets for monitoring data.
In the given scenario, this means that only Workspace1 can be set as a destination in DCR1. Storage1 and DB1 are not valid choices for a DCR destination, as the DCR framework is designed to work with Log Analytics workspaces for centralized monitoring and analytics.
Reference(s):
