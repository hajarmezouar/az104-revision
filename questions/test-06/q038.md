## Énoncé et corrigé fourni


You have a virtual network named VNet1 with an address space of 10.2.0.0/16 and a single subnet configured as 10.2.0.0/24.
Based on the current address space and subnet configuration, a virtual machine deployed in VNet1 must be assigned an IP address from the 10.2.1.0/24 range.
What must you do before the virtual machine can receive an IP address from this range?
Réponses:
☐ add a network interface
**☑** add a subnet
☐ add an address space
☐ delete a subnet
☐ delete an address space
Explication
`Add a subnet` is correct because the current address space for VNet1 is 10.2.0.0/16, which already includes the 10.2.1.0/24 range. However, there is only one existing subnet (default) configured with the 10.2.0.0/24 address prefix. To assign IP addresses from 10.2.1.0/24, you would need to create a new subnet using this address range within the existing address space.
`Add a network interface` is incorrect because a network interface allows a VM to connect to a subnet but does not create a new address range or subnet.
`Add an address space` is incorrect because 10.2.1.0/24 is already part of the existing 10.2.0.0/16 address space, so adding a new address space is unnecessary.
`Delete a subnet` is incorrect because removing an existing subnet does not help in assigning a new IP range.
`Delete an address space` is incorrect because deleting an address space would reduce the IP range available, which is not required here.
