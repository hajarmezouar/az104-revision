## Énoncé et corrigé fourni


An Azure subscription contains two virtual machines with the following configurations:
- VM1
- Operating system: Windows Server 2019
- Connected to: Subnet1
- VM2
- Operating system: Windows Server 2019
- Connected to: Subnet2
Both VM1 and VM2 have public IP addresses, and inbound Remote Desktop (RDP) access is enabled on each virtual machine.
Subnet1 and Subnet2 belong to the same virtual network named VNET1.
The subscription contains two network security groups (NSGs):
- NSG1 contains only the default security rules.
- NSG2 contains the default rules and an additional inbound rule with the following configuration:
- Priority: 100
- Name: Rule1
- Protocol: TCP
- Port: 3389
- Source: Any
- Destination: Any
- Action: Allow
NSG1 is associated with Subnet1, and NSG2 is associated with the network interface of VM2.
True or False:
`“You can connect to VM1 from the internet using Remote Desktop.”`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because VM1 is associated with NSG1, which only has the default rules. By default, NSGs deny inbound traffic from the internet unless there is an explicit rule to allow it. Since NSG1 does not have any custom rule allowing inbound Remote Desktop Protocol (RDP) traffic on port 3389 from the internet, VM1 cannot be accessed via RDP from the internet.
Reference(s):
- https://learn.microsoft.com/en-us/azure/virtual-network/network-security-groups-overview
