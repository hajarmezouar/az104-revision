## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that has the ironclad.onmicrosoft.com domain name.
You have a domain name of ironclad.com registered at a third-party registrar.
You need to ensure that you can create Microsoft Entra users that have names containing a suffix of @ironclad.com.
Which three actions should you perform in sequence?
ACTIONS
- Verify the domain.
- Add a record to the public ironclad.com DNS zone.
- Create an Azure DNS zone.
- Configure company branding.
- Add a Microsoft Entra tenant.
- Add a custom domain name.
Réponses:
☐ 2-3-6
**☑** 6-2-1
☐ 3-2-6
☐ 6-1-2
Explication
`6-2-1`  is the CORRECT sequence of actions.
`(Action 6)` Add a custom domain name is correct. You begin by adding `ironclad.com` as a custom domain in your Microsoft Entra tenant. This tells Entra ID that you want to use this domain for user principal names (UPNs) and email addresses.
`(Action 2)` Add a record to the public ironclad.com DNS zone is correct. To prove ownership of the domain, Microsoft Entra ID provides a TXT or MX record that must be added to the public DNS zone where the domain (`ironclad.com`) is hosted. This is required for verification.
`(Action 1)` Verify the domain is correct. After adding the DNS record, you return to Microsoft Entra ID and complete the verification process. Once verified, the domain can be used to create users with UPNs like `user@ironclad.com`.
`(Action 3)` Create an Azure DNS zone is incorrect. Not required unless you're hosting DNS within Azure, which is not needed for verifying a third-party registered domain.
`(Action 4)` Configure company branding is incorrect. Not required to use a custom domain for user accounts.
`(Action 5)` Add a Microsoft Entra tenant is incorrect. Already provided in the question, so not needed.

- https://learn.microsoft.com/en-us/entra/fundamentals/add-custom-domain
