## Énoncé et corrigé fourni


You have an Azure subscription that includes a user named User1.
You must grant User1 permissions to:
- Create and manage virtual machines
- Create and manage virtual networks
The permissions assigned must follow the principle of least privilege.
Which role-based access control (RBAC) role should you assign to User1?
Réponses:
☐ Owner
☐ Virtual Machine Contributor
**☑** Contributor
☐ Virtual Machine Administrator Login
Explication
`Contributor` is the correct answer because this role grants full access to manage all Azure resources, including virtual machines and virtual networks, but does not allow access to assign roles in Azure RBAC. This aligns with the requirement to deploy virtual machines and manage virtual networks while following the principle of least privilege, as the role does not grant unnecessary permissions such as role assignment.
`Owner` is incorrect because the Owner role has full access to all resources, including the ability to assign roles in RBAC. This exceeds the principle of least privilege since User1 does not require role assignment capabilities.
`Virtual Machine Contributor` is incorrect because this role grants permissions only for managing virtual machines, but it does not include the ability to manage virtual networks, which is explicitly required in the scenario.
`Virtual Machine Administrator Login` is incorrect because this role only allows a user to log in to virtual machines with administrator privileges. It does not provide permissions to deploy virtual machines or manage virtual networks.
