## Énoncé et corrigé fourni


You have an Azure subscription linked to a hybrid Microsoft Entra tenant. The tenant includes the users listed below:
- User1: Not enabled for on-premises synchronization
- User2: Enabled for on-premises synchronization
You create the following Azure Files shares:
- share1 in storage account contoso2025
- share2 in storage account contoso2025
- share3 in storage account contoso2026
You configure identity-based access for contoso2025 by enabling Active Directory Domain Services (AD DS) as the identity source and setting the default share-level permissions to allow access for all authenticated users and groups.
True or False:
`"User1 can access the content in share1."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because User1 does not have on-premises synchronization enabled, as indicated. According to the identity-based access configuration shown in the exhibit, only users synchronized from on-premises AD DS or those with hybrid identities can access the file shares. User1 is not synced from an on-premises AD DS environment and is therefore not eligible for access to share1, despite the permissions being enabled for authenticated users.
