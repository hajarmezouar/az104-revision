## Énoncé et corrigé fourni


You have an Azure subscription named ProdSubscription that contains the following resources:
You plan to configure Azure Backup reports for RSVault1.
While configuring diagnostic settings for the AzureBackupReports log category, you must choose a storage account as the destination.
Which `Log Analytics workspaces` can you use for the Azure Backup reports of RSVault1?
Réponses:
☐ LogWorkspace1 only
☐ LogWorkspace2 only
☐ LogWorkspace3 only
**☑** LogWorkspace1, LogWorkspace2, and LogWorkspace3
Explication
`LogWorkspace1, LogWorkspace2, and LogWorkspace3` is correct because, as per the documentation, the location of the Log Analytics workspace does not need to match the location of the Recovery Services vault. Therefore, all three workspaces LogWorkspace1, LogWorkspace2, and LogWorkspace3, can be used to store the Azure Backup reports for Vault1.
Reference(s):
- https://learn.microsoft.com/en-us/azure/backup/configure-reports?tabs=recovery-services-vaults#1-create-a-log-analytics-workspace-or-use-an-existing-one
