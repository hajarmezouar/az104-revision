## Énoncé et corrigé fourni


You have an Azure subscription named Sub1 that contains the following resources:
- MG1: Management group
- RG1: Resource group
- VM1: Virtual machine
You create a user account named Admin1.
To which of these resources can you assign Admin1 as a co-administrator?
Réponses:
☐ VM1
☐ MG1
☐ RG1
**☑** Sub1
Explication
Sub1 is correct because the Co-administrator role can only be assigned at the subscription level. This role grants the same access as the built-in Owner role but does not allow modifying role assignments within the subscription.
