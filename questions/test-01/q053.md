## Énoncé et corrigé fourni


You have an Azure subscription that includes the following virtual networks:
The subscription also contains the following virtual machines:
Each virtual machine has only a private IP address assigned.
You then deploy an Azure Bastion resource with the following configuration:
True or False:
`"The Azure portal can use SSH to connect to VM2 through Bastion1."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because Bastion1 is deployed in VNet1 using the Basic SKU, which supports RDP for Windows VMs and SSH for Linux VMs through the Azure portal’s browser-based session. VM2 is a Linux VM located in VNet2, and since VNet2 is directly peered with VNet1, Bastion1 can be used to establish an SSH session from the portal. The Basic SKU limitation only applies to native client support (mstsc.exe or ssh.exe), which requires the Standard SKU. Since the question specifically states “Azure portal”, SSH through the portal is fully supported.
