## Énoncé et corrigé fourni


You have multiple Azure virtual machines deployed in a virtual network named VNet1.
You configure an Azure Storage account as shown below. The networking settings restrict public network access to selected virtual networks and subnets, and VNet1 is explicitly added with a service endpoint enabled on a specific subnet. No additional IP address ranges are configured in the firewall section. The network routing preference is set to use Microsoft network routing, and no private endpoints are configured.
Based on the configuration shown, select the option that correctly completes the following statement:
`"Azure Backup will be able to back up the unmanaged disks of the virtual machines in the storage account ________________________________."`
Réponses:
☐ always
☐ during a backup
**☑** never
Explication
`Never` is the correct answer because if you enable Virtual network in the firewall setting, you need to select the option at the bottom - Allow Azure services on the trusted services list to access this storage account and enable it. Otherwise the access will be limited to the resources in the VNet only.

- https://azure.microsoft.com/en-us/blog/azure-backup-now-supports-storage-accounts-secured-with-azure-storage-firewalls-and-virtual-networks
