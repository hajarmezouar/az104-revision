## Énoncé et corrigé fourni


You have an Azure subscription that contains an Azure container registry named ShireenReg1.
You enable the Admin user for ShireenReg1.
After enabling the Admin user, you want to sign in directly to the container registry.
Which username can you use to sign in to ShireenReg1?
Réponses:
☐ root
☐ admin
☐ administrator
**☑** ShireenReg1
Explication
ShireenReg1 is correct because when you enable the admin user for an Azure container registry, Azure provides the registry name itself as the username. This means you can use the container registry's name (in this case, "ShireenReg1") as the username, along with the admin user access key as the password, to log in.
