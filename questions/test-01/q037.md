## Énoncé et corrigé fourni


An Azure subscription contains an Azure Storage account named storageaccount1.
You export storageaccount1 as an Azure Resource Manager (ARM) template. The exported template defines the storage account type, location, SKU, encryption settings, access tier, and network access configuration. The network rules allow access by default and include a bypass for Azure services, with no virtual network rules or IP address restrictions specified.

True or False:
`"Individual blobs in storageaccount1 can be set to use the archive tier."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because this storage account is of type StandardV2 which supports blob-level tiering. So individual blob can have different tiers.
