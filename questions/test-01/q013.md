## Énoncé et corrigé fourni


You have an Azure subscription.
You plan to deploy a storage account named storage1 by using an Azure Resource Manager (ARM) template, as shown in the configuration below. The template defines the storage account location, SKU, and kind, along with network access settings. It also configures Blob service–level data protection features, including soft delete, container delete retention, change feed, and blob versioning, each with specified retention periods.
Based on this ARM template configuration, determine whether the following statement is True or False.
`"Three copies of storage1 will be maintained in the East US Azure region."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because with LRS type of redundancy you get 3 copies of the data spread in 3 different zones/datacenters of the region.
