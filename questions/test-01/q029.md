## Énoncé et corrigé fourni


An Azure subscription contains the following vault resources:
- Backup1: Backup vault
- Recovery1: Recovery Services vault
You then create a storage account that contains these resources:
- cont1: Blob container
- share1: File share
You need to determine where cont1 can be backed up.
To which vault can you back up cont1?
Réponses:
**☑** Backup1 only
☐ Recovery1 only
☐ Backup1 or Recovery1
☐ Cannot be backed up to Backup1 or Recovery1
Explication
`Backup1 only` is correct because Azure blob container can only be backed up in Azure Backup vault as it supports Azure blob storage service. Azure Recovery service vault on the other hand does not support Azure Blob storage.

- https://learn.microsoft.com/en-us/answers/questions/405915/what-is-difference-between-recovery-services-vault
