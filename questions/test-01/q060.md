## Énoncé et corrigé fourni


You create a virtual machine scale set named Scale1.
During deployment, Scale1 is configured with custom autoscaling settings, as shown in the exhibit. The configuration specifies an initial number of instances, minimum and maximum instance limits, and CPU-based scale-out and scale-in rules. In particular, the scale-out rule increases the instance count when average CPU usage exceeds the defined threshold for a specified duration.
Based on the autoscaling configuration shown in the exhibit, complete the following statement:
`“If Scale1 is first utilized at 25 percent for six minutes after it is deployed, and then utilized at 50 percent for six minutes, Scale1 will be running _______________.”`
Réponses:
**☑** 2 virtual machines
☐ 4 virtual machines
☐ 6 virtual machines
☐ 10 virtual machines
☐ 20 virtual machines
Explication
`2 virtual machines` is the correct answer because the Azure Virtual Machine Scale Set (VMSS) configuration specifies:
- Initial instance count: 4
- Minimum number of VMs: 2
- Scale-in threshold: CPU usage below 30% triggers a reduction of 4 VMs
In the given scenario:
- The CPU utilization drops to 25% and stays at this level for 6 minutes.
- This satisfies the scale-in policy, which reduces the number of VMs by 4.
- However, the minimum VM threshold is set to 2, and a scale set cannot scale below the configured minimum limit.
As a result, Scale1 will be running 2 virtual machines after the scale-in process completes.
