## Énoncé et corrigé fourni


An Azure subscription includes a storage account named storageaccount1. The storage account has the following lifecycle management rules configured:
On June 1, you upload the following blobs to storageaccount1:
- File1 is stored in container1 and uses the Hot access tier.
- File2 is stored in container2 and uses the Hot access tier.
True or False:**
`"On June 6, File1 will be stored in the Cool access tier."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because once the file1 is moved to archive after 3 days, the modified date time remains the same. Which means, after 5+ days for Rule 2, it will not be able to move it back to cool tier from archive, as it needs to be rehydrated which cannot be done via a policy.
Reference(s):
- https://learn.microsoft.com/en-us/azure/storage/blobs/archive-rehydrate-overview
