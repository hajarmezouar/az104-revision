Select the answer choice that completes the following statement based on the information presented.
`“If a power outage occurs in the Azure datacenter rack hosting WEBPROD-AS-USE2, the maximum number of virtual machines that could become unavailable will be ______.”`
Réponses:

Explication
`7` is the correct. The exhibit shows that the Availability Set WEBPROD-AS-USE2 is configured with:
- `"platformFaultDomainCount": 2`
Fault domains represent physical server racks in the Azure datacenter. Virtual machines in an Availability Set are distributed across the specified number of fault domains to protect against rack-level failures, such as power or network outages.
If the availability set contains 14 virtual machines and is configured with 2 fault domains, Azure will distribute the VMs as evenly as possible across both fault domains:
- One fault domain will host 7 VMs
- The other fault domain will host 7 VMs
If one server rack (i.e., one fault domain) experiences a power failure, all VMs in that fault domain will be unavailable. Hence, a maximum of 7 virtual machines could be offline in such a scenario.
