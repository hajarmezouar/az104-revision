## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storageacct1234 and two users named User1 and User2.
You assign User1 the role assignments shown below. The assignments indicate that User1 has a Reader role inherited from the resource group scope and a Storage Blob Data Contributor role assigned directly at the storage account level.
Based on these role assignments, which two actions can User1 perform?
Réponses (plusieurs réponses possibles)
☐ Assign roles to User2 for storageacct1234.
**☑** Upload blob data to storageacct1234.
☐ Modify the firewall of storageacct1234.
**☑** View blob data in storageacct1234.
☐ View file shares in storageacct1234.
Explication
`Upload blob data to storageacct1234` is correct because the Storage Blob Data Contributor role is a data-plane role that allows read, write, and delete operations on blob containers and blobs within the storage account.
`View blob data in storageacct1234` is correct because the ability to read blob content is granted by the Storage Blob Data Contributor role. The Reader role alone does not provide data access, but it allows viewing the storage account resource itself in the Azure portal.**
`Assign roles to User2 for storageacct1234` is incorrect because assigning RBAC roles requires Owner or User Access Administrator permissions. Neither the Reader role nor the Storage Blob Data Contributor role includes authorization to assign roles.**
`Modify the firewall of storageacct1234` is incorrect because changing networking or firewall settings is a management-plane operation that requires Contributor, Owner, or specific networking permissions. The Reader role is read-only, and the Storage Blob Data Contributor role applies only to blob data access.**
`View file shares in storageacct1234` is incorrect because Azure Files access is controlled by separate data-plane roles such as Storage File Data SMB Share Reader or Storage File Data SMB Share Contributor. The Storage Blob Data Contributor role applies only to blob storage and does not grant access to file shares.
