## Énoncé et corrigé fourni


You have an Azure virtual machine named VM1 that is running Windows Server 2019. You export VM1 as an Azure Resource Manager template named Template1 and store it in the Azure Resource Manager library.
You then plan to use Template1 to deploy a new virtual machine called VM2.
What can you configure during the deployment of VM2?
Réponses:
☐ administrator username
☐ operating system
**☑** resource group
☐ virtual machine size
Explication
`resource group` is correct because when deploying a virtual machine from a saved Azure Resource Manager (ARM) template, the deployment process prompts you to select or create a resource group. This is a required part of any ARM deployment as the resource group defines the logical container for the resources created.
`administrator username` is incorrect because although it may appear as a parameter in some templates, a saved template from an existing VM typically contains the username already configured and does not prompt for a new one unless manually modified in the template.
`operating system` is incorrect because the OS is defined in the base image used in the original virtual machine and carried forward in the template. You cannot change the OS during deployment from a saved template without editing the template's image reference.
`virtual machine size` is incorrect because while it can be configured in custom templates, deploying from a saved template does not always expose the size as a parameter unless it was explicitly defined that way in the template configuration. Without modification, the size remains the same as that of the source VM.
