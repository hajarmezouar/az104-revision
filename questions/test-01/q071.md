## Énoncé et corrigé fourni


You have an Azure subscription that uses the public IP addresses shown in the following table.
You need to create a public Azure Standard Load Balancer.
Which of the listed public IP addresses can be used for this deployment?
Réponses:
☐ IP2 only
**☑** IP3 only
☐ IP1 and IP3 only
☐ IP1, IP2, and IP3
Explication
`IP3 only` is the correct answer here. Azure Standard Load Balancers require a Standard SKU public IP address with a Static assignment. From the table:
- IP3 has IP version IPv6, SKU Standard, Static assignment, and is zone-redundant. All these characteristics make it eligible to be associated with a Standard Load Balancer.
`IP1` is incorrect because it uses the Basic SKU, which is not compatible with Standard Load Balancers.
`IP2` is incorrect because it also uses the Basic SKU and is dynamically assigned, both of which disqualify it for use with a Standard Load Balancer.
Azure Load Balancers follow strict compatibility rules:
- Standard Load Balancers support only Standard SKU public IPs with Static assignments.
- Basic Load Balancers support only Basic SKU public IPs and allow Dynamic assignment, especially for IPv6, but cannot be used with Standard Load Balancers.
