## Énoncé et corrigé fourni


An Azure subscription contains a storage account named storage1, which includes a blob container called container1.
You need to define a lifecycle management policy for storage1 that automatically moves blobs stored in container1 to the lowest-cost access tier after they have remained unchanged for 90 days.
You are completing the lifecycle management rule shown in the configuration. The rule enables lifecycle management, targets base blobs, applies an action after a specified number of days since modification, and filters the scope of the rule to a specific container.
What should you choose for `Code Segment B`?

**☑** “prefixMatch”: [
Explication
`“prefixMatch”: [` is correct because you need to apply the filter which will look for only the blobs in a specified container, container1 in this case. And PrefixMatch does exactly that, because the full name/address of the blob always includes the name of the container they are stored in.
`blobIndexMatch` is incorrect because we do not need to filter on the index of the blobs. We need to apply this policy for all the blobs in the container. Hence we do not use this.
`blobTypes` is incorrect because again we do not need to filter on the type of the blobs. We need to make all the blobs in container1 to move to the archive tier.
