Each virtual machine has only a private IP address assigned.
You then deploy an Azure Bastion resource with the following configuration:
True or False:
`"The Remote Desktop Connection client (mstsc.exe) can be used to connect to VM1 through Bastion1."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct. The Remote Desktop Connection client (`mstsc.exe`) cannot be used to connect to VM1 through Bastion1 because Bastion1 is deployed using the Basic SKU, and the Basic SKU does not support native client access. Native client access refers to using external tools such as `mstsc.exe` or SSH from a local terminal, rather than the Azure portal's browser-based Bastion session.
To use `mstsc.exe` for RDP access to a virtual machine through Azure Bastion, you must deploy Azure Bastion with the Standard SKU, and explicitly enable the “Native client support” feature. Since the Bastion instance in this scenario uses the Basic tier, the native client feature is not available, and RDP access is only possible through the Azure portal.
