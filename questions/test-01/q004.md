## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- ManagementGroup1: Management group
- RG1: Resource group
- 5e7a2c91-4b3d-4f68-9a21-c8d7e3b5f402: Subscription ID
- Tag1: Tag
You are working in Azure Cloud Shell and need to deploy a virtual machine by using an Azure Resource Manager (ARM) template.
You must complete the shown command to perform the deployment.
What should you choose for Code Segment A?
Réponses:
☐ New-AzVm
☐ New-AzResource
☐ New-AzTemplateSpec
**☑** New-AzResourceGroupDeployment
Explication
New-AzResourceGroupDeployment is correct as we can only deploy the resources via ARM template in powershell when we scope it to a collection in Azure for e.g., a resource group, a subscription or a management group. Although there is no context mentioned in the question, yet among the options, this is the only correct command that can be used during an ARM template deployment.
New-AzVM is incorrect because this command although does create a VM, yet cannot use a template file for the deployment. It uses a VM object with all the parameters you need to define the size, OS and other properties of the new VM.
New-AzResource is incorrect because similar to New-AzVM, this command can be used to create a resource of type VM, but it does not have a parameter where it can take the link of an ARM template to be used for the deployment.
New-AzTemplateSpec is incorrect because creating a templatespec is not going to help in directly creating a VM for you. You would have to manually deploy the VM again in the second step with the templateSpec that you create with this command. Hence this is not the correct answer.
