## Énoncé et corrigé fourni


You have an Azure virtual machine called VM1, and Azure Monitor is set up to capture events from the virtual machine.
You need to configure an alert rule that notifies an administrator whenever an error is recorded in the System event log on VM1.
Which resource should be selected as the target when creating this alert rule?
Réponses:
☐ virtual machine extension
☐ virtual machine
☐ metric alert
**☑** Azure Log Analytics workspace
Explication
`Azure Log Analytics workspace` is the correct answer because when you want to create an alert based on event logs (such as System event log) collected from a virtual machine, those logs are first sent to a Log Analytics workspace via the Azure Monitor agent or Log Analytics agent.
Once the logs are in the workspace, you can query them using Kusto Query Language (KQL) and create log alert rules based on the results — such as triggering an alert when an error is logged in the System event log of VM1.
`virtual machine` is incorrect because you can only use metric-based alerts directly on VMs, not event log-based queries.
`virtual machine extension` is incorrect because extensions are agents that help collect data but are not targets for alerts.
`metric alert` is incorrect because event logs are not metrics. You need a log-based alert, not a metric-based one.
