## Énoncé et corrigé fourni


You have an Azure App Service web app named app1.
Autoscaling is configured to scale based on a metric. The configuration defines instance limits with a minimum of 1 instance, a maximum of 5 instances, and a default of 1 instance.
A scale-out rule is configured as follows:
- When the average CPU percentage exceeds 70%, increase the instance count by 1.
You configure the autoscale rule criteria as shown below. The rule evaluates the CPU Percentage metric from the App Service plan metrics, uses a specified aggregation method and time grain, applies a threshold condition over a defined duration, and performs a scale-out action with a cooldown period.
Based on the information presented in the configuration, select the option that correctly completes the following statement:
"After CPU usage has reached 80 percent for 15 minutes, ____________________ will be running."
Réponses:
☐ 1 instance
**☑** 2 instances
☐ 3 instances
☐ 4 instances
☐ 5 instances
Explication
2 instances is correct because the default count is 1. So it starts with 1 instance. If the CPU usage remains greater than 70% for more than 10 minutes, it increases the count by 1. And then it does not do any scaling operation for the next 5 minutes. So after 15 minutes, we will have 2 instances running.
