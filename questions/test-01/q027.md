## Énoncé et corrigé fourni


An Azure subscription is associated with a Microsoft Entra tenant that includes two users named User1 and User2.
The subscription contains the following Azure resources:
- RG1: A resource group
- VM1: A virtual machine that is created in RG1
The subscription also has the following alert rules configured:
- Alert1: Scoped to RG1 and triggered by all administrative operations
- Alert2: Scoped to VM1 and triggered by all administrative operations
The users perform these actions:
- User1 creates a new virtual disk and attaches the disk to VM1.
- User2 creates a new resource tag and assigns the tag to both RG1 and VM1.
Which alert rule is triggered by User1?
Réponses:
☐ No alert is triggered
☐ Only Alert1 is triggered
☐ Only Alert2 is triggered
**☑** Alert1 and Alert2 are triggered
Explication
`Alert1 and Alert2 are triggered` is correct because these operations are administrative actions. Basically any create/update/delete operation is logged as an admin action in the Activity log which will then trigger these alerts. And the activity by User1 has create operation in RG1 and update operation in VM1.
Reference(s):
- https://learn.microsoft.com/en-us/azure/azure-monitor/essentials/activity-log-schema#administrative-category
