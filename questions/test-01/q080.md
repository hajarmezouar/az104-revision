## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that includes the following resources:
You assign a policy to RG6 as shown in the following table.
Additionally, the following action is performed:
- The tag RGroup: RG6 is applied directly to the resource group RG6.
After the policy assignment and tag configuration, you deploy a new virtual network named VNET2 into RG6.
Which tag(s) apply to VNET2?
Réponses:
☐ None
☐ RGroup: RG6 only
**☑** Label: Value1 only
☐ RGroup: RG6, and Label: Value1
Explication
`Label: Value1 only` is the correct answer here. Azure resources do not automatically inherit tags from their resource group or subscription. While the tag `RGroup: RG6` was manually applied to the resource group RG6, this tag is not automatically passed down to newly created resources within that group.
The only tag that applies to VNET2 is the one enforced through the assigned Azure Policy. The policy uses the Append effect to apply a tag with name `Label` and value `Value1` to all new resources created in RG6. Since VNET2 was deployed after this policy was applied, it receives only the tag defined by the policy.
`None` is incorrect because the policy explicitly appends a tag to any newly created resource in RG6.
`RGroup: RG6 only` is incorrect because tags from the resource group are not automatically inherited by its resources unless explicitly defined by a policy or script.
`RGroup: RG6, and Label: Value1` is incorrect because only the policy-defined tag is applied, and resource group tags are not inherited.
