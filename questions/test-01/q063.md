## Énoncé et corrigé fourni


You have a deployment template named Template1 that provisions 10 Azure web apps.
Before deploying Template1, you need to determine which prerequisite resource must be created in advance. The solution should be designed to keep Azure costs as low as possible.
What should you identify?
Réponses:
☐ one Azure Traffic Manager
☐ one Azure Application Gateway
**☑** one App Service plan
☐ 10 App Service plans
☐ five Azure Application Gateways
Explication
`one App Service plan` is correct because an App Service Plan allows multiple web apps to run within a single plan, sharing the same resources (e.g., CPU, memory). This approach minimizes Azure costs by avoiding the need for separate App Service Plans for each web app. Instead of provisioning separate infrastructure for each app, a single App Service Plan can host multiple apps, as long as they share similar performance and scaling requirements.
`one Azure Traffic Manager` is incorrect because Azure Traffic Manager is a DNS-based load balancer primarily used for global traffic routing across multiple regions. It is not required to host or run Azure Web Apps.
`one Azure Application Gateway` is incorrect because an Application Gateway is a layer 7 load balancer for web traffic routing and SSL offloading. It is useful for managing incoming web traffic but is not a requirement for deploying Azure Web Apps.
`10 App Service plans` is incorrect because deploying 10 separate App Service Plans for 10 web apps is unnecessary and would significantly increase costs. A single App Service Plan can host multiple web apps efficiently.
`five Azure Application Gateways` is incorrect because, similar to one Azure Application Gateway, five instances would be redundant and cost-inefficient for deploying just 10 web apps.

- https://learn.microsoft.com/en-us/azure/app-service/overview-hosting-plans
- https://learn.microsoft.com/en-us/azure/app-service/overview
