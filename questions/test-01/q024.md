## Énoncé et corrigé fourni


An Azure subscription named Sub1 contains the following resources:
- RG1: Resource group
- storage1: Storage account
- VNET1: Virtual network
You assign an Azure Policy with these characteristics:
- The policy is applied at the Sub1 scope.
- An exclusion is configured for Sub1/RG1/VNET1.
- The policy definition appends a tag and its value to resources.
- Policy enforcement is enabled.
- The tag name is Tag4, and the tag value is value4.
You then apply tags to the resources as follows:
- Sub1 has the tag Tag1: subscription.
- RG1 has the tag Tag2: IT.
- storage1 has the tag Tag3: value1.
- VNET1 has the tag Tag3: value2.
True or False:
`"RG1 has the Tag2:IT tag assigned only."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct. If you look at the policy, only VNET1 is excluded. (sub1/RG1/VNET1 is just the path). So, when you add the tag Tag2: IT to RG1 manually, the policy won't trigger for the resource group because policies are applicable to resources and not on resource group.
Therefore, RG1 will only have the Tag2:IT tag assigned.
Reference(s):
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/tag-resources
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/tag-policies
