## Énoncé et corrigé fourni


You create a virtual machine scale set named Scale1.
During deployment, Scale1 is configured with custom autoscaling settings, as shown in the exhibit. The configuration specifies an initial number of instances, minimum and maximum instance limits, and CPU-based scale-out and scale-in rules. In particular, the scale-out rule increases the instance count when average CPU usage exceeds the defined threshold for a specified duration.
Based on the autoscaling configuration shown in the exhibit, complete the following statement:
`“If Scale1 is utilized at 85 percent for six minutes after it is deployed, Scale1 will be running _______________.”`
Réponses:
☐ 2 virtual machines
☐ 4 virtual machines
**☑** 6 virtual machines
☐ 10 virtual machines
☐ 20 virtual machines
Explication
`6 virtual machines` is the correct option because the virtual machine scale set (VMSS) is configured to scale out when CPU utilization exceeds 80% for 5 minutes. In this case:
- The initial number of VMs is 4.
- When the CPU usage crosses 80% for 6 minutes (exceeding the configured threshold of 5 minutes), 2 additional VMs will be added.
- Therefore, the total number of VMs becomes 4 + 2 = 6 VMs.
