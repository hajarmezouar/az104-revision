## Énoncé et corrigé fourni


Your Azure subscription includes an Azure SQL database named DB1.
You plan to use Azure Monitor to collect performance data for DB1. The solution must allow you to run queries against the collected log data for analysis.
Which destination should you select in the Diagnostic settings of DB1 to meet this requirement?
Réponses:
☐ Archive the logs to an Azure Storage account
**☑** Send the logs to a Log Analytics workspace
☐ Stream the logs to an Azure Event Hub
Explication
`Send the logs to a Log Analytics workspace` is correct because Azure Monitor enables querying and analyzing performance data and logs by sending them to a Log Analytics workspace. This allows you to use Kusto Query Language (KQL) to analyze log data and create visualizations in Azure Monitor Workbooks, meeting the requirement to run queries for analyzing log data.
`Archive the logs to an Azure Storage account` is incorrect because it is designed for long-term storage of diagnostic data. While useful for archiving, it doesn't support querying or analyzing log data directly.
`Stream the logs to an Azure Event Hub` is incorrect because it is used for streaming diagnostics data to external systems for real-time processing or integration, not for querying or analyzing log data.
Reference(s):

- https://learn.microsoft.com/en-us/azure/data-factory/monitor-configure-diagnostics
- https://learn.microsoft.com/en-us/azure/active-directory/reports-monitoring/tutorial-azure-monitor-stream-logs-to-event-hub
