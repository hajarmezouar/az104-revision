## Énoncé et corrigé fourni


An Azure subscription contains a storage account named contoso2024. The storage account includes the following resources:
- cont1: Blob container
- share1: File share
The contoso2024 storage account is configured with the settings shown below. The configuration defines the account kind, performance tier, security and access options, minimum TLS version, copy scope, and the default blob access tier.
You also have a Microsoft Entra tenant with the following users, each assigned a Shared Access Signature (SAS) token for contoso2024:
True or False:
`"User2 can access content in cont1."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct. User2 cannot access content in cont1 because the storage account contoso2024 has "Allow storage account key access" set to Disabled. This setting prevents any requests that rely on shared key authorization, including those using Service SAS tokens.
Although User2 has a Service SAS token with maximum available permissions, Service SAS tokens are signed using the storage account key. When shared key access is disabled, these SAS tokens become invalid, regardless of their permissions.
