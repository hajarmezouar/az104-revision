## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1.
You plan to create a blob container named container1 within storage1.
You must configure customer-managed key (CMK) encryption for container1.
Which encryption key should you select?
Réponses:
☐ An elliptic curve (EC) key that uses only the P-384 curve
☐ An elliptic curve (EC) key that uses only the P-521 curve
☐ An elliptic curve (EC) key that uses either the P-384 or P-521 curve
☐ an RSA key with a key size of 4096 only
**☑** an RSA key type with a key size of 2048, 3072, or 4096 only
Explication
`an RSA key type with a key size of 2048, 3072, or 4096 only` is the correct answer because Azure Storage supports customer-managed keys (CMK) for encryption using RSA keys only, and those keys must have a key size of 2048, 3072, or 4096 bits. EC (Elliptic Curve) keys are not supported for encrypting data in Azure Storage with CMK.
`An elliptic curve (EC) key that uses only the P-384 curve` and `An elliptic curve (EC) key that uses either the P-384 or P-521` curve are all incorrect because Azure Storage does not support EC keys for customer-managed encryption.
`an RSA key with a key size of 4096 only` is incorrect because it unnecessarily restricts the valid RSA key sizes. While 4096 is supported, 2048 and 3072 are also valid, and the question does not require the only 4096 constraint.

- https://learn.microsoft.com/en-us/azure/key-vault/keys/about-keys#supported-key-types-and-sizes
