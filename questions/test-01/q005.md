## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- ManagementGroup1: Management group
- RG1: Resource group
- 5e7a2c91-4b3d-4f68-9a21-c8d7e3b5f402: Subscription ID
- Tag1: Tag
You are working in Azure Cloud Shell and need to deploy a virtual machine by using an Azure Resource Manager (ARM) template.
You must complete the shown command to perform the deployment.
What should you choose for Code Segment B?
Réponses:
☐ -Tag Tag1 `
**☑** -ResourceGroupName RG1 `
☐ -GroupName ManagementGroup1 `
☐ -Subscription 8c4be1cd-7655-4c66-63ea-a9ee101d8y75 `
Explication
-ResourceGroupName RG1 is correct because we are using New-AzResourceGroupDeployment as the first part, and that command uses the name of the resource group as the mandatory parameter.
-Tag Tag1, -GroupName ManagementGroup1 and -Subscription 8c4be1cd-7655-4c66-63ea-a9ee101d8y75 are incorrect options because these switches (parameters) are not used with the New-AzResourceGroupDeployment command used for deploying resources to a resource group using an ARM template. Hence we cannot choose these options.
