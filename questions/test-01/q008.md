## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- share1: An Azure file share hosted in storage1
- storage1: An Azure Storage account
- User1: A Microsoft Entra user
You need to assign User1 the Storage File Data SMB Share Contributor role for share1.
What action should you perform first?
Réponses:
☐ Enable identity-based data access for the file shares in storage1.
☐ Update the security configuration for the file shares in storage1.
☐ Set the default authorization method to Microsoft Entra ID in the Azure portal for storage1.
**☑** Configure Access control (IAM) for share1.
Explication
Configure Access control (IAM) for share1 is correct as you can add access for a user from Access control for any type of resource in Azure. For share specific role also you need to go to IAM of the share and then add the respective Azure AD user.
Enable identity-based data access for the file shares in storage1 is incorrect because this is needed when you want a hybrid user to access the share. In that case, you enable access to Active Directory, Azure AD DS and Azure AD Kerberos. But in our case, the user is an Azure AD entity so a RBAC role assignment would be the way to go.
Update the security configuration for the file shares in storage1 is incorrect because security profile of a share has nothing to do with how a user authorizes itself against the share. It has other security features which you can configure for each of your shares.
Set the default authorization method to Microsoft Entra ID in the Azure portal for storage1 is incorrect because this option is not enough to allow user to be able to act as contributor for the share in your storage account.
