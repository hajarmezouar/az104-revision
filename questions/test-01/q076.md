## Énoncé et corrigé fourni


You are preparing to enable backup for an Azure virtual machine named VM1.
During the backup setup process, you notice that the Backup Pre-Check reports a Warning status.
Which of the following situations could explain why the pre-check shows a warning?
Réponses:
☐ VM1 has a disk configuration that does not match the expected requirements.
**☑** VM1 is missing the most recent version of the Azure VM Agent (WaAppAgent.exe).
☐ VM1 is currently in a stopped state.
☐ The associated Recovery Services vault is not available.
Explication
`VM1 is missing the most recent version of the Azure VM Agent (WaAppAgent.exe)` is the correct answer here. When configuring backup for an Azure virtual machine, Azure performs a Backup Pre-Check to validate whether the VM is properly configured for backup. If the Azure VM Agent is outdated or missing, it may not be able to communicate with the backup service properly, which results in a Warning status in the Backup Pre-Check. The agent is essential for snapshot-based backup and must be up to date for backup extensions to function reliably.
`VM1 has a disk configuration that does not match the expected requirements` is incorrect because that condition typically results in a Failed status, not just a warning. Unmatched or unmanaged disks can prevent backup from proceeding altogether.
`VM1 is currently in a stopped state` is incorrect because a stopped VM can still be backed up, and Azure will handle backup at the storage level. Being stopped does not automatically trigger a warning status in Backup Pre-Check.
`The associated Recovery Services vault is not available` is incorrect because that would lead to a critical error or failed status, not a warning. The vault must be available for any backup operation to proceed.
