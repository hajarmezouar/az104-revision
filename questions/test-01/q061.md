## Énoncé et corrigé fourni


You have an Azure App Service plan configured with autoscaling. In the autoscale configuration, the plan uses metric-based scaling with defined scale-out and scale-in rules. The instance limits specify a minimum, maximum, and default number of instances. Scale-out occurs when CPU usage exceeds a configured threshold, and scale-in occurs when
The scale-in settings for the App Service plan are configured as shown in the following exhibit.
The scale out rule is configured with the same duration and cool down tile as the scale in rule.
Based on the information presented, select the answer choice that completes the following statement correctly.
`“If after deployment CPU usage is 70 percent for one hour and then reaches 90 percent for five minutes, at that time the total number of instances will be ________.”`
Réponses:
☐ 1
**☑** 2
☐ 3
☐ 4
☐ 5
Explication
`2` is the correct answer because the scaling conditions are set as follows:
- Scale-out condition: When CPU usage exceeds 85%, the instance count increases by 1.
- Scale-in condition: When CPU usage drops below 30%, the instance count decreases by 1.
- Instance limits: Minimum = 1, Maximum = **5
- Initial State: The default instance count starts at 1.
- First Condition (70% for one hour): This does not trigger a scale-out because it doesn’t exceed the 85% threshold. The instance count remains at 1.
- Second Condition (90% for 5 minutes): This exceeds the 85% threshold, triggering a scale-out by 1 instance.
As a result, after these events, the total number of instances will increase from 1 to 2.
