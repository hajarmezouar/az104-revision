## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VMRG – Resource group
- VNet1 – Virtual network
- VNet2 – Virtual network
- VM5 – Virtual machine connected to VNet1
- VM6 – Virtual machine connected to VNet2
You create an Azure private DNS zone named apexcore.com.
You then link the private DNS zone to VNet2 and enable auto-registration for the virtual network link.
The apexcore.com private DNS zone is configured with existing DNS records, as shown in the below exhibit.
True or False:
`“VM6 can resolve VM9.apexcore.com."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct. VM6 can resolve VM9.apexcore.com because it belongs to VNet2, which is configured as the registration virtual network for the apexcore.com private DNS zone. Since VNet2 is the registration virtual network, it also serves as the resolution virtual network by default, allowing DNS resolution within this virtual network. An A (Host) record for VM9 exists in the DNS zone, enabling VM6 to successfully resolve the domain name VM9.apexcore.com from within VNet2.
