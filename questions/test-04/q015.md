## Énoncé et corrigé fourni


You have an Azure subscription that includes the container images listed below:
- Image1: Built on Windows Server
- Image2: Built on Linux
You plan to deploy containers by using the following Azure services:
- Azure Container Instances
- Azure Container Apps
- Azure App Service
Based on the supported operating systems for each service,  which of the listed Azure services can be used to run Image2?
Réponses:
☐ Azure Container Instances only
☐ Azure Container Apps only
☐ Azure Container Instances and App Services only
☐ Azure Container Apps and App Services only
**☑** Azure Container Instances, Azure Container Apps, and App Services
Explication
`Azure Container Instances, Azure Container Apps, and App Services` is the correct answer because Image2 is based on Linux, and all three services — Azure Container Instances (ACI), Azure Container Apps, and Azure App Service — support Linux-based containers. Therefore, Image2 can run on any of these services.
`Azure Container Instances only` is incorrect because both Azure Container Apps and Azure App Service also support Linux-based containers, making them valid options for running Image2.
`Azure Container Apps only` is incorrect because Azure Container Instances and Azure App Service can also run Linux-based containers, so this option is too restrictive.
`Azure Container Instances and App Services only` is incorrect because Azure Container Apps also supports Linux-based containers, making it another valid option for Image2.
`Azure Container Apps and App Services only` is incorrect because Azure Container Instances is also capable of running Linux-based containers.
