## Énoncé et corrigé fourni


You have an Azure App Service named AppService01 that includes two folders: LogsFolder and TempFolder.
You must configure a daily backup of AppService01, but ensure that TempFolder is excluded from the backup process.
What should you use to exclude TempFolder?
Réponses:
**☑** A _backup.filter file
☐ A backup policy
☐ A lock
☐ A WebJob
Explication
`A _backup.filter file` is the correct answer because, in Azure App Service, you can exclude specific files or directories from a backup by creating a _backup.filter file in the root directory of the app. This file allows you to specify any files or directories that should be excluded from the backup, such as TempFolder.
`A backup policy` is incorrect because Azure App Service does not use backup policies to exclude specific directories. It relies on the _backup.filter file.
`A lock` is incorrect because locks are used to prevent accidental modification or deletion of resources, not to control backup contents.
`A WebJob` is incorrect because WebJobs are used to run background tasks in Azure App Service, not to manage backup configurations or exclusions.
Reference(s):
- https://learn.microsoft.com/en-us/azure/app-service/manage-backup
