## Énoncé et corrigé fourni


You have an Azure web app named webapp1. You also have a virtual network named VNET1 and an Azure virtual machine named VM1 that hosts a MySQL database. VM1 is connected to VNET1.
You must ensure that webapp1 can access the data stored on VM1.
What action should you take?
Réponses:
**☑** Connect webapp1 to VNET1.
☐ Set up an internal load balancer.
☐ Configure virtual network peering between VNET1 and another virtual network.
☐ Deploy an Azure Application Gateway.
Explication
`Connect webapp1 to VNET1` is the correct answer because, to enable direct network communication between the Azure web app (webapp1) and the virtual machine (VM1) hosting the MySQL database, the web app needs to be integrated with the same virtual network (VNET1). This integration allows webapp1 to access VM1 over the private network, ensuring secure and seamless connectivity to the database.
`Set up an internal load balancer` is incorrect because a load balancer manages traffic distribution but does not enable direct network connectivity between web apps and VMs.
`Configure virtual network peering between VNET1 and another virtual network` is incorrect because peering with another virtual network does not directly enable webapp1 to access VM1; webapp1 must be connected to VNET1 itself.
`Deploy an Azure Application Gateway` is incorrect because an Application Gateway manages HTTP/S traffic to web applications, not private connectivity between a web app and a VM in a virtual network.
