## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual network named VNET1 located in the East US 2 region. Two network interfaces, VM1-NI and VM2-NI, are connected to VNET1.
You successfully deploy the following Azure Resource Manager template.
{
"apiVersion": "2017-03-30",
"type": "Microsoft.Compute/virtualMachines",
"name": "VM1",
"zones": "1",
"location": "EastUS2",
"dependsOn": [
"[resourceId('Microsoft.Network/networkInterfaces', 'VM1-NI')]"
],
"properties": {
"hardwareProfile": {
"vmSize": "Standard_A2_v2"
},
"osProfile": {
"computerName": "VM1",
"adminUsername": "AzureAdmin",
"adminPassword": "[parameters('adminPassword')]"
},
"storageProfile": {
"imageReference": "[variables('image')]",
"osDisk": {
"createOption": "FromImage"
}
},
"networkProfile": {
"networkInterfaces": [
{
"id": "[resourceId('Microsoft.Network/networkInterfaces', 'VM1-NI')]"
}
]
}
}
},
{
"apiVersion": "2017-03-30",
"type": "Microsoft.Compute/virtualMachines",
"name": "VM2",
"zones": "2",
"location": "EastUS2",
"dependsOn": [
"[resourceId('Microsoft.Network/networkInterfaces', 'VM2-NI')]"
],
"properties": {
"hardwareProfile": {
"vmSize": "Standard_A2_v2"
},
"osProfile": {
"computerName": "VM2",
"adminUsername": "AzureAdmin",
"adminPassword": "[parameters('adminPassword')]"
},
"storageProfile": {
"imageReference": "[variables('image')]",
"osDisk": {
"createOption": "FromImage"
}
},
"networkProfile": {
"networkInterfaces": [
{
"id": "[resourceId('Microsoft.Network/networkInterfaces', 'VM2-NI')]"
}
]
}
}
}
True or False:
`“If an Azure datacenter becomes unavailable, VM1 or VM2 will be available.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here. In the ARM template, VM1 is assigned to `"zones": "1"` and VM2 to `"zones": "2"`, which places them in separate availability zones within the same Azure region. This configuration ensures that if one datacenter within the region becomes unavailable, the other virtual machine in a different zone remains operational. Azure's availability zones are designed to protect against datacenter-level failures, providing high availability by distributing resources across multiple zones within a region.
Reference(s):
- https://learn.microsoft.com/en-us/azure/reliability/availability-zones-overview?tabs=azure-cli
