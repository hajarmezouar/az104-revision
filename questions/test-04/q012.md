## Énoncé et corrigé fourni


You have two Azure virtual machines running Windows Server, configured as shown below:
You then create a private Azure DNS zone named apexcore.com and configure the zone to allow automatic DNS registration from VNet-A.
Which A record will be automatically created in the apexcore.com private DNS zone for VM-A?
Réponses:
☐ None
**☑** Private IP address only
☐ Public IP address only
☐ Private IP address and public IP address
Explication
`Private IP address only` is the correct answer because when a private Azure DNS zone (such as apexcore.com) is configured for auto-registration in a virtual network (VNet-A), only the private IP addresses of virtual machines in that network are automatically registered in the DNS zone. Public IP addresses are not registered in private DNS zones. Therefore, for VM-A, only the private IP address 10.1.0.4 will be added as an A record in the apexcore.com zone, while the public IP address 52.186.85.63 will not be included.
`None` is incorrect because VM-A is part of VNet-A, and VNet-A is configured for auto-registration in the apexcore.com DNS zone. Therefore, VM1’s private IP address will be registered in the zone.
`Public IP address only` is incorrect because public IP addresses are not registered in private DNS zones. Auto-registration only includes the private IP address.
`Private IP address and public IP address` is incorrect because only the private IP address will be registered in the apexcore.com zone. Public IP addresses are excluded from auto-registration.
