## Énoncé et corrigé fourni


You have an Azure subscription that contains the following App Service plans:
- ASP1 runs on Linux and uses the Basic B1 pricing tier.
- ASP2 runs on Windows and uses the Standard S1 pricing tier.
- ASP3 runs on Linux and uses the Premium v3 pricing tier.
You plan to create an additional App Service plan with these settings:
- Name: ASP4
- Operating system: Windows
- Pricing tier: Premium v3
You need to determine which of the App Service plans support rule-based scale-out.
Which App Service plans should you identify?
Réponses:
☐ ASP4 only
☐ ASP2 and ASP4 only
**☑** ASP2, ASP3, and ASP4 only
☐ ASP1, ASP2, ASP3, and ASP4
Explication
`ASP2, ASP3, and ASP4 only` is correct. The question asks which App Service plans support rule-based scale out, which refers specifically to autoscale—the ability to automatically increase or decrease the number of instances based on predefined rules, such as CPU usage, memory load, or a schedule.
According to Microsoft documentation:
- Autoscale is not supported in the Basic (B1) pricing tier. While Basic plans support manual scale-out (up to 3 instances), they do not support rule-based scaling.
- Standard (S1) and Premium v3 plans do support autoscale, allowing automatic instance management based on defined rules and schedules.
Therefore, ASP2, ASP3, and ASP4 all support rule-based scale out, while ASP1 does not.
