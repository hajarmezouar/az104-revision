## Énoncé et corrigé fourni


You manage two Azure subscriptions: Subscription1 and Subscription2.
In Subscription1, the following resource groups exist:
- RG1 – Region: West Europe – Lock: None
- RG2 – Region: West Europe – Lock: Read-only
The resource group RG1 contains a web application named App1, which is deployed in the West Europe region.
In Subscription2, the following resource groups are configured:
- RG3 – Region: North Europe – Lock: Delete
- RG4 – Region: Central US – Lock: None
True or False:
`“App1 can be moved to RG4.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer because App1 can be moved to RG4, which is located in the Central US region, provided that RG4 does not contain any existing App Service resources such as web apps, App Service plans, or TLS/SSL certificates.
Although App1 is in West Europe, moving an app across resource groups or subscriptions does not change the region of the app. The app retains its original region (West Europe) after the move. The metadata such as resource group or subscription may change, but the physical location of the app stays the same.
There is no lock on RG4, so it won’t block the operation.
Reference(s):
- https://learn.microsoft.com/en-us/azure/app-service/manage-move-across-resources
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/move-support-resources
