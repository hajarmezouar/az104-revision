## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that contains the users listed in the following table, each assigned specific administrative roles.
The tenant also contains the groups as shown in the below table, with different group types and membership configurations.
Self-service password reset (SSPR) must be configured for the tenant.
Which of the listed users are permitted to configure SSPR?
Réponses:
☐ AdminA only
☐ AdminB only
☐ AdminC only
**☑** AdminA and AdminB only
☐ AdminB and AdminC only
☐ AdminA, AdminB, and AdminC
Explication
`AdminA and AdminB only` is correct because in order to configure Self-Service Password Reset (SSPR) in Microsoft Entra, a user must have at least the Authentication Policy Administrator role. In this case, AdminA is the user with the Global Administrator role and AdminA has Authentication Policy Admin role which grant them the necessary permissions to configure SSPR.
`AdminA only` is the incorrect answer because AdminB (Authentication Policy Administrator) also has the required permissions to configure SSPR.
`AdminB only` is incorrect  because AdminA (Global Administrator) also has permissions to configure SSPR, and AdminB cannot be the only one who can configure it.
`AdminC only` is incorrect because neither Authentication Administrator nor Security Administrator roles provide permissions to configure SSPR.
`AdminB and AdminC only` is incorrect because AdminC does not have the required role to configure SSPR. Only AdminA and AdminB have the necessary roles.
`AdminA, AdminB, and AdminC` is incorrect because AdminC does not hold a role that permits configuring SSPR. Only AdminA and AdminB meet the role requirements.

- https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/permissions-reference#authentication-policy-administrator
