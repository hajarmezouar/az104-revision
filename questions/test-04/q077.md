## Énoncé et corrigé fourni


You have an Azure subscription that contains the following App Service plans:
- ASP1 runs on Linux and uses the Basic B1 pricing tier.
- ASP2 runs on Windows and uses the Standard S1 pricing tier.
- ASP3 runs on Linux and uses the Premium v3 pricing tier.
You plan to create an additional App Service plan with these settings:
- Name: ASP4
- Operating system: Windows
- Pricing tier: Premium v3
You need to determine which of the App Service plans support zone redundancy.
Which App Service plans should you identify?
Réponses:
**☑** ASP4 only
☐ ASP2 and ASP4 only
☐ ASP2, ASP3, and ASP4 only
☐ ASP1, ASP2, ASP3, and ASP4
Explication
`ASP4 only` is the correct answer here. Azure App Service supports zone redundancy only on the Premium v2 and Premium v3 pricing tiers. This makes ASP3 and ASP4 eligible, since both are using the Premium v3 tier.
But since the correct combination (ASP3 and ASP4 only) is not available among the answer choices, we need to select the best possible correct option from the list.
Among the choices provided:
- `ASP4 only` is the most accurate, because while it omits ASP3, it is the only option that exclusively lists a supported plan.
Therefore, ASP4 only is the best and most appropriate answer based on the available options.
