## Énoncé et corrigé fourni


You have two Azure subscriptions named Sub1 and Sub2.
In Sub1, there is a virtual machine named VM1 and a storage account named storage1.
The virtual machine VM1 is associated with the following resources:
- Disk1, which is the operating system disk for VM1
- NetInt1, which is the network interface attached to VM1
- VNet1, which is the virtual network that VM1 connects to
You need to move VM1 from Sub1 to Sub2.
Which of the associated resources must you move to Sub2 to complete this task?
Réponses:
☐ VM1, Disk1, and NetInt1 only
☐ VM1, Disk1, and VNet1 only
☐ VM1, Disk1, and storage1 only
**☑** VM1, Disk1, NetInt1, and VNet1
Explication
`VM1, Disk1, NetInt1, and VNet1` is the correct answer here. When you move a virtual machine (VM1) to another subscription, all its associated dependent resources must be moved as well. This includes the OS disk (`Disk1`), the network interface (`NetInt1`), and the virtual network (`VNet1`). Azure requires that all dependent resources are part of the move operation to ensure the VM remains functional in the target subscription. If any dependency, like the NIC or virtual network, is left behind, the VM will lose connectivity or fail validation during the move.
