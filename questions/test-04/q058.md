## Énoncé et corrigé fourni


Your Azure environment contains 20 Windows Server virtual machines, an existing network security group called NSG1, and two virtual networks — VNET1 and VNET2 — that are connected through peering.
You intend to deploy an Azure Bastion host using the Basic SKU into VNET1. To ensure the Bastion service is reachable from external networks, you need to update NSG1 to allow incoming traffic from the internet.
When creating the inbound rule in NSG1, which destination port must be allowed?
Réponses:
☐ 22
**☑** 443
☐ 3389
☐ 8080
Explication
`443` is correct because Azure Bastion uses HTTPS on port 443 for secure communication from the user's browser to the Azure Bastion host. This allows secure RDP or SSH access to virtual machines in the virtual network without exposing these VMs directly to the internet. When deploying Azure Bastion, an inbound rule must be added to the NSG for port 443 to allow this secure connection from the internet to the Bastion host.
`22` is incorrect because port 22 is used for SSH connections, but with Azure Bastion, the communication is tunneled over port 443 via HTTPS, making SSH directly over port 22 unnecessary.
`3389` is incorrect because port 3389 is used for RDP connections. Azure Bastion tunnels RDP sessions over port 443, eliminating the need to open port 3389 in the NSG.
`8080` is incorrect because port 8080 is not used by Azure Bastion for any connection.
