## Énoncé et corrigé fourni


You have an Azure subscription called Subscription1 that includes two virtual machines named VM1 and VM2, both running Windows Server 2016.
VM1 is protected with Azure Backup, configured to run daily backups without using the Azure Backup agent.
VM1 has been compromised by ransomware that encrypts data.
You need to restore data from the most recent backup of VM1.
To which location can you restore the backup?
Réponses:
☐ VM1 only
**☑** VM1 or a new Azure virtual machine only
☐ VM1 and VM2 only
☐ Any Windows computer that has Internet connectivity
Explication
`VM1 or a new Azure virtual machine only` is the correct answer because when Azure Backup is used to back up a VM without using the Azure Backup agent, it performs a full image-level backup of the virtual machine. In the event of data loss (e.g., ransomware), the entire VM can be restored either to the original VM (VM1) or as a new Azure virtual machine from the latest recovery point. This method does not support file-level recovery to arbitrary machines unless the MARS agent is used, which is not applicable in this scenario.
`VM1 only` is incorrect because Azure Backup allows restoring the VM to a new VM as well, not just to the original one.
`VM1 and VM2 only` is incorrect because Azure Backup does not allow restoring a VM backup to a different existing VM like VM2. Restores are limited to the original VM or a new one.
`Any Windows computer that has Internet connectivity` is incorrect because that type of file-level restore is only supported when using the Azure Backup agent (MARS) or the System Center DPM/MABS, which is not being used in this scenario.
