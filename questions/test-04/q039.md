## Énoncé et corrigé fourni


You have an Azure subscription in which a virtual machine scale set is deployed with the following scaling configuration:
- Initial instance count: 2
- Scaling policy: Custom
- Minimum number of instances: 1
- Maximumnumber of  instances: 10
Scale-out settings:
- CPU Threshold: 75%
- Duration in minutes: 10 minutes
- Number of instances to increase by: 1
Scale-in settings:
- CPU Threshold: 25%
- Number of instances to increase by: 1
Based on the configuration provided, select the answer choice that completes the following statement correctly.
“At 10:00 AM, the scale set is running five virtual machine instances, and CPU utilization drops below 15 percent for 60 minutes. How many virtual machine instances will be running at 11:00 AM?”
Réponses:
**☑** 1
☐ 2
☐ 3
☐ 4
Explication
`1` is the correct answer.
Based on this information, at 11:00 AM, there will be 1 virtual machine instance running.
At 10:00 AM, the scale set has five virtual machine instances running, and CPU utilization falls to less than 15% for 60 minutes, which is below the scale-in CPU threshold of 25%. With the default scale-in duration set to 10 minutes, the scale set will evaluate the CPU utilization every 10 minutes during the 60-minute period and determine that it is below the scale-in threshold.
If the CPU utilization remains below 15% continuously for 60 minutes, the autoscale mechanism will evaluate the conditions every 10 minutes. Each time the condition is met, it will decrease the instance count by 1, subject to the minimum instance limit.​
Assuming the minimum number of instances is set to 1, the scaling would proceed as follows:
- 10:10 AM: Decrease to 4 instances
- 10:20 AM: Decrease to 3 instances
- 10:30 AM: Decrease to 2 instances
- 10:40 AM: Decrease to 1 instance
- 10:50 AM: No further decrease (minimum limit reached)
- 11:00 AM: No change​
Therefore, at 11:00 AM, you will have 1 virtual machine instance running.
