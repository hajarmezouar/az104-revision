## Énoncé et corrigé fourni


You have an Azure virtual machine named VM1. You use Azure Backup to create a backup of VM1 called Backup1.
After Backup1 is created, you make the following changes to VM1:
- Change the virtual machine size.
- Copy a file named Budget.xls into a folder named Data.
- Reset the password for the built-in administrator account.
- Attach an additional data disk to the virtual machine.
An administrator then restores VM1 from Backup1 by using the Replace existing restore option.
You need to ensure that all the changes made after the backup are present on VM1 again.
Which action must you perform again?
Réponses:
☐ Attach an additional data disk.
**☑** Copy Budget.xls into the Data folder.
☐ Change the size of VM1.
☐ Reset the password for the built-in administrator account.
Explication
`Copy Budget.xls into the Data folder` is correct because the Replace existing restore option restores the virtual machine disks from the selected recovery point. Any changes made to the contents of the disks after Backup1 was created are reverted. Since the Budget.xls file was copied into the Data folder after the backup was taken, it will not exist after the restore and must be copied again.
`Attach an additional data disk` is incorrect because attaching a data disk is a configuration change to the Azure virtual machine resource itself. The Replace existing restore operation primarily restores the VM disks from the backup recovery point and does not necessarily remove VM-level configuration changes such as attached disk references.
`Change the size of VM1` is incorrect because the VM size is a property of the Azure virtual machine resource and is not part of the disk contents restored from the recovery point. Restoring the VM disks does not typically revert the VM size configuration.
`Reset the password for the built-in administrator account` is incorrect because password reset operations are commonly managed through VM extensions and VM resource configuration rather than through the restored disk contents alone. The Replace existing operation does not necessarily revert these VM-level settings.
