## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- A virtual network named VNET1 deployed in the East US region
- A public IP address named IP1 deployed in the West Europe region
- A route table named RT1 deployed in the North Europe region
You are required to create a network interface named NIC1. The solution must use only existing resources, and no additional Azure resources can be created as part of the process.
In which Azure region can NIC1 be created?
Réponses:
**☑** East US only
☐ East US and West Europe only
☐ East US and North Europe only
☐ East US, West Europe, and North Europe
Explication
`East US only` is the correct answer because network interfaces (NICs) must be created in the same region as the virtual network (VNet) they are associated with. In this case, VNET1 is in the East US region, so NIC1 must also be created in East US to connect to VNET1 without requiring additional resources.
`East US and West Europe only` is incorrect because a NIC must be in the same region as its associated virtual network, and VNET1 is only in East US.
`East US and North Europe only` is incorrect for the same reason. NIC1 cannot be created in North Europe if it needs to connect to VNET1, which is located in East US.
`East US, West Europe, and North Europe` is incorrect because the NIC must be in the same region as the VNet, which is East US in this case.
