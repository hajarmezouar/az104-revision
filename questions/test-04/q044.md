## Énoncé et corrigé fourni


You have a registered DNS domain named apexcore.com. You then create a public Azure DNS zone with the same name (apexcore.com).
You must ensure that any DNS records added to this Azure DNS zone can be successfully resolved by clients on the public internet.
What action should you take?
Réponses:
☐ Update the SOA record in the DNS domain registrar.
☐ Create the SOA record in apexcore.com.
**☑** Update the NS records in the DNS domain registrar.
☐ Create NS records in apexcore.com.
Explication
`Update the NS records in the DNS domain registrar` is the correct answer here. To ensure that records created in the apexcore.com Azure DNS zone are resolvable from the internet, you need to update the NS (Name Server) records in your DNS domain registrar. These records should point to the Azure DNS name servers associated with the apexcore.com zone in Azure. This change directs external DNS queries for apexcore.com to Azure DNS, allowing them to be resolved by the public Azure DNS servers.
`Update the SOA record in the DNS domain registrar` is incorrect because the SOA (Start of Authority) record is managed by Azure DNS, and you do not need to modify it in the domain registrar to enable public resolution.
`Create the SOA record in apexcore.com` is incorrect because the SOA record is automatically created and managed by Azure DNS for the zone. No manual action is needed for this record to enable internet resolvability.
`Create NS records in apexcore.com` is incorrect because NS records within the Azure DNS zone are already created automatically. The critical step is to update the NS records at the DNS domain registrar, not within Azure DNS.
