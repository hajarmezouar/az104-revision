## Énoncé et corrigé fourni


You have an Azure subscription that includes three virtual networks: VNet-A, VNet-B, and VNet-C.
The current peering configuration is as follows:
- VNet-A
- Peered with VNet-B -> Status: Connected -> Gateway transit: Disabled
- Peered with VNet-C -> Status: Connected -> Gateway transit: Disabled
- VNet-B
- Peered with VNet-A -> Status: Connected -> Gateway transit: Disabled
- VNet-C
- Peered with VNet-A -> Status: Connected -> Gateway transit: Disabled
Each peering shows a connected status.
Based on the information shown in the exhibits, complete the following statement by selecting the correct option:
“Traffic originating from VNet-B can be routed to __________.”
Réponses:
**☑** VNet-A only
☐ VNet-C only
☐ VNet-A and VNet-C
Explication
`VNet-A only` is the correct answer because VNet-B has a direct peering connection with VNet-A, which allows routing of packets between these two virtual networks. Since gateway transit is disabled, VNet-B cannot leverage VNet-A as a transit network to reach other networks, such as VNet-C. This configuration restricts communication to only those virtual networks with direct peering links.
`VNet-C only` is incorrect because there is no direct peering connection between VNet-B and VNet-C, and VNet-B cannot route through VNet-A due to the disabled gateway transit.
`VNet-A and VNet-C` is incorrect because, without gateway transit enabled, VNet-B is restricted to direct communication only with VNet-A.

- https://docs.microsoft.com/en-us/azure/vpn-gateway/vpn-gateway-peering-gateway-transit
