## Énoncé et corrigé fourni


You have an Azure subscription that contains the storage account shown in the following exhibit.
Based on the information provided, select the answer choice that completes the following statement correctly.
“The maximum number of additional immutable blob storage policies that can be created for container1 is ________.”
Réponses:
☐ 0
**☑** 1
☐ 2
☐ 4
☐ 5
Explication
`1` is the correct answer because Azure Storage accounts support a maximum of 2 immutable blob storage policies per container. Since there is already 1 immutable blob storage policy configured for container1 (with a time-based retention of 14 days), you can add 1 more to reach the maximum limit of 2.

- https://learn.microsoft.com/en-us/azure/storage/blobs/immutable-storage-overview
