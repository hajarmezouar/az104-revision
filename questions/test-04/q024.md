## Énoncé et corrigé fourni


You have an Azure subscription named ProdSub01. In the subscription, you create an Azure file share named fileshare01. You then generate a shared access signature (SAS) named SASKey01 with the following configuration:
- Allowed services: File
- Allowed resource types: Service, Container, Object
- Allowed permissions: Read, Write, List
- Start date/time: September 1, 2018 at 2:00 PM
- End date/time: September 14, 2018 at 2:00 PM
- Allowed IP addresses: 193.77.134.10 – 193.77.134.50
- Allowed protocols: HTTPS only
- Signing key: key1
Based on this configuration, complete the following statement:
`If on September 10, 2018, you run the net use command on a computer that has an IP address of 193.77.134.50, and you use SASKey01 as the password to connect to fileshare01, you _________________________.”`
Réponses:
☐ will be asked for credentials
**☑** will have no access
☐ will have read, write, and list access
☐ will have read-only access
Explication
`will have no access` is the correct answer here because the net use command relies on the SMB (Server Message Block) protocol, which only supports authentication using the Azure Storage account key for access to Azure File Shares. The SAS token cannot be used for authentication in this context, and attempting to use it will result in an error indicating invalid credentials. Therefore, the user will not gain any access to the file share with the net use command when using the SAS token.
`will be asked for credentials` is incorrect because the SAS token is not valid for SMB authentication, so no prompt for credentials will occur in a way that allows access.
`will have read, write, and list access` is incorrect because, without support for SAS authentication, the SMB protocol cannot grant any permissions in this scenario.
`will have read-only access` is incorrect because the net use command with SAS authentication will not provide any access due to the limitations of the SMB protocol, which requires the storage account key.
