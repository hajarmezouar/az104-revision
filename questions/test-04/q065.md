## Énoncé et corrigé fourni


In an Azure subscription named Subscription1, there is a resource group named RG1.
Inside RG1, two load balancers are deployed:
- LB1 – configured as an internal load balancer
- LB2 – configured as a public load balancer
You need to grant a user named Admin1 the ability to add and configure a backend address pool for LB1 by using backend resources in RG1. The solution must follow the principle of least privilege.
To enable Admin1 to create and configure a backend address pool for LB1, which Azure RBAC role should be assigned?
Réponses:
☐ Contributor role assigned at the LB1 scope
☐ Network Contributor role assigned at the LB1 scope
**☑** Network Contributor role assigned at the RG1 scope
☐ Owner role assigned at the LB1 scope
Explication
`Network Contributor role assigned at the RG1 scope` is correct because adding a backend pool to a load balancer requires permissions not only on the load balancer itself but also on the resources (e.g., virtual machines or virtual machine scale sets) that will be added to the backend pool. The Network Contributor role at the resource group (RG1) level ensures Admin1 has the necessary permissions to manage network resources across RG1, including both the load balancer and the backend pool resources, while still adhering to the principle of least privilege.
`Contributor role assigned at the LB1 scope` is incorrect because this role grants overly broad permissions beyond just managing network resources. It does not align with the principle of least privilege.
`Owner role assigned at the LB1 scope` is incorrect because the Owner role allows full control, including assigning roles, which exceeds the requirements for adding a backend pool.
`Network Contributor role assigned at the LB1 scope` is incorrect because while this role provides permissions to manage the load balancer, it does not include permissions for managing the backend pool's underlying resources (e.g., virtual machines). These additional permissions are required to successfully add resources to the backend pool.
