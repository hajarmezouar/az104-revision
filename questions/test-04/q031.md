## Énoncé et corrigé fourni


You have an Azure subscription that includes the resources listed in the following table.
You need to configure a proximity placement group for ScaleSet01.
Which proximity placement groups should you use?
Réponses:
**☑** PPG-West-01 only
☐ PPG-West-01 and PPG-Central-02 only
☐ PPG-Central-01 only
☐ PPG-West-01, PPG-Central-01, and PPG-Central-02
Explication
`PPG-West-01 only` is the correct answer because a virtual machine scale set can only use a proximity placement group that is located in the same Azure region. Proximity placement groups are used to ensure that compute resources are placed physically close to each other within an Azure datacenter to minimize latency.
In this scenario, ScaleSet01 is located in the West US region. Among the available proximity placement groups, only PPG-West-01 is also located in West US, making it the only valid option.
It is important to note that the proximity placement group and the virtual machine scale set do not need to be in the same resource group. They only need to exist in the same region.
`PPG-West-01 and PPG-Central-02 only` is incorrect because PPG-Central-02 is located in Central US, which does not match the West US** region of ScaleSet01.
`PPG-Central-01 only` is incorrect because PPG-Central-01 is located in Central US, while ScaleSet01 is located in West US. Proximity placement groups must be in the same region as the compute resources that use them.
`PPG-West-01, PPG-Central-01, and PPG-Central-02` is incorrect because only PPG-West-01 is located in the West US region required by ScaleSet01. The other proximity placement groups are located in Central US and therefore cannot be associated with the scale set.
Reference(s):
- https://azure.microsoft.com/en-us/blog/introducing-proximity-placement-groups/
