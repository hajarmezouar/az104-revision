## Énoncé et corrigé fourni


You have an Azure subscription called Subscription1 that includes two virtual machines named VM1 and VM2, both running Windows Server 2016.
VM1 is protected with Azure Backup, configured to run daily backups without using the Azure Backup agent.
VM1 has been compromised by ransomware that encrypts data.
You need to restore data from the most recent backup of VM1.
To which of the following targets can you perform a file-level recovery for VM1?
Réponses:
☐ VM1 only
☐ VM1 or a new Azure virtual machine only
☐ VM1 and VM2 only
☐ A new Azure virtual machine only
**☑** Any Windows computer that has Internet connectivity
Explication
`Any Windows computer that has Internet connectivity` is the correct answer because Azure Backup supports file-level recovery from a VM backup even when the Azure Backup agent is not used. The recovery is performed by downloading and running a script provided by the portal, which mounts the backup snapshot as a virtual drive. This can be done on any supported Windows machine with internet access, allowing files to be copied to any desired location.
Reference(s):
- https://learn.microsoft.com/en-us/azure/backup/backup-azure-restore-files-from-vm
- https://learn.microsoft.com/en-us/azure/backup/backup-azure-vms-introduction
