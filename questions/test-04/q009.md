## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VMRG – Resource group
- VNet1 – Virtual network
- VNet2 – Virtual network
- VM5 – Virtual machine connected to VNet1
- VM6 – Virtual machine connected to VNet2
You create an Azure private DNS zone named apexcore.com.
You then link the private DNS zone to VNet2 and enable auto-registration for the virtual network link.
The apexcore.com private DNS zone is configured with existing DNS records, as shown in the below exhibit.
True or False:
`“The A record for VM5 will be registered automatically in the apexcore.com zone.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer. Azure DNS allows for the automatic registration of virtual machines from one designated virtual network linked to a private DNS zone as the registration network. In this case, VNet2 is set as the registration virtual network for the apexcore.com zone. However, VM5 is part of VNet1, not VNet2. Since VM5 does not belong to the registration virtual network, its DNS record will not be automatically registered in the apexcore.com zone.
Reference(s):
- https://learn.microsoft.com/en-us/azure/dns/private-dns-autoregistration
- https://learn.microsoft.com/en-us/azure/dns/private-dns-overview
