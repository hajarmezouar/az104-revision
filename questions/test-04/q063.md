## Énoncé et corrigé fourni


You have an Azure Storage account named storage1.
You plan to use AzCopy to transfer data into storage1.
You need to determine which storage services within storage1 support data uploads by using AzCopy.
Which storage services should you identify?
Réponses:
☐ file storage only
**☑** blob storage and file storage only
☐ file storage and table storage only
☐ blob storage, table storage, and queue storage only
☐ blob storage, file storage, table storage, and queue storage
Explication
`blob storage and file storage only` is correct because AzCopy supports copying data to Blob storage and File storage, but not Table storage or Queue storage. AzCopy is specifically designed for transferring blob and file data efficiently within and across Azure storage accounts.

https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azcopy-v10?tabs=dnf
