## Énoncé et corrigé fourni


You have two Azure virtual machines named VM1 and VM2, and two Recovery Services vaults named RSV1 and RSV2.
Currently, VM2 is protected by backups stored in RSV1.
You want to configure backups for VM2 by using RSV2 instead.
What action should you perform first?
Réponses:
**☑** From the RSV1 blade, click Backup items and stop the VM2 backup.
☐ From the RSV2 blade, click Backup. From the Backup blade, select the backup for the virtual machine, and then click Backup.
☐ From the VM2 blade, click Disaster recovery, click Replication settings, and then select RSV2 as the Recovery Services vault.
☐ From the RSV1 blade, click Backup Jobs and export the VM2 job.
Explication
`From the RSV1 blade, click Backup items and stop the VM2 backup` is the correct answer because an Azure virtual machine can only be backed up to one Recovery Services vault at a time. To back up VM2 to a different vault (RSV2), you must first stop the existing backup in RSV1. Once the backup is stopped and the backup data is removed, you can reconfigure the backup for VM2 in RSV2.
`From the RSV2 blade, click Backup. From the Backup blade, select the backup for the virtual machine, and then click Backup` is incorrect because you cannot directly configure VM2 to back up in RSV2 without first stopping the existing backup configuration in RSV1.
`From the VM2 blade, click Disaster recovery, click Replication settings, and then select RSV2 as the Recovery Services vault` is incorrect because Disaster Recovery settings are for replicating a VM to another region, not for configuring backup to a Recovery Services vault.
`From the RSV1 blade, click Backup Jobs and export the VM2 job` is incorrect because exporting backup jobs does not change the Recovery Services vault assigned to the virtual machine.
