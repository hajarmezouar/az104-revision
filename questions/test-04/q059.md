## Énoncé et corrigé fourni


You have an Azure subscription that includes a user named User1 and a storage account named storage1.
The storage account contains the following resources:
- A blob container named container1
- A file share named folder1
- A table named Table1
User1 is assigned the following roles on storage1:
- Storage Blob Data Reader
- Storage Table Data Contributor
- Storage File Data SMB Share Contributor
A shared access signature (SAS) named SAS1 is created for storage1 with the configuration shown in the exhibit.
Which of the following resources can User1 write to by using SAS1?
Réponses:
**☑** Table1 only
☐ Table1 and container1 only
☐ folder1 and Table1 only
☐ folder1 and container1 only
☐ Table1, folder1, and container1
Explication
`Table1 only` is correct because the SAS policy shown in the exhibit explicitly grants permissions only for the Table service. This means that when connecting to the storage account using SAS1, the scope of access is restricted to Table-based resources, such as Table1. Other services, such as Blob or File (which include container1 and folder1, respectively), are not included in the SAS policy. Therefore, only Table1 is accessible for all permitted operations, including creating, reading, updating, and deleting (CRUD). Other services will not be visible or accessible when connecting using this SAS key.
