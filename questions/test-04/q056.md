## Énoncé et corrigé fourni


You have an Azure subscription that follows the resource hierarchy shown in the diagram, which includes a Tenant Root Group, ManagementGroup1, Subscription1, a resource group named RG1, and a virtual machine named VM1.
You create an Azure Policy definition named Policy1.
To which Azure resources in this hierarchy can Policy1 be assigned?
Réponses:
☐ Subscription1 and RG1 only
☐ ManagementGroup1 and Subscription1 only
☐ Tenant Root Group, ManagementGroup1, and Subscription1 only
☐ Tenant Root Group, ManagementGroup1, Subscription1, and RG1 only
**☑** Tenant Root Group, ManagementGroup1, Subscription1, RG1, and VM1
Explication
`Tenant Root Group, ManagementGroup1, Subscription1, RG1, and VM1` is correct because Azure Policy definitions can be assigned at any level in the Azure hierarchy, including the tenant root group, management groups, subscriptions,  resource groups, and individual resource.
It should be noted that policy cannot be applied to an individual resource from the Azure Portal, however, it can be done via Azure CLI or PowerShell.
Since the question dosen't specifically state that the policy should be applied using Azure Portal only, we can safely assume  that using CLI/PowerShell, the policy can also be applied to an individual resource (VM1).
