## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
You configure Azure Site Recovery to replicate VM1 from East US to West US.
You then initiate a test failover and choose VNET2 as the destination virtual network.
After the test failover completes, to which subnet in VNET2 will the test instance of VM1 be connected?
Réponses:
☐ RecoverySubnetB
**☑** DemoSubnet1
☐ TestSubnet1
☐ RecoverySubnetA
Explication
`DemoSubnet1` is the correct answer because when performing a test failover in Azure Site Recovery and no matching subnet name exists in the target virtual network (VNET2), the test virtual machine is automatically connected to the first subnet in alphabetical order. In this case, the source subnet is `Subnet2`, which does not exist in VNET2. Among the available subnets in VNET2—DemoSubnet1, RecoverySubnetA, RecoverySubnetB, and TestSubnet1—the one that comes first alphabetically is DemoSubnet1, so the test VM is connected there.
`RecoverySubnetA` is incorrect because although it contains “Recovery” in the name, it comes after DemoSubnet1 alphabetically.
`RecoverySubnetB` is incorrect because it is not the first subnet in alphabetical order and does not match the source subnet name.
`TestSubnet1` is incorrect because ASR does not prioritize subnets based on naming conventions like “Test”. It only looks for an exact match or falls back to the first subnet in alphabetical order.
