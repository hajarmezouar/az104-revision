## Énoncé et corrigé fourni


You have an Azure subscription and intend to deploy multiple Azure Container Instances, defined as follows:
- Instance1: Windows Server 2019 (Nano Server installation)
- Instance2: Windows Server 2019 (Server Core installation)
- Instance3: Linux
- Instance4: Linux
Which of these instances are eligible to be deployed together within the same container group?
Réponses:
☐ Instance1 only
☐ Instance2 only
☐ Instance1 and Instance2 only
**☑** Instance3 and Instance4 only
Explication
`Instance3 and Instance4 only` is correct because Azure Container Instances (ACI) currently supports multi-container groups only for Linux containers. This means you can deploy multiple Linux-based containers (such as Instance3 and Instance4) together within a single container group that shares networking, storage volumes, and lifecycle.
Instance1 and Instance2 are Windows-based containers (Nano Server and Server Core). Azure Container Instances does not support deploying multiple Windows containers in a group. Windows containers can only be deployed as single-container instances. Therefore, even though both are Windows-based, they cannot be combined into a container group.
Instance1 only, Instance2 only, and Instance1 and Instance2 only are incorrect because these configurations would either use Windows containers (unsupported for container groups) or fail to meet the definition of a multi-container group.

- https://learn.microsoft.com/en-us/azure/container-instances/container-instances-container-groups
