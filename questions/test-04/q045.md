## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual network named VNet1. VNet1 is connected to two separate on-premises datacenters by using two ExpressRoute circuits.
You need to build a dashboard that provides in-depth network metrics and a graphical view of the network topology.
Which Azure service should you use?
Réponses:
☐ Azure Virtual Network Watcher
**☑** Azure Monitor Network Insights
☐ a Data Collection Rule (DCR)
☐ Log Analytics
Explication
`Azure Monitor Network Insights` is the correct answer here. Azure Monitor Network Insights provides a comprehensive view of your network’s health and performance. It includes detailed metrics, visualizations, and insights into the network topology, making it ideal for monitoring complex environments like the one described with multiple ExpressRoute circuits.
`Azure Virtual Network Watcher` is incorrect because, while it offers some monitoring and diagnostic tools for network resources, it does not provide an all-encompassing dashboard or a visual representation of network topology as effectively as Network Insights.
`A Data Collection Rule (DCR)` is incorrect because DCRs are primarily used to define data collection and ingestion rules for Azure Monitor. They do not provide a visual representation of network topology or a network-specific dashboard.
`Log Analytics` is incorrect because it is a tool for querying and analyzing logs. While you can use Log Analytics to query network data, it does not provide a pre-built dashboard or topology visualization as Network Insights does.
