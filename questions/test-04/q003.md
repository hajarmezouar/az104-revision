## Énoncé et corrigé fourni


You have an Azure subscription that includes three virtual networks: VNet-A, VNet-B, and VNet-C.
The current peering configuration is as follows:
- VNet-A
- Peered with VNet-B -> Status: Connected -> Gateway transit: Disabled
- Peered with VNet-C -> Status: Connected -> Gateway transit: Disabled
- VNet-B
- Peered with VNet-A -> Status: Connected -> Gateway transit: Disabled
- VNet-C
- Peered with VNet-A -> Status: Connected -> Gateway transit: Disabled
Each peering shows a connected status.
Based on the information shown in the exhibits, complete the following statement by selecting the correct option:
“Traffic originating from VNET-A can be routed to __________.”
Réponses:
☐ VNet-B only
☐ VNet-C only
**☑** VNet-B and VNet-C
Explication
`VNet-B and VNet-C` is the correct answer because VNet-A has peering connections established with both VNet-B and VNet-C. This setup allows packets from VNet-A to be routed directly to both VNet-B and VNet-C through the peering connections. The peering status is connected, and no additional configurations are needed since the gateway transit is disabled for all peering links, which does not impact routing between the peered networks.
`VNET-B only` is incorrect because packets can also be routed to VNet-C due to the established peering connection between VNet-A and VNet-C.
`VNET-C only` is incorrect because packets can also be routed to VNet-B due to the established peering connection between VNet-A and VNet-B.
