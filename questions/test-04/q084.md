## Énoncé et corrigé fourni


You have an Azure subscription that contains a virtual machine named VM1.
The virtual machine has two disks attached:
- An operating system disk named Disk1
- A data disk named Disk2
You are required to back up only Disk2 by using Azure Backup.
Which three actions should you perform in sequence?
ACTIONS
- Create a backup policy and configure the backup.
- Create a Recovery Services vault.
- Create an Azure Backup vault.
- Configure a managed identity.
- Delegate permissions for the vault.
Réponses:
☐ 1-3-4
☐ 4-3-1
**☑** 3-1-4
☐ 2-1-4
☐ 4-2-1
Explication
`3-1-4` is the correct sequence of actions.
`(Action 3)` Create an Azure Backup vault is correct. For Azure Disk Backup (as opposed to full VM backup), you use an Azure Backup vault, which is a specific vault type designed for backing up individual managed disks. This is different from a Recovery Services vault, which is used for broader scenarios like VM, SQL, and file backups.
`(Action 1)` Create a backup policy and configure the backup is correct. After the vault is created, you define a backup policy that dictates the schedule and retention for the disk backup. You then associate Disk2 with this policy.
`(Action 4)` Configure a managed identity is correct. Azure Disk Backup uses Azure RBAC and managed identities for access. You must configure a user-assigned managed identity with appropriate roles (like `Disk Backup Reader`) to allow the vault to access and back up Disk2.
`(Action 2)` Create a Recovery Services vault is incorrect. This is used for VM-level backup and is not applicable to Azure Disk Backup, which requires a Backup vault.
`(Action 5)` Delegate permissions for the vault is incorrect. Disk Backup uses managed identity and RBAC instead of manual permission delegation. You assign roles to the managed identity instead of explicitly delegating permissions.
