## Énoncé et corrigé fourni


You have an Azure subscription with a virtual network named VNet1.
VNet1 includes four subnets named Gateway, Perimeter, NVA, and Production.
The NVA subnet hosts two network virtual appliances (NVAs).
These NVAs are used to inspect network traffic flowing between the Perimeter subnet and the Production subnet.
You need to deploy an Azure Load Balancer in front of the NVAs.
The solution must meet the following conditions:
- The NVAs must operate in an active-active setup with automatic failover.
- Traffic must be load balanced to two different services in the Production subnet, and each service uses a different IP address.
Which three actions should you take?
Réponses (plusieurs réponses possibles)
**☑** Add a frontend IP configuration, two backend pools, and a health probe
☐ Add a frontend IP configuration, a backend pool, and a health probe
☐ Deploy a basic load balancer
**☑** Deploy a standard load balancer
☐ Add two load balancing rules that have HA Ports enabled and Floating IP disabled
**☑** Add two load balancing rules that have HA Ports and Floating IP enabled
Explication
`Add a frontend IP configuration, two backend pools, and a health probe` is correct because the requirement involves load balancing traffic to two services on different IP addresses in the Production subnet. This necessitates two separate backend pools, each associated with one of the services. A frontend IP configuration is needed to receive incoming traffic, and a health probe is essential to determine the availability of the NVAs in the backend pool for failover.
`Deploy a standard load balancer` is correct because only the Standard SKU load balancer supports advanced features like HA Ports, Floating IP, and availability zones, all of which are needed for this high availability active-active NVA setup. The Basic SKU does not support multiple backend pools or advanced configurations required in this scenario.
`Add two load balancing rules that have HA Ports and Floating IP enabled` is correct because:
- HA Ports allows the load balancer to listen on all ports for the services, ensuring full connectivity through the NVAs.
- Floating IP (also known as Direct Server Return) must be enabled for scenarios that involve high availability and active-active NVAs, because it ensures the return path of packets doesn't interfere with source NAT.
`Add a frontend IP configuration, a backend pool, and a health probe` is incorrect because a single backend pool cannot load balance traffic to two distinct IP addresses (services). This setup lacks the isolation needed for managing traffic across both services.
`Deploy a basic load balancer` is incorrect because Basic SKU does not support HA Ports or multiple backend pools, which are essential for this solution.
`Add two load balancing rules that have HA Ports enabled and Floating IP disabled` is incorrect because disabling Floating IP prevents the correct routing behavior necessary for high availability and direct server return, which is needed in an active-active NVA configuration.
