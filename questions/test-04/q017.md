## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that contains the users listed in the following table, each assigned specific administrative roles.
The tenant also contains the groups as shown in the below table, with different group types and membership configurations.
Self-service password reset (SSPR) must be configured for the tenant.
For which group can SSPR be enabled?
Réponses:
☐ SecGroup only
☐ M365Group only
**☑** SecGroup or M365Group only
☐ SecGroup or MailSecGroup only
☐ SecGroup, M365Group, or MailSecGroup
Explication
`SecGroup or M365Group only` is the correct answer because Self-Service Password Reset (SSPR) can be enabled for security groups and Microsoft 365 groups. SecGroup is a Security group, and M365Group is a Microsoft 365 group, both of which are supported for SSPR.
`MailSecGrou` is a Mail-enabled security group, which does not support SSPR.

- https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks
- https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr#enable-self-service-password-reset
