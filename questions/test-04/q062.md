## Énoncé et corrigé fourni


You have an Azure subscription that includes the storage accounts listed below:
- storage1: StorageV2 with geo-zone-redundant storage (GZRS)
- storage2: BlobStorage with read-access geo-redundant storage (RA-GRS)
- storage3: BlockBlobStorage with zone-redundant storage (ZRS)
You need to determine which of these storage accounts support moving blob data to the Archive access tier.
Which storage accounts satisfy this requirement?
Réponses:
☐ storage1 only
**☑** storage2 only
☐ storage1 and storage3 only
☐ storage2 and storage3 only
☐ storage1, storage2, and storage3
Explication
`storage2 only` is correct because only storage accounts configured with LRS (Locally Redundant Storage), GRS (Geo-Redundant Storage), or RA-GRS (Read-Access Geo-Redundant Storage) support moving blob data to the Archive access tier.
`storage1` is incorrect because it is a StorageV2 account configured with GZRS (Geo-Zone-Redundant Storage), which does not support the Archive access tier.
`storage3` is incorrect because it is a BlockBlobStorage account configured with ZRS (Zone-Redundant Storage), which does not support the Archive access tier.
Reference(s):
https://learn.microsoft.com/en-us/azure/storage/blobs/access-tiers-overview
