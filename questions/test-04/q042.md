## Énoncé et corrigé fourni


You have an Azure environment that includes a virtual network named VNet1. The virtual machines deployed in VNet1 are configured to allow Remote Desktop access.
Several users will be working from home and must securely connect to these virtual machines over the internet. You are required to implement Point-to-Site (P2S) VPN connectivity so that each user can establish a private connection to the virtual network.
Which three actions should you perform in sequence?
ACTIONS
- Provision a local network gateway resource.
- Configure a public IP address for each virtual machine.
- Create an additional subnet within VNet1.
- Add an IP address pool.
- Deploy a load balancer to VNet1.
- Deploy a VPN gateway for the virtual network.

Explication
`(Action 3) Create an additional subnet within VNet1` – A specific subnet is needed for the VPN gateway within VNet1. This subnet is usually named the GatewaySubnet and is required to deploy the VPN gateway for a Point-to-Site (P2S) VPN connection.
`(Action 6) Create a VPN gateway` – After the subnet is created, you need to deploy a VPN gateway in VNet1. The VPN gateway provides the Point-to-Site (P2S) VPN functionality, allowing users to securely connect to the virtual network from a remote location.**
`(Action 4) Add an IP address pool` – Once the VPN gateway is set up, you configure an IP address pool. This pool assigns IP addresses to users who connect through the P2S VPN, ensuring they can connect to resources within VNet1.**
`(Action 1) Provision a local network gateway resource` is incorrect  because a local network gateway is used for Site-to-Site (S2S) VPN connections to represent the on-premises VPN device, not for Point-to-Site connections.**
`(Action 2) Configure a public IP address for each virtual machine` is incorrect  because with a P2S VPN, users can securely connect to the VMs over the VPN without needing public IPs on each VM, enhancing security.**
`(Action 5) Deploy a load balancer to VNet1` is incorrect because a load balancer is not required for P2S VPN connectivity. It’s typically used for distributing traffic across multiple VMs.
