## Énoncé et corrigé fourni


You have an Azure subscription that includes 10 virtual machines running Windows Server. Each VM hosts a website using IIS, and the Azure Monitor Agent is already installed on all machines.
Your objective is to collect IIS log files from each virtual machine and store them in a Log Analytics workspace.
What should you configure as the initial step?
Réponses:
☐ a private endpoint
**☑** Diagnostic settings
☐ a data collection endpoint
☐ VM insights
☐ an Azure Monitor Private Link Scope (AMPLS)
Explication
`Diagnostic settings` is the correct answer because Diagnostic settings in Azure allow you to specify which logs and metrics should be collected from your virtual machines and where they should be sent, such as a Log Analytics workspace. To collect IIS logs from each virtual machine and store them in a Log Analytics workspace, you must configure Diagnostic settings on each virtual machine to enable and route IIS log data appropriately.
`a private endpoint` is incorrect because private endpoints are used to provide private access to Azure services via a private IP address, which is unrelated to configuring IIS log collection.
`a data collection endpoint` is incorrect because a Data Collection Endpoint (DCE) is only needed if Azure Monitor Private Links are in use, which is not specified in this scenario.
`VM insights` is incorrect because VM insights focuses on performance monitoring and dependency mapping for virtual machines. It does not handle IIS log collection and routing to a Log Analytics workspace.
`an Azure Monitor Private Link Scope (AMPLS)` is incorrect because AMPLS enables private access to Azure Monitor resources using Private Links. It is not a requirement for IIS log collection in this context.
Reference(s):
- https://learn.microsoft.com/en-us/azure/azure-monitor/essentials/diagnostic-settings
- https://learn.microsoft.com/en-us/azure/azure-monitor/agents/data-collection-iis
