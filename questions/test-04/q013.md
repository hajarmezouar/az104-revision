## Énoncé et corrigé fourni


You have two Azure virtual machines running Windows Server, configured as shown below:
You then create a private Azure DNS zone named apexcore.com and configure the zone to allow automatic DNS registration from VNet-A.
Which A record will be automatically created in the apexcore.com private DNS zone for VM-B?
Réponses:
☐ None
**☑** Private IP address only
☐ Public IP address only
☐ Private IP address and public IP address
Explication
`Private IP address only` is the correct answer because in Azure private DNS zones, DNS records are created based on the Virtual network links to the VNet rather than the DNS suffix configured on the VM itself. Since VNet-A is linked to the adatum.com private DNS zone and auto-registration is enabled, VM-B’s private IP address (10.1.0.5) will be automatically registered in the apexcore.com zone despite its DNS suffix being set to ironclad.com.
`None` is incorrect because the DNS name configured on the VM does not impact auto-registration; as long as the VNet is linked, VM-B’s private IP will be registered.
`Public IP address only` is incorrect because Azure private DNS zones do not register public IP addresses; they register only private IP addresses.
`Private IP address and public IP address` is incorrect because Azure private DNS zones only register private IP addresses, not public ones.
