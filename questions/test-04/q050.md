## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that contains the groups listed below, each with a specific group type and security setting.
- Group1 - Security group (Security enabled: Yes)
- Group2 - Mail-enabled security group (Security enabled: Yes)
- Group3 - Microsoft 365 group (Security enabled: Yes)
- Group4 - Microsoft 365 group (Security enabled: No)
You purchase Microsoft Entra ID P2 licenses and want to assign the licenses by using group-based licensing.
To which groups can you assign a license?
Réponses:
☐ Group1 only
☐ Group1 and Group3 only
☐ Group3 and Group4 only
**☑** Group1, Group2, and Group3 only
☐ Group1, Group2, Group3, and Group4
Explication
Group1, Group2, and Group3 only is correct because group-based licensing in Microsoft Entra ID supports security groups (including mail-enabled security groups) and Microsoft 365 groups that have securityEnabled=TRUE.
- Group1 is a security group with security enabled, so it can be used.
- Group2 is a mail-enabled security group, which is still a type of security group, and Microsoft documentation confirms that it is supported for license assignment.
- Group3 is a Microsoft 365 group with security enabled, so it also qualifies.
Group1 only is incorrect because Group3 (a security-enabled Microsoft 365 group) and Group2 (a mail-enabled security group) are also supported.
Group1 and Group3 only is incorrect because Group2 is also eligible for license assignment, as mail-enabled security groups are supported.
Group3 and Group4 only is incorrect because Group4 is a Microsoft 365 group with security disabled, making it ineligible.
Group1, Group2, Group3, and Group4 is incorrect because Group4 is security-disabled and cannot be used for license assignment.
Reference(s):
- https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-group-licenses?view=o365-worldwide
- https://learn.microsoft.com/en-us/microsoft-365/admin/create-groups/compare-groups?view=o365-worldwide
