True or False:
`“Users who are assigned Role1 are able to deploy new virtual machines.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here.
Although `Microsoft.Compute/virtualMachines/*` alone is not always sufficient to deploy a new virtual machine, Role1 includes all the additional permissions required to create a VM and its associated resources.
The role grants the following key permissions:
- `Microsoft.Compute/virtualMachines/*` – Allows all operations on virtual machines, including creating (`write`), updating, deleting, starting, stopping, restarting, and deallocating VMs.
- `Microsoft.Compute/disks/*` – Allows creation and management of managed disks required by the VM.
- `Microsoft.Network/networkInterfaces/*` – Allows creation and management of network interfaces.
- `Microsoft.Network/virtualNetworks/subnets/join/action` – Allows the network interface to be attached to a subnet.
- `Microsoft.Resources/deployments/*` – Allows ARM template deployments, which are commonly used when deploying virtual machines.
Because Role1 includes permissions for both the virtual machine and its dependent resources, users assigned this role can successfully deploy new virtual machines.
The `notActions` section only prevents users from modifying Azure RBAC role assignments or elevating their own permissions. It does not restrict virtual machine deployment.
