## Énoncé et corrigé fourni


You manage two Azure subscriptions: Subscription1 and Subscription2.
In Subscription1, the following resource groups exist:
- RG1 – Region: West Europe – Lock: None
- RG2 – Region: West Europe – Lock: Read-only
The resource group RG1 contains a web application named App1, which is deployed in the West Europe region.
In Subscription2, the following resource groups are configured:
- RG3 – Region: North Europe – Lock: Delete
- RG4 – Region: Central US – Lock: None
True or False:
`“App1 can be moved to RG2.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because RG2 has a `Read Only` lock applied. When a resource group is locked with `Read Only`, you cannot add or move any resources into it. This type of lock prevents all write operations, including the action of moving a resource (such as App1) into the locked resource group. Even though App1 and RG2 are in the same region and subscription, the lock on RG2 blocks the move.

- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/lock-resources?tabs=json
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/move-resource-group-and-subscription
