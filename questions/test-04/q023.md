## Énoncé et corrigé fourni


You have an Azure subscription named ProdSub01. In the subscription, you create an Azure file share named fileshare01. You then generate a shared access signature (SAS) named SASKey01 with the following configuration:
- Allowed services: File
- Allowed resource types: Service, Container, Object
- Allowed permissions: Read, Write, List
- Start date/time: September 1, 2018 at 2:00 PM
- End date/time: September 14, 2018 at 2:00 PM
- Allowed IP addresses: 193.77.134.10 – 193.77.134.50
- Allowed protocols: HTTPS only
- Signing key: key1
Based on this configuration, complete the following statement:
`“If on September 2, 2018, you use Microsoft Azure Storage Explorer from a computer with the IP address 193.77.134.1, and connect to the storage account using SASKey01, you __________.”`
Réponses:
☐ will be asked for credentials
**☑** will have no access
☐ will have read, write, and list access
☐ will have read-only access
Explication
`will have no access` is the correct answer because, as given, the SAS (Shared Access Signature) restricts access to IP addresses within the range 193.77.134.10 to 193.77.134.50. Although the date of September 2, 2018 is within the permitted time period (2018-09-01 2:00 PM to 2018-09-14 2:00 PM), the IP address 193.77.134.1 does not fall within the specified IP address range, resulting in no access to the storage account.
`will be asked for credentials` is incorrect because SAS tokens provide access based on the permissions and restrictions defined in the token itself, without requiring additional credentials.
`will have read, write, and list access` is incorrect because, while these permissions are specified in the SAS, the IP address restriction prevents any access.
`will have read-only access` is incorrect because the IP address falls outside the permitted range, so access will not be granted regardless of the permissions.
