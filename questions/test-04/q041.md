## Énoncé et corrigé fourni


You have an Azure subscription containing the following storage accounts:
- storage1 - General-purpose v2 (StorageV2), located in Central US
- storage2 - BlobStorage, located in West US
- storage3 - BlockBlobStorage, located in West US
- storage4 - FileStorage, located in East US
You deploy a web application named App1 to the West US region. You must configure a backup solution for App1 while minimizing costs.
Which storage account should you choose as the backup target?
Réponses:
☐ storage1
**☑** storage2
☐ storage3
☐ storage4
Explication
`storage2` is the correct answer here. This storage account is of the BlobStorage type and is located in the West US region, the same region as the web app, App1. Azure Backup uses block blobs to store backup data, making BlobStorage an appropriate type for this purpose. Additionally, placing backup data in the same region as the resource being backed up minimizes latency and avoids additional costs associated with cross-region data transfers.
`storage1` is incorrect because it is located in Central US, a different region than the web app’s region (West US). While StorageV2 can also be used for backup, cross-region data transfers can lead to increased latency and additional costs, making it less ideal.
`storage3` is incorrect despite being in the same region as App1 (West US). Although it is of the BlockBlobStorage type, which supports block blobs, it is generally more expensive than BlobStorage or StorageV2, due to its premium performance characteristics. Given the requirement to minimize costs, BlockBlobStorage is not the optimal choice.
`storage4` is incorrect as it is of the FileStorage type, which is intended for Azure File Shares rather than backups. Furthermore, it is located in East US, which is a different region from the web app, leading to potential additional latency and transfer costs.
