## Énoncé et corrigé fourni


You have an Azure Load Balancer named LB1.
A user named User1 has the following role assignments:
- User Access Administrator assigned at the scope of LB1
- Virtual Machine Contributor assigned at the resource group level that contains LB1 (this assignment is inherited by LB1)
Based on these role assignments and their scopes, select the answer choice that completes the following statement correctly.
`“User 1 can __________________________.”`
Réponses:
☐ delete LB1
☐ create a NAT rule for LB1
**☑** assign access permissions to other users for LB1
Explication
`assign access permissions to other users for LB1` is the correct answer here. User1 has been assigned the User Access Administrator role on the specific resource, LB1. The User Access Administrator role allows User1 to manage access for other users on that resource, including assigning roles and permissions. This role provides the capability to delegate access without providing permissions to modify the resource itself.
`delete LB1` is incorrect because User1 does not have the Owner or Contributor role, which are required to delete resources in Azure. The assigned roles of User Access Administrator and Virtual Machine Contributor (at the resource group level) do not provide delete permissions for the Load Balancer.
`create a NAT rule for LB1` is incorrect because configuring or modifying NAT rules on a load balancer requires the Network Contributor or Load Balancer Contributor role. The User Access Administrator role does not allow User1 to configure or modify network settings, and the Virtual Machine Contributor role (inherited at the resource group level) also does not include permissions for network configurations.
