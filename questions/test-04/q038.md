## Énoncé et corrigé fourni


You have an Azure subscription in which a virtual machine scale set is deployed with the following scaling configuration:
- Initial instance count: 2
- Scaling policy: Custom
- Minimum number of instances: 1
- Maximumnumber of  instances: 10
Scale-out settings:
- CPU Threshold: 75%
- Duration in minutes: 10 minutes
- Number of instances to increase by: 1
Scale-in settings:
- CPU Threshold: 25%
- Number of instances to increase by: 1
Based on the configuration provided, select the answer choice that completes the following statement correctly.
“At 9:00 AM, the virtual machine scale set starts running, and CPU utilization remains at 90 percent for 15 minutes. How many virtual machine instances will be running at 9:15 AM?”
Réponses:
☐ 2
**☑** 3
☐ 4
☐ 5
Explication
`3` is the correct answer here. Given that the CPU utilization is 90% for 15 minutes, which is above the scale-out threshold of 75%, the scale set will evaluate this sustained high CPU usage after the 10-minute duration set for scale-out. Since the threshold has been exceeded, the scale set will add 1 instance as specified in the "Number of instances to increase by" setting. Therefore, starting with two instances at 9:00 AM, the scale set will have three instances running by 9:15 AM.
