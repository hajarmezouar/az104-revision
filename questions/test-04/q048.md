## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that contains a resource group with the following characteristics:
- Name: RG1
- Region: West US
- Tags: `"tag1": "value1"`
You assign an Azure Policy named Policy1 at the Subscription1 scope with these settings:
- Exclusions: None
- Policy definition: Append a tag and its value to resources
- Assignment name: Policy1
- Parameters:
- Tag name: tag2
- Tag value: value2
After assigning Policy1, you create a storage account with the following properties:
- Name: storage1
- Region: West US
- Resource group: RG1
- Tags: `"tag3": "value3"`
Which tags are applied to RG1?
Réponses:
**☑** "tag1" : "value1" only
☐ "tag2" : "value2" only
☐ "tag1" : "value1" and "tag2" : "value2"
Explication
`"tag1" : "value1" only` is the correct answer here. The policy definition "Append a tag and its value to resources" is configured to apply to resources within Subscription1, not to the resource group RG1 itself. This policy assignment means that any new resources created under Subscription1 will have the specified tag2 : value2 appended if they do not already have this tag. However, it does not apply the tag to the resource group where the resources are created. Therefore, RG1 retains only the original tag, "tag1" : "value1". It should also be noted here that “Subscription” and “Policy1” are created at the initial stage itself and therefore the created policy would apply to the resource group – namely “RG1” within this subscription.
`"tag2" : "value2" only` is incorrect because Policy1 does not add tag2 : value2 to the resource group itself, only to resources created within the scope of Subscription1.
`"tag1" : "value1" and "tag2" : "value2"` is incorrect because, as explained, Policy1 does not alter tags on the resource group RG1 directly. It only affects newly created resources within Subscription1.

- https://docs.microsoft.com/en-us/azure/azure-resource-manager/management/tag-policies
- https://docs.microsoft.com/en-us/azure/governance/policy/concepts/effects#append
