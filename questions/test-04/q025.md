## Énoncé et corrigé fourni


You have an Azure subscription and plan to create a new Azure Storage account. You must configure encryption for the storage account and ensure that the solution meets the following criteria:
- Encryption must use a customer-managed key stored in an Azure Key Vault.
- The key must use the highest supported bit length.
Which type of encryption key should you select?
Réponses:
☐ AES
☐ 3DES
**☑** RSA
Explication
`RSA` is the correct answer here because when using customer-managed keys with Azure Storage, the service supports RSA keys for encryption stored in Azure Key Vault. For Azure Storage encryption, RSA keys support the maximum bit length of 4096 bits, which is currently the highest supported bit length in Azure Key Vault for customer-managed keys.
`AES` is incorrect because, while AES is commonly used for encryption, Azure Key Vault only supports RSA for customer-managed keys in this context. AES is not an option for customer-managed keys stored in Azure Key Vault.
`3DES` is incorrect because 3DES (Triple DES) is an older encryption standard and is not supported for customer-managed keys in Azure Key Vault. Azure Key Vault supports RSA keys for customer-managed storage account encryption.

- https://docs.microsoft.com/en-us/azure/storage/common/storage-service-encryption
- https://learn.microsoft.com/en-us/azure/storage/common/customer-managed-keys-overview
- https://learn.microsoft.com/en-us/azure/key-vault/keys/about-keys
