## Énoncé et corrigé fourni


You have several virtual networks in your Azure environment. The peering settings for vNET6 are configured as follows:
- A peering connection Peering1 to vNET1 exists, but its Peering status is Disconnected and Gateway transit is Enabled.
- A peering connection Peering2 to vNET2 exists, but its Peering status is Disconnected and Gateway transit is Disabled.
Based on this configuration, complete the statement:
“Virtual machines hosted in vNET6 are able to communicate with virtual machines hosted in ____________________.”
Réponses:
**☑** vNET6 only
☐ vNET6 and vNET1 only
☐ vNET6, vNET1, and vNET2 only
☐ all the virtual networks in the subscription
Explication
`vNET6 only` is correct because the peering status for vNET6 with both vNET1 and vNET2 is mentioned as Disconnected. This means there is no active peering connection between vNET6 and any other virtual network. As a result, hosts on vNET6 can only communicate within vNET6 itself and cannot reach vNET1, vNET2, or any other virtual network in the subscription.
