## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual machine named VM1.
You plan to attach a 1 TB data disk to VM1. The disk must meet the following requirements:
- It must remain available if an entire datacenter becomes unavailable.
- It must deliver the lowest possible latency and the highest performance.
- It must prevent data loss in the event that the host fails.
Which host caching would you recommend?
Réponses:
☐ None
**☑** Read-only
☐ Read/Write
Explication
`Read-only `is correct because it provides a balance between performance and data durability. Enabling Read-only caching on a Premium SSD with zone-redundant storage (ZRS) allows frequently accessed data to be cached, which enhances read performance without risking significant data loss. In the event of a host failure, data is read from the redundant storage across zones, ensuring data resiliency. Since only read operations are cached, the data stored on disk remains consistent and resilient to host failures, addressing the requirement of no data loss.
Although None caching eliminates any risk of data loss, Read-only caching is acceptable for workloads that prioritize high performance and data resiliency, as it does not impact data integrity during writes.
`None` is incorrect because, while it prevents any risk of data loss, it does not utilize the performance benefits of read caching, which may be desirable for high-performance workloads with Premium SSD storage.
`Read/Write` is incorrect as it caches both read and write operations on the host, which can result in data loss in the event of a host failure. This does not meet the requirement to ensure that no data loss occurs if a host fails.
