## Énoncé et corrigé fourni


You manage a Microsoft Entra tenant that contains approximately 7,000 user accounts.
You create a new user named AdminUsr1.
You must assign the User Administrator administrative role to AdminUsr1.
Which action should you take from the user account properties to complete this task?
Réponses:
☐ From the Licenses blade, assign a new license.
☐ From the Groups blade, invite the user account to a new group.
**☑** From the Directory role blade, modify the directory role.
Explication
`From the Directory role blade, modify the directory role` is correct because to assign an administrative role, such as the User Administrator role, to AdminUsr1, you need to navigate to the Directory role blade in the user account properties. From there, you can modify the directory role and assign the appropriate administrative role.
`From the Licenses blade, assign a new license` is incorrect because assigning a license is unrelated to assigning an administrative role. Licenses are used for service access, not role-based access control.
`From the Groups blade, invite the user account to a new group` is incorrect because adding the user to a group does not assign the User Administrator role. Role assignments are handled through the Directory role settings.
