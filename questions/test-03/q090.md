## Énoncé et corrigé fourni


You have an Azure subscription that includes a web app named webapp1.
You want to associate a custom domain, www.apexcore.com, with webapp1.
Before you can complete the custom domain configuration, what is the first action you must take?
Réponses:
☐ Upload a certificate.
☐ Stop webapp1.
**☑** Create a DNS record.
☐ Add a connection string.
Explication
`Create a DNS record` is the correct answer because before you can map a custom domain (like `www.apexcore.com`) to an Azure Web App (e.g., `webapp1`), you must prove ownership of the domain. This is done by creating a CNAME or A record in the public DNS zone for the domain, pointing to the web app's default Azure domain (e.g., `webapp1.azurewebsites.net`). This step allows Azure to validate that you control the domain name.
`Upload a certificate` is incorrect because uploading an SSL certificate is only required if you plan to enable HTTPS for the custom domain. It’s not required as the first step in domain assignment.
`Stop webapp1` is incorrect because there's no need to stop the app when adding or validating a custom domain. The app can stay running throughout the process.
`Add a connection string` is incorrect because this relates to configuring access to backend services like databases. It has nothing to do with custom domain configuration.
