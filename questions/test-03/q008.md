## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- A virtual network named VNET1, which includes two subnets.
- subnet1 uses the IP address range 10.3.0.0/24.
- subnet2 uses the IP address range 10.4.0.0/24.
- A network security group named NSG1.
- A virtual machine named vm1 that has the private IP address 10.3.0.15 and is deployed in subnet1.
- A virtual machine named vm2 that has the private IP address 10.4.0.16 and is deployed in subnet2.
- A storage account named storage1.
The network security group NSG1 is configured with custom security rules as follows:
True or False:
`“VM1 can access storage1.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here. NSG1 has an outbound security rule named Storage_Access configured to allow TCP traffic on port 443 from the virtual network to resources tagged as Storage. This rule enables VM1 to access storage1 on port 443. Additionally, there is no inbound restriction on the Storage endpoint, so VM1 can successfully connect to storage1 as required.
Reference(s):
- https://docs.microsoft.com/en-us/azure/virtual-network/network-security-groups-overview
- https://docs.microsoft.com/en-us/azure/virtual-network/service-tags-overview
