## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VM1 - a virtual machine
- App1 - an Azure web app
- apexcore.com, which is a Microsoft Entra Domain Services domain
All of these resources are connected to the same virtual network, VNet1.
You plan to deploy an Azure Bastion host named Bastion1 into VNet1.
Which of these resources can be secured by using Bastion1?
Réponses:
**☑** VM1 only
☐ apexcore.com only
☐ App1 and apexcore.com only
☐ VM1 and apexcore.com only
☐ VM1, App1, and apexcore.com
Explication
`VM1 only` is correct because Azure Bastion is designed to provide secure and seamless RDP and SSH connectivity to virtual machines within a virtual network. In this scenario, VM1 is the only virtual machine listed in the table, and thus the only resource that can be accessed and protected via Bastion1. Azure Bastion does not support direct connectivity to web apps (such as App1) or to Microsoft Entra Domain Services domains (like apexcore.com).
Reference(s):
