## Énoncé et corrigé fourni


Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have an Azure subscription that contains 10 virtual networks, each deployed in its own resource group.
Another administrator intends to create multiple network security groups (NSGs) within the subscription.
You must ensure that every newly created NSG automatically blocks TCP traffic on port 8080 between the virtual networks.
Proposed solution: You create a custom Azure Policy definition and assign it at the subscription level.
Does this solution satisfy the requirement?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is the correct answer here. By configuring a custom policy definition and assigning it to the subscription, you can enforce specific rules on NSGs, such as automatically blocking TCP port 8080 between virtual networks. Custom policies allow you to specify detailed compliance requirements and enforce specific configurations, which in this case include blocking a particular port across newly created NSGs within the subscription.

- https://docs.microsoft.com/en-us/azure/governance/policy/concepts/definition-structure
