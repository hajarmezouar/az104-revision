## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that contains a virtual machine named VM1.
On VM1, you install and configure the following services:
- A web server
- A DNS server
VM1 has the effective network security rules shown in the following exhibit.
Based on this configuration, select the option that correctly completes the following statement:
“If you delete Rule2, Internet users _________________________________________.”
Réponses:
☐ can connect to only the DNS server on VM1
☐ can connect to only the web server on VM1
**☑** can connect to the web server and the DNS server on VM1
☐ cannot connect to the web server and the DNS server on VM1
Explication
`can connect to the web server and the DNS server on VM1` is correct because if Rule2 is deleted, the restriction on ports 50-60 is removed, allowing port 53 (used by DNS) to be accessible. The web server on port 80 is already accessible, as it falls outside the range that was blocked by Rule2. Therefore, with Rule2 deleted, internet users would be able to connect to both the web server (on port 80) and the DNS server (on port 53).
`Can connect to only the DNS server on VM1` is incorrect because port 80 for the web server is also accessible.
`Can connect to only the web server on VM1` is incorrect because port 53 for DNS would also be accessible once Rule2 is deleted.
`Cannot connect to the web server and the DNS server on VM1` is incorrect because deleting Rule2 allows access to both port 80 and port 53.
