## Énoncé et corrigé fourni


You intend to use Azure Network Watcher to perform the following activity:
- Determine which security rule is blocking a network packet from reaching an Azure virtual machine.
Which feature should you use for the above task?
Réponses:
**☑** IP flow verify
☐ Next hop
☐ Packet capture
☐ Traffic Analytics
Explication
`IP flow verify` is the correct option because this feature in Azure Network Watcher is specifically designed to identify whether a network packet is allowed or denied to or from an Azure virtual machine (VM). It evaluates the effective security rules applied to the VM's network interface and identifies the rule responsible for blocking or allowing the traffic.
`Next hop` is incorrect because it helps determine the route a packet takes to reach its destination but does not identify security rules blocking traffic.
`Packet capture` is incorrect because it captures live packet data for network traffic but does not identify which security rule is affecting the traffic.
`Traffic Analytics` is incorrect because it provides insights into traffic flow patterns and network resource usage, but it does not identify the specific security rule blocking traffic.
