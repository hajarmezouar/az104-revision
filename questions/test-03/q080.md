## Énoncé et corrigé fourni


You have an Azure virtual network named VNet1 that is connected to an on-premises network by using a site-to-site VPN. VNet1 includes a single subnet named Subnet1.
Subnet1 is associated with a network security group (NSG) called NSG1. The subnet hosts a basic internal load balancer named ILB1, which has three Azure virtual machines configured in its backend pool.
You need to collect information about the IP addresses that establish connections to ILB1. The collected data must be available for interactive querying directly from the Azure portal.
Which resource should you create to meet this requirement?
Réponses:
☐ An Azure Event Grid
**☑** An Azure Log Analytics workspace
☐ An Azure Storage account
Explication
`An Azure Log Analytics workspace` is the correct answer here. To collect and analyze data about incoming IP addresses connecting to resources like an internal load balancer (ILB1), and to run interactive queries via the Azure portal, the data must be sent to a Log Analytics workspace.
By enabling NSG flow logs on NSG1 (which is associated with Subnet1), you can capture information such as source and destination IP addresses, ports, protocols, and whether traffic was allowed or denied. These logs can be sent to a Log Analytics workspace, where they are indexed and made available for querying using Kusto Query Language (KQL).
`An Azure Event Grid` is incorrect because it is used for event-based messaging and automation—not for storing or querying traffic flow data.
`An Azure Storage account` is incorrect in this context because although NSG flow logs can be stored in a storage account, you cannot run interactive queries on the data from the Azure portal unless the data is also sent to a Log Analytics workspace.
