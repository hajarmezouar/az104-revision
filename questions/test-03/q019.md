## Énoncé et corrigé fourni


You have an Azure subscription with the following resources in the same resource group (RG1):
- Vault1: A Recovery Services vault located in the East US region
- VM1: A virtual machine running Windows Server in the East US region
- VM2: A virtual machine running Windows Server in the West US region
On VM1, you configure Azure Backup to protect a folder named Folder1 using a scheduled file-and-folder backup policy. The backup schedule is configured as follows:
- Backup frequency: Daily
- Backup times: 6:00 AM and 10:00 PM
You plan to restore this backup to a different virtual machine and want the data to be recovered on VM2.
What is the first action you must take?
Réponses:
☐ On VM2, install the Windows Server Backup feature.
☐ On VM1, install the Microsoft Azure Recovery Services Agent.
☐ On VM1, install the Windows Server Backup feature.
**☑** On VM2, install the Microsoft Azure Recovery Services Agent.
Explication
`On VM2, install the Microsoft Azure Recovery Services Agent` is correct because in order to restore a backup from the Recovery Services vault to a different virtual machine (in this case, VM2), you need to have the Microsoft Azure Recovery Services (MARS) Agent installed on the destination VM. This agent enables the VM to communicate with the Recovery Services vault, allowing it to access and restore backups stored in Azure.
`On VM2, install the Windows Server Backup feature` is incorrect because the Windows Server Backup feature alone does not provide the necessary integration with Azure Recovery Services. The MARS Agent is required to retrieve backups from Azure.
`On VM1, install the Microsoft Azure Recovery Services Agent` is incorrect as the MARS Agent is already installed on VM1 to perform the initial backup. The task here is to restore the backup to VM2.
`On VM1, install the Windows Server Backup feature` is incorrect because this feature does not assist in restoring a backup to another VM. The backup is already configured on VM1, and the requirement is to restore it to VM2, which requires the MARS Agent on VM2.
