## Énoncé et corrigé fourni


You have a virtual network named VNET1 that includes the following subnets:
You also have the following Azure virtual machines with the listed network configurations:
For NSG1, you configure the following inbound security rule:
- Priority: 101
- Source: 10.10.2.0/24
- Destination: 10.10.1.0/24
- Destination port: TCP 1433
- Action: Allow
For NSG2, you configure the following inbound security rule:
- Priority: 125
- Source: 10.10.2.5
- Destination: 10.10.1.5
- Destination port: TCP 1433
- Action: Block
True or False:
`“VM2 can connect to the TCP port 1433 services on VM3.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer because there are no Network Security Groups (NSGs) applied to Subnet2, where VM3 resides, or directly to VM3's network interface. NSG1, applied to Subnet1, allows traffic from Subnet2 (10.10.2.0/24) to Subnet1 (10.10.1.0/24) on TCP port 1433.
The rule in NSG2 that blocks inbound traffic specifically applies to traffic from VM2 (10.10.2.5) to VM1 (10.10.1.5), but not to VM3 (10.10.2.6). Therefore, VM2 can successfully connect to TCP port 1433 services on VM3 without restriction.
