## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual network named VNet1.
VNet1 uses the IP address space 10.0.0.0/16 and contains the following subnets:
- Subnet0 (IP address range: 10.0.0.0/24)
- Subnet1 (IP address range: 10.0.1.0/24)
- Subnet2 (IP address range: 10.0.2.0/24)
- GatewaySubnet (IP address range: 10.0.254.0/24)
Subnet1 hosts a virtual appliance named VM1, which functions as a router.
You create a route table named RT1.
You need to ensure that all inbound traffic arriving from the VPN gateway into VNet1 is routed through VM1.
You plan to configure RT1 accordingly.
What value should you specify for the next hop type?
Réponses:
**☑** Virtual appliance
☐ Virtual network
☐ Virtual network gateway
Explication
`Virtual appliance` is correct because the virtual appliance next-hop type is used when traffic needs to be routed through a specific virtual machine or network virtual appliance (NVA). In this scenario, VM1 in Subnet1 acts as a router for all inbound traffic from the VPN gateway. The routing table RT1 should use the "Virtual appliance" next-hop type to direct traffic to the virtual machine.
`Virtual network` is incorrect because it refers to routing traffic within the virtual network itself, not specifically through a virtual machine or appliance acting as a router.
`Virtual network gateway` is incorrect because it refers to routing traffic to or through an Azure VPN Gateway. In this case, the traffic has already reached the VPN Gateway and needs to be routed through the virtual appliance (VM1).
Reference(s):
- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-udr-overview
- https://azure.microsoft.com/en-in/solutions/network-appliances/
