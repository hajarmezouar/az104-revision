## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual machine named VM1.
You plan to attach a 1 TB data disk to VM1. The disk must meet the following requirements:
- It must remain available if an entire datacenter becomes unavailable.
- It must deliver the lowest possible latency and the highest performance.
- It must prevent data loss in the event that the host fails.
Which storage type should you choose?
Réponses:
☐ Premium SSD that uses locally-redundant storage (LRS)
**☑** Premium SSD that uses zone-redundant storage (ZRS)
☐ Standard SSD that uses locally-redundant storage (LRS)
☐ Standard SSD that uses zone-redundant storage (ZRS)
Explication
`Premium SSD that uses zone-redundant storage (ZRS)` is correct because it provides data resiliency by replicating data across multiple availability zones, ensuring that data remains available in the event of a datacenter outage. Additionally, Premium SSDs offer the lowest latency and highest performance compared to Standard SSDs. The use of ZRS ensures that data is also protected against potential failures within a specific zone, meeting the requirement of no data loss in case of a host or datacenter failure.
`Premium SSD that uses locally-redundant storage (LRS)` is incorrect because while it provides high performance and low latency, LRS only replicates data within a single datacenter, which does not provide resiliency in the event of a datacenter outage.
`Standard SSD that uses locally-redundant storage (LRS)` is incorrect because Standard SSDs do not meet the requirement for the highest performance and low latency, and LRS does not protect against datacenter outages.
`Standard SSD that uses zone-redundant storage (ZRS)` is incorrect because, while ZRS provides data resiliency across zones, Standard SSDs lack the performance and low latency required.
