## Énoncé et corrigé fourni


You have the following App Service plans:
- ASP1
- OS: Windows
- Region: West US
- ASP2
- OS: Windows
- Region: Central US
- ASP3
- OS: Linux
- Region: West US
You plan to create the following Azure web apps:
- WebApp1
- Runtime stack: .NET 8 (LTS)
- Location: West US
- WebApp2
- Runtime stack: ASP.NET 4.8
- Location: West US
Which App Service plan can be used to host WebApp2?
Réponses:
**☑** ASP1 only
☐ ASP3 only
☐ ASP1 and ASP2 only
☐ ASP1 and ASP3 only
☐ ASP1, ASP2, and ASP3
Explication
`ASP1 only` is correct because WebApp2 requires the ASP.NET 4.8 runtime stack, which is supported only on Windows-based App Service plans. ASP1 is a Windows-based App Service plan in the West US region, matching the requirements for WebApp2.
In the screenshot below, you can see that the Linux option for the Operating System is greyed out when the Runtime stack is selected as ASP.NET 4.8.
`ASP3 only` is incorrect because ASP3 is a Linux-based plan, which does not support the ASP.NET 4.8 runtime stack.
`ASP1 and ASP2 only` is incorrect because, although ASP2 is a Windows-based plan, it is in the Central US region, whereas WebApp2 requires a plan in the West US region.
`ASP1 and ASP3 only` is incorrect because ASP3 does not support ASP.NET 4.8.
`ASP1, ASP2, and ASP3` is incorrect because ASP2 and ASP3 do not meet the requirements for WebApp2 due to either region mismatch or OS incompatibility.
