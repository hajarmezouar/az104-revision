## Énoncé et corrigé fourni


**Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have a Microsoft Entra tenant named ironclad.com and an Azure subscription named Subscription1. The tenant contains a group called Developers. The subscription contains a resource group named Dev.
You need to allow the Developers group to create Azure Logic Apps in the Dev resource group.
Proposed Solution: On the Dev resource group, you grant the Logic App Contributor role to the Developers group.
Does this configuration satisfy the requirement?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is correct because the Logic App Contributor role provides the necessary permissions to manage Azure Logic Apps within the assigned scope, which includes creating, updating, and deleting logic apps. Assigning this role to the Developers group at the Dev resource group level fulfills the requirement to allow the group to create Azure Logic Apps in the Dev resource group without granting broader permissions.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#logic-app-contributor
