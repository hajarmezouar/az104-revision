Subscription 2 contains the following virtual network:

- Address space: 10.10.128.0/17

True or False:
`“A Site-to-site connection can be established between VNET1 and VNET2.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. A Site-to-Site connection in Azure requires a gateway subnet to be present in each virtual network that participates in the connection. However, in this case, VNet1 uses the entire address space `10.10.10.0/24` for Subnet11, leaving no free IP range available to define a gateway subnet within VNet1.
Since Azure requires a dedicated subnet named `GatewaySubnet` with available IPs in the address space for a VPN gateway to function, and VNet1 does not have any spare address space, you cannot deploy a gateway there.
Because of this, a Site-to-Site connection cannot be established between VNet1 and VNet2, even though their address spaces do not overlap.
