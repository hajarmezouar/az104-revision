## Énoncé et corrigé fourni


You manage two Azure App Service apps named App1 and App2. Each app contains:
- A production deployment slot
- A test deployment slot
The backup settings for the production slots are configured as follows:
- App1
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 0 days
- Keep at least one backup: Yes
- App2
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 30 days
- Keep at least one backup: Yes
Based on this configuration, determine the effect of the backup and retention settings.
True or False:
`“On January 15, 2024, you can restore the App2 production slot backup from January 6 to the App2 test slot.”`
Réponses:
**☑** True
☐ False
Explication
`True` is correct  because Azure App Service allows you to restore a backup taken from the production slot to any other slot of the same app, including a test slot. The backup of the App2 production slot from January 6, 2024 would still be available on January 15, 2024 because the retention policy is set to 30 days and the "Keep at least one backup" option is enabled.
This means that the backup from January 6 is retained and can be used to restore not only to the production slot but also to the test slot, assuming the restore operation is initiated within the retention period.
Reference(s):
- https://learn.microsoft.com/en-us/azure/app-service/manage-backup#restore-an-app
- https://learn.microsoft.com/en-us/azure/app-service/web-sites-staged-publishing
