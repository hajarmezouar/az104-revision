## Énoncé et corrigé fourni


**Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have a Microsoft Entra tenant named ironclad.com and an Azure subscription named Subscription1. The tenant contains a group called Developers. The subscription contains a resource group named Dev.
You need to allow the Developers group to create Azure Logic Apps in the Dev resource group.
Proposed Solution: You assign the Contributor role to the Developers group at the Dev resource group scope.
Does this configuration satisfy the requirement?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is correct because assigning the Contributor role to the Developers group at the Dev resource group level allows the group members to manage all resources within the resource group, including the ability to create Azure Logic Apps. The Contributor role provides full access to manage resources without granting permissions to assign roles or manage access, which fulfills the requirement stated in the question.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#contributor
