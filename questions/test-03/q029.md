## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named apexcore.onmicrosoft.com that contains the following users:
- User1 is a member of Group1 and has no directory role assigned.
- User2 is a member of Group2 and has no directory role assigned.
- User3 is a member of Group1 and Group2, and is assigned the User Administrator role.
You enable password reset for apexcore.onmicrosoft.com as below:
- SSPR is enabled for Selected users only.
- The selected group is Group2.
Authentication method settings for password reset are configured with these options:
- Number of methods required to reset: 2
- Enabled methods:
- Mobile phone
- Security questions
- The following methods are not enabled:
- Mobile app notification
- Mobile app code
- Email
- Office phone
- Number of security questions required to register: 5
- Number of security questions required to reset: 3
- A total of 10 security questions are available.
True or False:
`"User3 can add security questions to the password reset process."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because although User3 has the User Administrator role, this role does not include permissions to modify the security questions configured for self-service password reset (SSPR). Only users with the Global Administrator or Authentication Administrator roles have the necessary permissions to modify security questions in the SSPR settings.
