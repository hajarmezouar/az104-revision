## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storacc1.
The storacc1 account contains blob data stored in a container named cont1.
You plan to share access to storacc1 by generating a shared access signature (SAS).
The SAS must meet the following requirements:
- Ensure that the SAS can only be used to enumerate and download blobs stored in cont1.
- Use the principle of least privilege.
Which three settings should you enable?
Réponses (plusieurs réponses possibles)

**☑** Container
☐ Object
**☑** Read
**☑** List
☐ Filter
Explication
`Container` is correct.  This level of access limits the scope to container-level operations, specifically allowing access to cont1 where the blobs are stored.
`Read` and `List` are correct. Enabling Read and List permissions ensures that the SAS can only enumerate and download blobs within container1. Read permission allows downloading the blobs, and List permission allows enumerating the blobs within the container.
