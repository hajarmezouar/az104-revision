## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that is shared across multiple departments. The subscription currently includes the following resources:
- storage1 - Azure Storage account
- RG1 - Resource group
- container1 - Blob container
- share1 - Azure file share
Another administrator deploys two new resources, a virtual machine named VM1 and a storage account named storage2, by using a single Azure Resource Manager (ARM) template.
You want to review the ARM template that was used for this deployment.
From which Azure portal blade can you view the template associated with the deployment?
Réponses:
☐ container1
**☑** RG1
☐ storage1
☐ VM1
Explication
`RG1` is correct because to view the Azure Resource Manager (ARM) template used for a deployment, you need to access the Resource Group (in this case, `RG1`) where the deployment was made. The Resource Group blade in the Azure portal includes an option to view the deployment history and allows you to access the templates used in those deployments.
`container1` is incorrect because a Blob container does not have deployment information or templates associated with it directly. It is a storage object within a storage account and lacks deployment-level insights.
`storage1` is incorrect as it is the storage account itself, and the ARM template used for deployments would not be accessible from the storage account blade. Templates are accessible through the Resource Group level.
`VM1` is incorrect because while you can see configuration and settings specific to `VM1`, the VM blade does not provide access to the ARM template used in the original deployment. The Resource Group blade is needed for viewing deployment templates.
Reference(s):
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/deployment-history
