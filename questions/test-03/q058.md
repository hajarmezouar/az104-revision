## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VNet1 - Virtual network located in West US, in RG2
- VNet2 - Virtual network located in West US, in RG1
- VNet3 - Virtual network located in East US, in RG1
- NSG1 - Network security group located in East US, in RG2
To which subnets can you apply NSG1?
Réponses:
☐ the subnets on VNet1 only
☐ the subnets on VNet2 only
**☑** the subnets on VNet3 only
☐ the subnets on VNet2 and VNet3 only
☐ the subnets on VNet1, VNet2, and VNet3
Explication
`the subnets on VNet3 only` is correct because a network security group (NSG) must be in the same region as the virtual network or subnets to which it is applied. NSG1 is in the East US region, and therefore it can only be applied to the subnets within VNet3, as VNet3 is also in the East US region.
Reference(s):
- https://learn.microsoft.com/en-us/azure/virtual-network/network-security-groups-overview
- https://learn.microsoft.com/en-us/azure/security/fundamentals/network-best-practices
