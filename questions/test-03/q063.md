## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual network named VNet1.
VNet1 uses the IP address space 10.0.0.0/16 and contains the following subnets:
- Subnet0 (IP address range: 10.0.0.0/24)
- Subnet1 (IP address range: 10.0.1.0/24)
- Subnet2 (IP address range: 10.0.2.0/24)
- GatewaySubnet (IP address range: 10.0.254.0/24)
Subnet1 hosts a virtual appliance named VM1, which functions as a router.
You create a route table named RT1.
You need to ensure that all inbound traffic arriving from the VPN gateway into VNet1 is routed through VM1.
You plan to configure RT1 accordingly.
Which option should you select for the Assigned to setting?
Réponses:
**☑** GatewaySubnet
☐ Subnet0
☐ Subnet1 and Subnet2
Explication
`GatewaySubnet` is correct because the routing table RT1 must be associated with the GatewaySubnet to ensure that all traffic coming from the VPN Gateway is routed through the virtual appliance (VM1) in Subnet1. The GatewaySubnet is a dedicated subnet for VPN Gateway and requires proper routing configuration to direct traffic appropriately.
`Subnet0` is incorrect because associating the route table with Subnet0 would not ensure that traffic from the VPN Gateway is routed through the virtual appliance in Subnet1.
`Subnet1 and Subnet2` is incorrect because associating the route table with these subnets does not target the GatewaySubnet, which is the entry point for VPN traffic. Routing must start from the GatewaySubnet.
