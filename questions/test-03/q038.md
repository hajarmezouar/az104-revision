## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VM1 - a virtual machine
- VM2 - a virtual machine
- LB1 - a load balancer that uses the Basic SKU
You install the Web Server (IIS) role on both VM1 and VM2. After the installation, you add both virtual machines to the backend pool of LB1.
LB1 is configured as shown below.
Rule1 is configured as shown below.
True or False:
`"VM1 is in the same availability set as VM2."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because a Basic SKU load balancer requires that all network interfaces (NICs) connected to it be part of the same availability set. This restriction means that both VM1 and VM2 must be in the same availability set to be added to LB1 (a Basic SKU load balancer). The Basic SKU does not support flexibility across multiple availability sets, enforcing that all associated VMs are within the same availability set.
