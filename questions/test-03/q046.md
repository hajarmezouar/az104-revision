## Énoncé et corrigé fourni


You have an Azure subscription and plan to deploy the below Bicep file named File01.bicep.
param location string = resourceGroup().location
resource virtualNetwork 'Microsoft.Network/virtualNetworks@2025-01-01' = {
name: 'VNET1'
location: location
properties: {
addressSpace: {
addressPrefixes: [
'10.0.0.0/16'
]
}
subnets: [
{
name: 'Subnet-1'
properties: {
addressPrefix: '10.0.0.0/24'
}
}
{
name: 'Subnet-2'
properties: {
addressPrefix: '10.0.1.0/24'
}
}
]
}
}
True or False:
`“Deploying File1.bicep multiple times will result in a deployment error.”`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because deploying File01.bicep more than once will not inherently cause an error, as Azure Resource Manager is designed to perform idempotent deployments. This means that if you deploy the same Bicep file multiple times without changing the parameters, Azure will recognize that the resources already exist and will not attempt to recreate them, avoiding any conflict or error. Any subsequent deployments would simply update the existing resources if there are changes; otherwise, the deployment will succeed without modification.
