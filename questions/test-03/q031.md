## Énoncé et corrigé fourni


You have the following Azure resources:
- Tenant Root Group - tenant root management group
- MG1 - management group
- Sub1 - subscription
- RG1 - resource group
- VM1 - virtual machine
You want to monitor resource usage and ensure that resources cannot be accidentally deleted.
To which resources can you apply locks?
Réponses:
☐ RG1 and VM1 only
☐ Sub1 and RG1 only
**☑** Sub1, RG1, and VM1 only
☐ MG1, Sub1, RG1, and VM1 only
☐ Tenant Root Group, MG1, Sub1, RG1, and VM1
Explication
`Sub1, RG1, and VM1 only` is correct because locks can be applied at the subscription, resource group, and resource (such as a virtual machine) levels to prevent accidental deletion or modification. In this case, Sub1 (the subscription), RG1 (the resource group), and VM1 (the virtual machine) are valid targets for applying locks to track usage and prevent deletion.
`RG1 and VM1 only` is incorrect because locks can also be applied at the subscription level (Sub1), not just at the resource group and resource levels.
`Sub1 and RG1 only` is incorrect because locks can also be applied directly to resources like VM1.
`MG1, Sub1, RG1, and VM1 only` is incorrect because locks cannot be applied to management groups (MG1).
`Tenant Root Group, MG1, Sub1, RG1, and VM1` is incorrect because locks cannot be applied to the Tenant Root Group or management groups.
