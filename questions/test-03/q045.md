## Énoncé et corrigé fourni


You have an Azure subscription and plan to deploy the below Bicep file named File01.bicep.
param location string = resourceGroup().location
resource virtualNetwork 'Microsoft.Network/virtualNetworks@2025-01-01' = {
name: 'VNET1'
location: location
properties: {
addressSpace: {
addressPrefixes: [
'10.0.0.0/16'
]
}
subnets: [
{
name: 'Subnet-1'
properties: {
addressPrefix: '10.0.0.0/24'
}
}
{
name: 'Subnet-2'
properties: {
addressPrefix: '10.0.1.0/24'
}
}
]
}
}
True or False:
`“Both subnet objects will be created successfully without any deployment errors.”`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because both Subnet-1 and Subnet-2 in the Bicep file have unique address prefixes (10.0.0.0/24 for Subnet-1 and 10.0.1.0/24 for Subnet-2) that fall within the address space of VNET1 (10.0.0.0/16). Since the subnets have non-overlapping address ranges within the virtual network's address space, they will be provisioned successfully.
