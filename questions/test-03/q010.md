## Énoncé et corrigé fourni


You have an Azure subscription that contains the following resources:
- A virtual network named VNET1, which includes two subnets.
- subnet1 uses the IP address range 10.3.0.0/24.
- subnet2 uses the IP address range 10.4.0.0/24.
- A network security group named NSG1.
- A virtual machine named vm1 that has the private IP address 10.3.0.15 and is deployed in subnet1.
- A virtual machine named vm2 that has the private IP address 10.4.0.16 and is deployed in subnet2.
- A storage account named storage1.
The network security group NSG1 is configured with custom security rules as follows:
True or False:
`“The NSG1 security rules apply to all virtual machines on VNET1.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. NSG1 is attached to a subnet, and by examining the inbound rule, the destination is specified as the private IP of VM1, indicating that NSG1 is likely connected to subnet1. Network Security Group (NSG) rules apply only to the resources within the scope to which the NSG is associated. Therefore, these rules will apply only to the virtual machines in subnet1 and not to all virtual machines on VNET1.
