## Énoncé et corrigé fourni


You manage two Azure App Service apps named App1 and App2. Each app contains:
- A production deployment slot
- A test deployment slot
The backup settings for the production slots are configured as follows:
- App1
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 0 days
- Keep at least one backup: Yes
- App2
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 30 days
- Keep at least one backup: Yes
Based on this configuration, determine the effect of the backup and retention settings.
True or False:
`“On February 6, 2024, you can access the backup of the App2 test slot from January 15, 2024.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because the backup configuration applies only to the production slot of App2, not the test slot. The table provided shows backup settings for the production slots of App1 and App2, and there is no mention of backups being configured for the test slot of App2.
Since Azure App Service does not automatically back up deployment slots other than the production slot unless explicitly configured, no backup of the App2 test slot from January 15, 2024 would exist by February 6, 2024.
Reference(s):
- https://learn.microsoft.com/en-us/azure/app-service/manage-backup
- https://learn.microsoft.com/en-us/azure/app-service/deploy-staging-slots
