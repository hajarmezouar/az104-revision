## Énoncé et corrigé fourni


You have the following Azure resources:
- Tenant Root Group - tenant root management group
- MG1 - management group
- Sub1 - subscription
- RG1 - resource group
- VM1 - virtual machine
You want to monitor resource usage and ensure that resources cannot be accidentally deleted.
To which resources can you apply tags?
Réponses:
☐ RG1 and VM1 only
☐ Sub1 and RG1 only
**☑** Sub1, RG1, and VM1 only
☐ MG1, Sub1, RG1, and VM1 only
☐ Tenant Root Group, MG1, Sub1, RG1, and VM1
Explication
`Sub1, RG1, and VM1 only` is correct because tags can be applied to subscriptions (Sub1), resource groups (RG1), and resources (such as VM1) in Azure. Tags cannot be applied to management groups (MG1) or the Tenant Root Group.
