- Creates a new resource group.
- Deploys an Azure Storage account into that resource group by using a nested deployment.

Which PowerShell cmdlet should you run to deploy the template?
Réponses:
**☑** New-AzDeployment
☐ New-AzResource
☐ New-AzResourceGroupDeployment
☐ New-AzTenantDeployment
Explication
`New-AzDeployment` is the correct cmdlet to use when your ARM template includes a nested deployment of a resource group, as shown in the image. This cmdlet allows you to deploy resources at the subscription level, which is necessary here because the template first creates a resource group (RG1) and then deploys a storage account into that group.
The nested deployment structure in the ARM template includes:
- A `Microsoft.Resources/resourceGroups` resource to create the resource group.
- A `Microsoft.Resources/deployments` resource that deploys the storage account into the newly created group using a nested template.
Since the deployment targets multiple scopes (subscription and resource group), you must use a subscription-level deployment cmdlet like `New-AzDeployment`.
`New-AzResourceGroupDeployment` is incorrect because it's used to deploy resources within an existing resource group. It cannot be used when your template includes the creation of a new resource group.
`New-AzSubscriptionDeployment` is an alias for `New-AzDeployment`, but the preferred cmdlet name is `New-AzDeployment`, which works consistently across all scopes in newer versions of the Az PowerShell module.
