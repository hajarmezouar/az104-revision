## Énoncé et corrigé fourni


You have an Azure subscription that includes two storage accounts named contoso101 and contoso102.
The subscription also contains two virtual machines with the following configurations:
- VM1 is connected to VNet1/Subnet1 and uses a Basic public IP address SKU.
- VM2 is connected to VNet1/Subnet2 and uses a Standard public IP address SKU.
Within VNet1, service endpoints are configured as follows:
- Microsoft.AzureActiveDirectory is enabled on Subnet2.
- Microsoft.Storage is enabled on Subnet1.
A service endpoint policy named Policy1 is created for the Microsoft.Storage service. The policy allows access only to the storage account contoso101. The policy is associated with subnets that have Microsoft.Storage service endpoints enabled.
True or False:
`“VM2 uses a private IP address to access Microsoft Entra ID.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. While there is a service endpoint for Microsoft.AzureActiveDirectory on Subnet2, which VM2 is connected to, this does not mean that VM2 can use a private IP address to access Microsoft Entra ID. Microsoft Entra ID is a global service that is accessible only via public IP addresses. The service endpoint for Microsoft.AzureActiveDirectory allows secure access to Entra ID but does not provide connectivity via private IP addresses; it only restricts access to specific VNets and subnets to enhance security while still using public IPs for the actual connection.
Reference(s):
- https://learn.microsoft.com/en-us/entra/fundamentals/whatis
