You are provided with a JSON file that lists several Azure role assignments at different scopes as shown below.
[
{
"RoleAssignmentId": "f1a9c2d4-8b35-4e71-9c2a-6d5e7f8a9012",
"Scope": "/subscriptions/9b2d7f41-6c8e-4a55-b1d9-3e7f2a6c4b10",
"DisplayName": "User1",
"SignInName": "User1@apexcore.onmicrosoft.com",
"RoleDefinitionName": "Owner"
},
{
"RoleAssignmentId": "a7c4e1b2-5d93-4f60-8a1e-2b6c9d7f3e44",
"Scope": "/subscriptions/9b2d7f41-6c8e-4a55-b1d9-3e7f2a6c4b10/resourceGroups/RG2",
"DisplayName": "User2",
"SignInName": "User2@apexcore.onmicrosoft.com",
"RoleDefinitionName": "Owner"
},
{
"RoleAssignmentId": "d3e8f7a1-2c44-4b9e-91fa-5c6d8e2b7a33",
"Scope": "/subscriptions/9b2d7f41-6c8e-4a55-b1d9-3e7f2a6c4b10/resourceGroups/RG1/providers/Microsoft.Compute/virtualMachines/VM1",
"DisplayName": "User3",
"SignInName": "User3@apexcore.onmicrosoft.com",
"RoleDefinitionName": "Owner"
},
{
"RoleAssignmentId": "b6d2a9f8-1e73-4c55-8b0d-9f2e6a4c7d88",
"Scope": "/subscriptions/9b2d7f41-6c8e-4a55-b1d9-3e7f2a6c4b10/resourceGroups/RG1",
"DisplayName": "User4",
"SignInName": "User4@apexcore.onmicrosoft.com",
"RoleDefinitionName": "Contributor"
}
]
Using the details in the role assignment file, choose the option that correctly completes the following statement:
“____________________________ assigned the Owner role for VM1.”
Réponses:
☐ User3 is
☐ User3 and User4 are
**☑** User1 and User3 are
☐ User1, User3, and User4 are
☐ User1, User2, User3, and User4 are
Explication
`User1 and User3 are` is correct because in the provided role assignment file, User3 is specifically assigned the Owner role at the scope of VM1 (/subscriptions/.../resourceGroups/RG1/providers/Microsoft.Compute/virtualMachines/VM1).
And User1 is the owner of the subscription, which inherently makes it the owner of VM inside that subscription as well.
