## Énoncé et corrigé fourni


You manage two Azure subscriptions named Subscription1 and Subscription2.
Subscription1 has the following virtual networks:
The virtual networks contain the following subnets:
Subscription 2 contains the following virtual network:
- Name: VNETA
- Address space: 10.10.128.0/17
- Location: Canada Central
VNETA contains the following subnets:
True or False:
`“VNET1 and VNETA can be peered.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here.
Azure allows peering between VNets as long as the following conditions are met:
- No overlapping address ranges
- VNets can be in the same or different subscriptions
- VNets can be in the same or different regions
Since VNET1 and VNETA are in different regions but have non-overlapping IP ranges, they can be peered using global VNet peering.
Reference(s.):
- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-network-peering-overview
- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-network-manage-peering
