## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VM1 - a virtual machine
- VM2 - a virtual machine
- LB1 - a load balancer that uses the Basic SKU
You install the Web Server (IIS) role on both VM1 and VM2. After the installation, you add both virtual machines to the backend pool of LB1.
LB1 is configured as shown below.
Rule1 is configured as shown below.
True or False:
`"If Probe1.htm is present on VM1 and VM2, LB1 will balance traffic for TCP port 80 between VM1 and VM2."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because Probe1 is configured as an HTTP probe on port 80, checking for the presence of Probe1.htm on both VM1 and VM2. If Probe1.htm is present on both virtual machines, the health probe will mark both VMs as healthy, enabling LB1 (the Basic SKU load balancer) to balance incoming traffic on TCP port 80 across VM1 and VM2. The load balancer will distribute traffic only to VMs that pass the health probe check, so the presence of Probe1.htm ensures load balancing between the two VMs.

- https://learn.microsoft.com/en-us/azure/load-balancer/load-balancer-custom-probe-overview
