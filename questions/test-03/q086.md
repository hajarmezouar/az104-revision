## Énoncé et corrigé fourni


You manage two Azure App Service apps named App1 and App2. Each app contains:
- A production deployment slot
- A test deployment slot
The backup settings for the production slots are configured as follows:
- App1
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 0 days
- Keep at least one backup: Yes
- App2
- Backup frequency: Every 1 day
- Schedule start date: January 6, 2024
- Retention period: 30 days
- Keep at least one backup: Yes
Based on this configuration, determine the effect of the backup and retention settings.
True or False:
`“On January 15, 2024, App1 will have only one backup in storage.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because the backup configuration for App1 specifies a retention period of 0 days with “Keep at least one backup” set to Yes. In Azure App Service, setting the retention to 0 means backups are retained indefinitely unless manually deleted. Additionally, the “keep at least one backup” option ensures that even if retention policies are applied, at least one backup is preserved.
Since App1 is backed up daily starting from January 6, 2024, by January 15, 2024, there would be multiple backups retained unless manually removed. Therefore, App1 would not have only one backup in storage on that date.
Reference(s):
- https://learn.microsoft.com/en-us/azure/app-service/manage-backup
- https://learn.microsoft.com/en-us/cli/azure/webapp/config/backup?view=azure-cli-latest
