## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named apexcore.com.
There are two external partner organizations: ironclad.com and bluerock.com.
Only ironclad.com is configured as a connected organization in Microsoft Entra.
You create an access package as shown in the below exhibit.
The external user lifecycle settings are configured so that when an external user loses their last access package assignment:
- The user is blocked from signing in.
- The user is removed from the directory after 30 days.
True or False:
`“Once 395 days have passed, users from ironclad.com will be removed from the apexcore.com tenant.”`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because, according to the external user lifecycle settings, after a ironclad.com user loses their last assignment to an access package, they are set to be removed from the apexcore.com tenant after 30 days. Given that the access package assignment expires after 365 days, ironclad.com users will be removed from the apexcore.com tenant 30 days later, totaling 395 days from the start of their assignment.
