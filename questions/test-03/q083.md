## Énoncé et corrigé fourni


You have an application named App1 that will be deployed on two Azure virtual machines, VM1 and VM2.
You plan to use an Azure Availability Set for App1. The solution must ensure that App1 remains available when Azure performs planned maintenance on the physical hardware hosting VM1 and VM2.
What configuration should you include when creating the Availability Set?
Réponses:
☐ one update domain
**☑** two update domains
☐ one fault domain
☐ two fault domains
Explication
`two update domains` is the correct answer here. Update domains in an Availability Set ensure that not all virtual machines are rebooted at the same time during planned maintenance events, such as OS patching or Azure platform updates. By placing VM1 and VM2 in two separate update domains, Azure ensures that only one VM is rebooted at a time, keeping App1 available during maintenance.
This satisfies the requirement to maintain availability of App1 during planned maintenance, which is exactly what update domains are designed to protect against.
`one update domain` is incorrect because placing both VMs in the same update domain would allow both to be rebooted simultaneously during planned maintenance, causing downtime for App1.
`one fault domain` and `two fault domains` are incorrect in this context because fault domains deal with unplanned hardware failures, not planned maintenance. While fault domains enhance resilience to physical failures, they do not ensure availability during platform maintenance activities.
