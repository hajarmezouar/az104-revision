## Énoncé et corrigé fourni


You have a Microsoft Entra tenant named apexcore.com.
There are two external partner organizations: ironclad.com and bluerock.com.
Only ironclad.com is configured as a connected organization in Microsoft Entra.
You create an access package as shown in the below exhibit.
The external user lifecycle settings are configured so that when an external user loses their last access package assignment:
- The user is blocked from signing in.
- The user is removed from the directory after 30 days.
True or False:
`“Users from bluerock.com can be assigned to package1.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. The access package package1 is configured to allow access requests from "All configured connected organizations." Based on the information given, only ironclad.com is set up as a connected organization. Since bluerock.com is not configured as a connected organization, users from litwareinc.com are not eligible to be assigned to package1.
