## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources:
- VM1 - a virtual machine
- VM2 - a virtual machine
- LB1 - a load balancer that uses the Basic SKU
You install the Web Server (IIS) role on both VM1 and VM2. After the installation, you add both virtual machines to the backend pool of LB1.
LB1 is configured as shown below.
Rule1 is configured as shown below.
True or False:
`"If you delete Rule1, LB1 will balance all the requests between VM1 and VM2 for all the ports."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because if Rule1 is deleted, LB1 will lack the configuration needed to balance traffic for any ports between VM1 and VM2. Additionally, if all health probes fail for all instances in the backend pool, no new flows will be directed to the backend pool, and the Basic Load Balancer will terminate any existing TCP flows to the backend pool. Therefore, deleting Rule1 would prevent LB1 from balancing any requests across VM1 and VM2.
