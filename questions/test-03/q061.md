## Énoncé et corrigé fourni


You have an Azure subscription that includes a virtual network named VNet1.
VNet1 uses the IP address space 10.0.0.0/16 and contains the following subnets:
- Subnet0 (IP address range: 10.0.0.0/24)
- Subnet1 (IP address range: 10.0.1.0/24)
- Subnet2 (IP address range: 10.0.2.0/24)
- GatewaySubnet (IP address range: 10.0.254.0/24)
Subnet1 hosts a virtual appliance named VM1, which functions as a router.
You create a route table named RT1.
You need to ensure that all inbound traffic arriving from the VPN gateway into VNet1 is routed through VM1.
You plan to configure RT1 accordingly.
What value should you specify for the address prefix?
Réponses:
**☑** 10.0.0.0/16
☐ 10.0.1.0/24
☐ 10.0.254.0/24
Explication
`10.0.0.0/16` is correct because it represents the entire IP address range of VNet1, including all its subnets (Subnet0, Subnet1, Subnet2, and GatewaySubnet). Configuring this address prefix in the route table ensures that all traffic arriving at the VPN gateway and destined for any subnet in VNet1 is routed through the virtual appliance (VM1) in Subnet1.
`10.0.1.0/24` is incorrect because this prefix only applies to Subnet1. Configuring RT1 with this prefix will not ensure that all traffic from the VPN gateway to the other subnets passes through VM1.
`10.0.254.0/24` is incorrect because this prefix refers specifically to the GatewaySubnet. It does not cover the entire VNet, and traffic to other subnets will not be routed through VM1.
Reference(s):
- https://azure.microsoft.com/en-in/solutions/network-appliances/
- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-udr-overview
