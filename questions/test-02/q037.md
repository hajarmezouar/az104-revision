## Énoncé et corrigé fourni


**Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You administer a virtual network named VNet1 located in the West US Azure region.
Within VNet1, there are two virtual machines, VM1 and VM2, both running Windows Server.
You are required to analyze and observe all network traffic flowing from VM1 to VM2 over a continuous three-hour window.
Proposed solution: You use Performance Monitor to configure a Data Collector Set (DCS).
Does this proposed solution achieve the stated requirement?
Réponses:
☐ Yes
**☑** No
Explication
`No` is correct because Performance Monitor and creating a Data Collector Set (DCS) on Windows Server allows you to collect performance metrics, such as CPU, memory, and disk usage, but it does not capture or inspect network traffic between VMs. To inspect all network traffic between VM1 and VM2, you would need to use Packet Capture in Azure Network Watcher, which is specifically designed for capturing and analyzing network traffic.
Reference(s):
- https://docs.microsoft.com/en-us/azure/azure-monitor/insights/network-performance-monitor
