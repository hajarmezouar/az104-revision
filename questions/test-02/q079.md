## Énoncé et corrigé fourni


Your on-premises environment includes the following resource:
- An SMB file share named Share1
Your Azure subscription contains these resources:
- A web app named webapp1
- An Azure virtual network named VNET1
You need to ensure that webapp1 can connect to Share1.
Which Azure resource should you deploy to meet this requirement?
Réponses:
**☑** an Azure Virtual Network Gateway
☐ an Azure Application Gateway
☐ a Microsoft Entra Application Proxy
Explication
`an Azure Virtual Network Gateway` is the correct answer here. Since `Share1` is an SMB file share hosted on-premises, and the web app (`webapp1`) is hosted in Azure, you need to establish network-level connectivity between your on-premises network and Azure. This can be accomplished by using an Azure Virtual Network Gateway in combination with either a site-to-site VPN or ExpressRoute connection. Once that private connectivity is established, webapp1 can access resources like the SMB share via VNet Integration, assuming webapp1 is integrated with `VNET1`.
`an Azure Application Gateway` is incorrect because Application Gateway is used for HTTP/HTTPS load balancing and web traffic routing; it does not provide connectivity to on-premises file shares or private networks.
`a Microsoft Entra Application Proxy` is incorrect because Entra Application Proxy is designed to provide secure remote access to on-premises web applications, not file shares like SMB. It works at the application layer, not the network layer.

- https://learn.microsoft.com/en-us/azure/vpn-gateway/vpn-gateway-about-vpngateways
