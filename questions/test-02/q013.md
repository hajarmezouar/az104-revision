## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that includes the following users:
- Admin1 with the User Administrator role
- User1 with the User role
You must complete the following tasks:
- Create a custom attribute named Property1.
- Ensure that Admin1 is able to assign Property1 to User1.
Which two settings should you configure from the Microsoft Entra ID blade?
Réponses (plusieurs réponses possibles)
**☑** Custom security attributes
**☑** Roles and administrators
☐ External Identities
☐ Administrative units
☐ Application proxy
☐ Microsoft Entra Connect
Explication
`Custom security attributes` is correct because this setting allows you to define attributes like `Property1` within Microsoft Entra ID. These attributes can then be assigned to users, groups, service principals, or managed identities as needed.
`Roles and administrators` is also correct because although Admin1 currently has the User Administrator role—which does not grant the ability to create or assign custom security attributes—this blade is used to assign the appropriate roles. To fulfill the requirement, Admin1 must be granted two additional roles: Attribute Definition Administrator to create `Property1`, and Attribute Assignment Administrator to assign it to User1. These roles must be explicitly assigned through the Roles and administrators section in the Microsoft Entra admin center.
`External Identities` is incorrect because it manages access and collaboration with external users and is not relevant to custom attribute configuration.
`**
Administrative units` is incorrect** because they are used for scoping administrative permissions to subsets of users or devices, not for managing attribute definitions or assignments.
`Application proxy` is incorrect this is unrelated to identity or attribute management; it provides secure remote access to on-premises applications.
`Microsoft Entra Connect` is incorrect because this is used for syncing identities from on-premises directories and has no role in attribute creation or assignment.
