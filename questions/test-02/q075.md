## Énoncé et corrigé fourni


You have an Azure subscription that contains the following vaults:
- Recovery1 – Recovery Services vault
- Backup1 – Azure Backup vault
You deploy two virtual machines:
- VM1 – Windows Server, configured with Azure Disk Encryption
- VM2 – Linux, configured with Trusted launch
The following backup policies are configured:
True or False:
`“VM2 can be backed up by using Policy3.”`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. Policy3 is associated with Backup1, which is an Azure Backup vault. However, Azure Backup vaults do not support backup of Azure virtual machines. Instead, Recovery Services vaults are required for backing up Azure VMs, whether the VM is Windows or Linux, and regardless of whether it uses features like Trusted Launch.
Additionally, Policy3 is marked as Not applicable, indicating that it does not contain backup configurations applicable for VM workloads. Azure Backup vaults are designed to support specific workloads such as:
- Azure Disks
- Azure Blobs (in Azure Storage)
- Azure Database for PostgreSQL servers
- Azure Kubernetes Services (AKS)
Since VM2 is a virtual machine, it cannot be backed up using Policy3 in Backup1.

- https://learn.microsoft.com/en-us/azure/backup/backup-vault-overview
