## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that contains the resources shown in the following table.
Within storage1, you create a blob container named blob1 and a file share named share1.
Which of the listed resources are eligible to be backed up to `Vault1`?
Réponses:
**☑** VM1 only
☐ VM1 and share1 only
☐ VM1 and SQL1 only
☐ VM1, storage1, and SQL1 only
☐ VM1, blob1, share1, and SQL1
Explication
`VM1 only` is correct because a Recovery Services vault can only back up resources that are in the same geographic region as the vault itself. In this case, Vault1 is located in Central US, so it can only protect resources within the Central US region. VM1 is the only resource in Central US and, therefore, the only resource that can be backed up by Vault1.
`VM1 and share1 only` is incorrect because share1 is in West US, which is not the same region as Vault1. Recovery Services vaults cannot back up resources in a different region.
`VM1 and SQL1 only` is incorrect because SQL1 is in East US, which is not the same region as Vault1.
`VM1, storage1, and SQL1 only` and `VM1, blob1, share1, and SQL1` are both incorrect because Vault1 cannot back up blobs or resources located outside of the Central US region.
