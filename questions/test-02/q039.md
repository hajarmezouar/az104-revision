## Énoncé et corrigé fourni


Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have a Microsoft Entra tenant named Bluerock.com and an Azure subscription called Subscription1. Within Bluerock.com, there is a security group named Developers. Within Subscription1, there is a resource group named Dev.
You must grant the Developers group permissions that allow them to create Azure Logic Apps within the Dev resource group.
Proposed solution: At the Subscription1 scope, you grant the Developers group the DevTest Labs User role.
Does this solution satisfy the requirement?
Réponses:
☐ Yes
**☑** No
Explication
`No` is correct because the DevTest Labs User role allows users to connect to, start, restart, and shut down virtual machines in Azure DevTest Labs. It does not provide permissions to create Azure Logic Apps. The ability to create Logic Apps requires a role such as Logic App Contributor or Contributor, which explicitly includes permissions for managing logic apps. Therefore, assigning the DevTest Labs User role does not meet the stated requirement.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#devtest-labs-user
