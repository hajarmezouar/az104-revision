## Énoncé et corrigé fourni


You have an Azure subscription.
You plan to create an Azure Storage account with the configuration shown in the following exhibit.
Based on the information presented, select the answer choice that completes the following statement correctly.
“To reduce the cost of infrequently accessed data in the storage account, you must modify the ____________________ setting.”
Réponses:
**☑** Access tier (default)
☐ Performance
☐ Account kind
☐ Replication
Explication
`Access tier (default)` is correct because changing the access tier to Cool, Cold, or Archive can help reduce the cost of storing data that is infrequently accessed. Switching from Hot to Cool, Cold, or Archive will optimize cost depending on the data access pattern.
`Performance` is incorrect because this setting affects the performance of the storage account (Standard vs. Premium) but does not specifically target cost savings for infrequently accessed data.
`Account kind` is incorrect because changing the account kind to a different type (e.g., StorageV1 to StorageV2) does not directly reduce costs for infrequently accessed data.
`Replication` is incorrect because replication affects data durability and redundancy but does not specifically reduce costs for infrequently accessed data.
