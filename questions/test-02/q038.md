## Énoncé et corrigé fourni


Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have a Microsoft Entra tenant named Bluerock.com and an Azure subscription called Subscription1. Within Bluerock.com, there is a security group named Developers. Within Subscription1, there is a resource group named Dev.
You must grant the Developers group permissions that allow them to create Azure Logic Apps within the Dev resource group.
Proposed solution: At the Dev resource group scope, you assign the Logic App Operator role to the Developers group.
Does this solution satisfy the requirement?
Réponses:
☐ Yes
**☑** No
Explication
`No` is correct because the Logic App Operator role allows users to perform runtime operations on logic apps, such as triggering, enabling, disabling, and viewing runs and history. However, it does not provide the permissions required to create, update, or delete logic apps. This means that assigning the Logic App Operator role to the Developers group does not fulfill the requirement to allow them to create Azure Logic Apps.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#logic-app-operator
