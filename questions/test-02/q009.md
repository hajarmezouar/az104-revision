## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 in which you create an alert rule named Alert1.
The Alert1 action group is configured as shown in the following exhibit.
ResourceGroupName : default-activitylogalerts
GroupShortName    : AG1
Enabled           : True
EmailReceivers    : {Action1 - EmailAction}
SmsReceivers      : {Action1 - SMSAction}
WebhookReceivers  : {}
Id                : /subscriptions/7c1e9b42-3f6a-4d88-9a21-5e7c4b2f9d10/resourceGroups/default-activitylogalerts/providers/microsoft.insights/actionGroups/ActionGroup1
Name              : ActionGroup1
Type              : Microsoft.Insights/ActionGroups
Location          : Global
Tags              : {}The alert condition for Alert1 is evaluated and triggered every minute.
Based on the information presented, select the answer choice that completes the following statement correctly.
“The number of SMS messages that Alert1 will send in an hour is ________.”
Réponses:
☐ 0
☐ 4
☐ 6
**☑** 12
☐ 60
Explication
`12` is correct because, although Alert1 is configured to trigger every minute (which would normally result in 60 alerts per hour), Azure imposes a limit of one SMS notification every 5 minutes. Due to this restriction, only 12 SMS messages will be sent per hour (one SMS every 5 minutes).
