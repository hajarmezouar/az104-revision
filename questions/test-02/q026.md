## Énoncé et corrigé fourni


You are working in an Azure subscription called Subscription1.
Within this subscription, you provision an Azure Storage account named contosostorage and then create an Azure Files share called data.
You are writing a script that must access files stored in the data file share.
Which UNC path should the script reference to correctly access those files?
UNC Path to include:
Values to choose from:
- blob
- blob.core.windows.net
- contosostorage
- data
- file
- file.core.windows.net
- portal.azure.com
- subscription1
Réponses:
**☑** contosostorage.file.core.windows.net\data
☐ data.file.core.windows.net\contosostorage
☐ contosostorage.blob.core.windows.net\data
☐ data.blob.core.windows.net\contosostorage
☐ file.subscription1\portal.azure.com
☐ blob.data\file.core.windows.net
Explication
contosostorage.file.core.windows.net\data is correct.
The correct UNC path to include in a script that references files from the `data` file share in the `contosostorage` storage account would be:
`\\contosostorage.file.core.windows.net\data`
Here’s why this is correct:
- The correct format for accessing an Azure file share is `\\<storage-account-name>.file.core.windows.net\<file-share-name>`.
- In this case:
- `<storage-account-name>` is `contosostorage`
- `<file-share-name>` is `data`
Thus, `\\contosostorage.file.core.windows.net\data` is the appropriate path.
