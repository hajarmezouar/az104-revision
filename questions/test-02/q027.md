## Énoncé et corrigé fourni


Your Azure subscription includes two virtual networks with the following characteristics:
- VNet1, deployed in the East US region and peered with VNet2
- VNet2, deployed in the East US region and peered with VNet1
Each virtual network hosts 50 virtual machines.
You are required to deploy Azure Bastion and must ensure that the configuration meets the following criteria:
- Allows automatic scaling of Bastion hosts.
- Supports file upload and download.
- Support the virtual machines on both VNet1 and VNet2.
- Minimize the number of addresses on the Azure Bastion subnet.
You need to configure Azure Bastion.
Which type of Public IP address should you select?
Réponses:
☐ A Basic SKU public IP address that uses dynamic assignment
☐ A Basic SKU public IP address that uses static assignment
**☑** A Standard SKU public IP address that uses static assignment
Explication
`A Standard SKU public IP address that uses static assignment` is correct because it is required to support host scaling and advanced features such as file upload and download when implementing Azure Bastion. The Standard SKU is necessary to meet these requirements, and static allocation of the Public IP ensures a consistent IP address for accessing the Bastion host, which is recommended for production environments.
`A Basic SKU public IP address that uses dynamic assignment` is incorrect because the Basic SKU does not support the necessary features like file upload and download or host scaling.
`A Basic SKU public IP address that uses static assignment` is incorrect because, similar to the dynamic allocation, the Basic SKU does not support the advanced features required for this setup.

- https://learn.microsoft.com/en-us/azure/bastion/configuration-settings
