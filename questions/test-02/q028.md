## Énoncé et corrigé fourni


Your Azure subscription includes two virtual networks with the following characteristics:
- VNet1, deployed in the East US region and peered with VNet2
- VNet2, deployed in the East US region and peered with VNet1
Each virtual network hosts 50 virtual machines.
You are required to deploy Azure Bastion and must ensure that the configuration meets the following criteria:
- Allows automatic scaling of Bastion hosts.
- Supports file upload and download.
- Support the virtual machines on both VNet1 and VNet2.
- Minimize the number of addresses on the Azure Bastion subnet.
You need to configure Azure Bastion.
What subnet size should you use?
Réponses:
☐ /24
**☑** /26
☐ /28
☐ /29
Explication
`/26` is correct because Azure Bastion requires a dedicated subnet called AzureBastionSubnet, and it is recommended to allocate a subnet with at least a /26 prefix to support scaling and additional features. This size provides sufficient IP addresses for supporting multiple concurrent sessions and scaling requirements.
`/24` is incorrect as it is unnecessarily large for this requirement, leading to wasted IP address space.
`/28` and `/29` are incorrect because these subnet sizes are too small and do not provide enough IP addresses to support scaling and the advanced features of Azure Bastion.
Reference(s):
- https://learn.microsoft.com/en-us/azure/bastion/configuration-settings
