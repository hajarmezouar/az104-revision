## Énoncé et corrigé fourni


You are reviewing alert instances in Azure Monitor.
The alert list displays four total alerts, all with a severity level of Verbose (Severity 4).
There are:
- Two instances of Alert2, each with:
- Alert condition: Fired
- User response: New
- Fired time: 4/29/2022, 2:09 PM
- Two instances of Alert1, each with:
- Alert condition: Fired
- User response: Closed
- Fired time: 4/29/2022, 2:04 PM
Based on the information presented, select the answer choice that completes the following statement correctly.
“For Alert2, User response _______________________.”
Réponses:
☐ cannot be modified
☐ can only be changed to Acknowledged
☐ can only be changed to Closed
**☑** can be updated to either Acknowledged or Closed
Explication
`can be updated to either Acknowledged or Closed` is the correct option because an Azure alert currently marked as New can transition to either Acknowledged or Closed, depending on how the issue is being managed. Azure Monitor allows flexibility in alert status transitions, enabling teams to track, acknowledge, or resolve alerts effectively.
`cannot be modified` is incorrect because Azure Monitor supports transitions between alert statuses.
`can only be changed to Acknowledged` is incorrect because the alert can also be transitioned to Closed.
`can only be changed to closed` is incorrect because the alert can also be transitioned to Acknowledged.

- https://learn.microsoft.com/en-us/training/modules/incident-response-with-alerting-on-azure
