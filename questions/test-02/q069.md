## Énoncé et corrigé fourni


You have an Azure subscription that includes the following Azure Container Instances (ACI):
- container1: Deployed in East US, running a Windows image
- container2: Deployed in West US, running a Windows image
- container3: Deployed in East US, running a Linux image
A storage account with an Azure file share named storage1 is created in the East US region.
You need to mount storage1 to supported container instances.
Which container instances can successfully mount storage1?
Réponses:
☐ container1 only
**☑** container3 only
☐ container1 and container2 only
☐ container1 and container3 only
☐ container1, container2, and container3
Explication
`container3 only` is the correct answer because Azure Container Instances (ACI) supports mounting Azure Files only to Linux-based containers, not to Windows-based ones.
Reference(s):
- https://learn.microsoft.com/en-us/azure/container-instances/container-instances-volume-azure-files#limitations
