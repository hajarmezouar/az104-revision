## Énoncé et corrigé fourni


You have an Azure subscription and are preparing to move 50 virtual machines from an on-premises VMware vSphere environment into Azure.
As part of the migration setup, you have already created a Recovery Services vault.
What should you do next to continue the migration process?
Réponses:
☐ Define a recovery plan to orchestrate the migration workflow.
☐ Deploy an Open Virtualization Application (OVA) template to vSphere.
**☑** Set up an Azure virtual network that will host the migrated virtual machines.
☐ Configure a network extension between the on-premises environment and Azure.
Explication
`Set up an Azure virtual network that will host the migrated virtual machines` is correct because for migrating virtual machines from VMware vSphere to Azure using Azure Site Recovery (ASR), the next step after creating a Recovery Services vault is to configure a virtual network in Azure. This network will act as the target network for the VMs once they are migrated.
`Define a recovery plan to orchestrate the migration workflow` is incorrect because creating a recovery plan is part of the orchestration phase of disaster recovery and is not required as the next step in setting up ASR for migration.
`Deploy an Open Virtualization Application (OVA) template to vSphere` is incorrect because using Azure Site Recovery (ASR) does not require the Azure Migrate appliance or an OVA template. The OVA template is specific to Azure Migrate.
`Configure a network extension between the on-premises environment and Azure` is incorrect as configuring an extended network may be part of the networking requirements, but configuring a virtual network in Azure is the immediate next step.
