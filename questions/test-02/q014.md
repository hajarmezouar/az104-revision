## Énoncé et corrigé fourni


You have an Azure subscription.
You plan to create an Azure Storage account with the configuration shown in the following exhibit.
Based on the information presented, select the answer choice that completes the following statement correctly.
“The minimum number of copies of the storage account will be ________.”
Réponses:
☐ 1
☐ 2
**☑** 3
☐ 4
Explication
`3` is correct because the storage account is using Locally-redundant storage (LRS), which replicates data three times within a single data center in the selected region. This ensures that there are three copies of the data, providing local redundancy in case of hardware failures.
