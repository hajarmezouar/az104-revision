## Énoncé et corrigé fourni


You have an application named App1 that is hosted on an Azure App Service web app named webapp1.
Developers in your organization commit an updated version of App1 to a Git repository named Git1.
The webapp1 App Service has the following deployment slots configured:
- webapp1-prod – Production
- webapp1-test – Staging
You must ensure that the updated version of App1 is validated in a test environment before it is made available to end users.
Which two actions should you take?
Réponses (plusieurs réponses possibles)
☐ Stop the webapp1-prod deployment slot.
☐ Deploy the updated version of App1 directly to webapp1-prod, and then perform testing.
**☑** Deploy the updated version of App1 to webapp1-test, and then perform testing.
☐ Stop the webapp1-test deployment slot.
**☑** Perform a swap between the deployment slots.
Explication
`Deploy the updated version of App1 to webapp1-test, and then perform testing` is correct because deploying the update to the webapp1-test slot allows you to test the new version of App1 in a staging environment without impacting the production environment. This approach aligns with best practices for deploying updates to staging before production.
`Perform a swap between the deployment slots` is correct because once testing is complete and the update is verified, you can swap webapp1-test with webapp1-prod. Swapping slots allows you to seamlessly promote the tested version to production without downtime, making the update available to users.
`Stop the webapp1-prod deployment slot` is incorrect because stopping the production slot is unnecessary for testing updates in the staging slot.
`Deploy the updated version of App1 directly to webapp1-prod, and then perform testing` is incorrect because deploying directly to production bypasses the staging environment and does not allow testing before making the update available to users.
`Perform a swap between the deployment slots` is incorrect because stopping the staging slot is not required for testing or deploying updates.
