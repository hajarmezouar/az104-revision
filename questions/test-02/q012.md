## Énoncé et corrigé fourni


You manage a Recovery Services vault named RSV1. The backup policy configured for RSV1 has the following settings:
- Instant snapshots are retained for 5 days
- Daily backup recovery points are retained for 14 days
RSV1 is configured to perform daily backups of a virtual machine named VM1.
VM1 hosts a static website, and the site content was last updated eight days ago.
You must restore VM1 to its state from eight days ago, and the solution must minimize service downtime.
What should you do first?
Réponses:
☐ Delete VM1.
**☑** Restore VM1 by using the Create new restore configuration option.
☐ Deallocate VM1.
☐ Restore VM1 by using the Replace existing restore configuration option.
Explication
`Restore VM1 by using the Create new restore configuration option` is correct because it allows you to recover VM1 to a previous state from eight days ago without affecting the existing VM. This approach minimizes downtime as it creates a new VM instance based on the backup from eight days ago, enabling you to test and verify the restored version separately before making it live if needed.
`Delete VM1` is incorrect because deleting VM1 would not be required to perform the restore operation and would lead to unnecessary downtime and data loss.
`Deallocate VM1` is incorrect because deallocating VM1 is unnecessary for restoring from a backup. This option does not achieve the goal of recovering to a specific point in time.
`Restore VM1 by using the Replace existing restore configuration option` is incorrect because using the replace option would overwrite the current VM, causing downtime while the restore is performed. This does not align with the goal of minimizing downtime.
