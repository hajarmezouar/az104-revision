## Énoncé et corrigé fourni


You have an Azure subscription that includes several virtual machines deployed in the West US Azure region.
You want to use Traffic Analytics in Azure Network Watcher to monitor network traffic for the virtual machines.
Which two resources must you create?
Réponses (plusieurs réponses possibles)
**☑** a storage account
☐ a Microsoft Sentinel workspace
**☑** a Log Analytics workspace
☐ a Data Collection Rule (DCR) in Azure Monitor
☐ an Azure Monitor workbook
Explication
`a storage account` is correct because Traffic Analytics in Azure Network Watcher requires a storage account to store NSG flow logs. These logs capture information about the traffic to and from virtual machines, which Traffic Analytics uses for analysis.
`a Log Analytics workspace` is correct because Traffic Analytics processes the data collected from NSG flow logs and stores it in a Log Analytics workspace. This workspace allows you to query and analyze the traffic data collected by Traffic Analytics.
`a Microsoft Sentinel workspace` is incorrect because while Microsoft Sentinel can integrate with Log Analytics for security purposes, it is not required specifically for Traffic Analytics in Azure Network Watcher.
`a Data Collection Rule (DCR) in Azure Monitor` is incorrect because DCRs are used for configuring data collection in Azure Monitor but are not required for setting up Traffic Analytics.
`an Azure Monitor workbook` is incorrect because an Azure Monitor workbook provides visualization for data already collected in Azure Monitor or Log Analytics but is not a requirement for enabling Traffic Analytics.
Reference(s):
