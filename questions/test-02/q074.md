## Énoncé et corrigé fourni


You have an Azure subscription that contains the following vaults:
- Recovery1 – Recovery Services vault
- Backup1 – Azure Backup vault
You deploy two virtual machines:
- VM1 – Windows Server, configured with Azure Disk Encryption
- VM2 – Linux, configured with Trusted launch
The following backup policies are configured:
True or False:
`“VM1 can be backed up by using Policy1.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here. VM1 is a Windows Server virtual machine that uses Azure Disk Encryption and is intended to be backed up using a Recovery Services vault. According to Azure backup support policies, Standard policy types in Recovery Services vaults fully support backing up Windows VMs with Azure Disk Encryption enabled. Policy1, being a Standard policy in the Recovery1 vault, is compatible with this scenario.
There is no limitation that prevents using a Standard policy for encrypted Windows VMs when the vault type is Recovery Services vault. Azure officially supports encrypted disks with both Standard and Enhanced policies for Windows VMs.
Reference(s.):
- https://learn.microsoft.com/en-us/azure/backup/backup-support-matrix
- https://learn.microsoft.com/en-us/azure/backup/backup-azure-vms-introduction
