## Énoncé et corrigé fourni


You are reviewing alert instances in Azure Monitor.
The alert list displays four total alerts, all with a severity level of Verbose (Severity 4).
There are:
- Two instances of Alert2, each with:
- Alert condition: Fired
- User response: New
- Fired time: 4/29/2022, 2:09 PM
- Two instances of Alert1, each with:
- Alert condition: Fired
- User response: Closed
- Fired time: 4/29/2022, 2:04 PM
Based on the information presented, select the answer choice that completes the following statement correctly.
“For Alert1, User response _______________________.”
Réponses:
☐ cannot be modified
☐ can only be changed back to New
☐ can only be changed to Acknowledged
**☑** can be updated to either New or Acknowledged
Explication
`can be updated to either New or Acknowledged` is the correct option because in Azure Monitor, an alert's status can be changed between New, Acknowledged, and Closed at any point based on the current state or requirement. Even if an alert is marked as Closed, it can be reopened and transitioned back to New or Acknowledged. This flexibility allows teams to revisit alerts and reassess their status as conditions change.

- https://learn.microsoft.com/en-us/training/modules/incident-response-with-alerting-on-azure/
