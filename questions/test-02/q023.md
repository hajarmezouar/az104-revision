## Énoncé et corrigé fourni


You are working in an Azure subscription that includes a storage account named storage1.
The following client devices are available:
- Device1 - running Windows 10
- Device2 -  running Linux
- Device3 -  running macOS
You want to transfer data to storage1 by using the AzCopy utility.
From which of the listed devices can you perform this operation?
Réponses:
☐ Device1 and Device2 only
☐ Device1 only
☐ Device1 and Device3 only
**☑** Device1, Device2, and Device3
Explication
`Device1, Device2, and Device3` is correct because AzCopy is a cross-platform command-line utility available for Windows, Linux, and macOS. This means it can be used on all three devices listed in the table to copy data to an Azure storage account.
Reference(s):
https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azcopy-v10?tabs=dnf#download-azcopy
