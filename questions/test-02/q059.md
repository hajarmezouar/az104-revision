## Énoncé et corrigé fourni


You have an Azure subscription that contains virtual machines running Windows Server, configured as shown in the table below:
You create the following DNS resources:
- A public Azure DNS zone named adatum.com
- A private Azure DNS zone named contoso.com
You then create a virtual network link between the contoso.com private DNS zone and VNET2, with auto-registration enabled.
True or False:
`"When VM2 starts, a DNS record for VM2 is created in the contoso.com DNS zone."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because VM2 is also in VNET2, which is linked to the `contoso.com` private DNS zone with auto-registration enabled. Azure will register VM2’s DNS record in `contoso.com`, regardless of any DNS suffix configured in the VM's OS. Azure Private DNS zones do not consider the OS-configured DNS suffix; they rely solely on the VNet linkage and auto-registration settings.
