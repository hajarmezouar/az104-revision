## Énoncé et corrigé fourni


An Azure subscription contains a resource group named RG1.
You intend to deploy a new storage account called storage1 by using infrastructure-as-code. A Bicep file named File1 is available and will be used for this deployment.
To ensure that storage1 is automatically deployed into RG1, you must modify File1 accordingly.
Which property in the Bicep file should you change?
Réponses:
☐ kind
**☑** scope
☐ sku
☐ location
Explication
`scope` is correct because setting the scope property is necessary to target a specific resource group, such as RG1, when deploying resources in Bicep. By configuring the scope property, you direct the deployment of storage1 specifically to RG1. This approach is especially useful when deploying resources to a resource group that isn’t the default target in the Bicep file.
`kind` is incorrect because it specifies the type of storage account (e.g., StorageV2, BlobStorage) and does not control the deployment target.
`sku` is incorrect because it defines the storage account’s performance and redundancy (e.g., Standard_LRS, Standard_GRS) but does not determine the deployment target resource group.
`location` is incorrect because it specifies the Azure region for the storage account, but does not target the resource group for deployment.
