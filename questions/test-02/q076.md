## Énoncé et corrigé fourni


You have an Azure subscription that contains the following vaults:
- Recovery1 – Recovery Services vault
- Backup1 – Azure Backup vault
You deploy two virtual machines:
- VM1 – Windows Server, configured with Azure Disk Encryption
- VM2 – Linux, configured with Trusted launch
The following backup policies are configured:
True or False:
`“VM2 can be backed up by using Policy2.”`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer. Enhanced backup policies are used specifically for protecting Azure virtual machines in Recovery Services vaults, and they support advanced scenarios such as Trusted Launch virtual machines. Since Policy2 is defined as an Enhanced policy, it must be associated with a Recovery Services vault, because Backup vaults do not support VM backup policies of this type.
Even though Recovery2 is not explicitly listed among the available vaults, the presence of an Enhanced policy implicitly indicates that it belongs to a Recovery Services vault. Azure Backup supports protecting Linux virtual machines configured with Trusted Launch when using Enhanced policies in a Recovery Services vault. Therefore, VM2 meets the requirements for being backed up using Policy2.
