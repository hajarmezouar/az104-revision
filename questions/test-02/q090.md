## Énoncé et corrigé fourni


You are planning to create an Azure Storage account named storage1, which will host an Azure file share called share1. The file share must support SMB Multichannel, and the overall configuration should be chosen in a way that keeps costs as low as possible.
How should storage1 be configured to meet these requirements?
Réponses:
☐ Standard performance with locally-redundant storage (LRS)
**☑** Premium performance with locally-redundant storage (LRS)
☐ Standard performance with zone-redundant storage (ZRS)
Explication
`Premium performance with locally redundant storage (LRS)` is correct because SMB Multichannel is only supported on Premium File Shares, which use SSD-based storage. These premium shares deliver high throughput and low latency required for parallel SMB connections. Using LRS keeps costs minimal while maintaining adequate redundancy within a single region.
`Standard performance with LRS` and `Standard performance with ZRS` are incorrect because SMB Multichannel is not available on Standard File Shares, regardless of redundancy type. These tiers are optimized for general file storage and lower-cost scenarios, but they lack the performance capabilities and protocol support needed for SMB Multichannel.
