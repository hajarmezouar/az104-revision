## Énoncé et corrigé fourni


You are planning to deploy an Azure Container Instance by using the Azure Resource Manager (ARM) template shown.
{
"type": "Microsoft.ContainerInstance/containerGroups",
"apiVersion": "2018-10-01",
"name": "webprod",
"location": "westus",
"properties": {
"containers": [
{
"name": "webprod",
"properties": {
"image": "microsoft/iis:nanoserver",
"ports": [
{
"protocol": "TCP",
"port": 80
}
],
"environmentVariables": [],
"resources": {
"requests": {
"memoryInGB": 1.5,
"cpu": 1
}
}
}
}
],
"restartPolicy": "OnFailure",
"ipAddress": {
"ports": [
{
"protocol": "TCP",
"port": 80
}
],
"ip": "[parameters('IPAddress')]",
"type": "Public"
},
"osType": "Windows"
}
}
Based on the configuration provided, choose the option that correctly completes the following statement:
“If Internet Information Services (IIS) running inside the container fails, ____________________.”
Réponses:
**☑** the container instance will restart automatically
☐ the container instance will restart only through a manual action
☐ the container instance must be redeployed
Explication
`the container instance will restart automatically` is correct because the template specifies a restart policy of "OnFailure", which means that if the application within the container (in this case, Internet Information Services or IIS) fails, the container instance will automatically restart.
`the container instance will restart only through a manual action` is incorrect because the "OnFailure" restart policy ensures that the container restarts automatically upon a failure.
`the container instance must be redeployed` is incorrect because the container does not need to be redeployed; it will automatically restart based on the defined restart policy.
Reference(s):
- https://learn.microsoft.com/en-us/azure/container-instances/container-instances-restart-policy
