## Énoncé et corrigé fourni


You are planning to migrate a distributed on-premises application named App1 to Azure.
After the migration is complete:
- App1 will run across nine Azure virtual machines
- The application must remain highly available during planned Azure platform maintenance
You must design the solution so that at least eight virtual machines remain operational whenever Azure performs planned maintenance activities.
Which solution should you implement?
Réponses:
☐ Create a single virtual machine scale set configured with 12 VM instances.
**☑** Create a single virtual machine scale set configured with 10 VM instances.
☐ Create one availability set configured with three fault domains and one update domain.
☐ Create one availability set configured with 10 update domains and one fault domain.
Explication
`Create a single virtual machine scale set configured with 10 VM instances` is the correct answer here. Azure Virtual Machine Scale Sets (VMSS) automatically distribute VM instances across fault and update domains to provide high availability. By default, VMSS placement groups are configured with 5 fault domains and 5 update domains, and update domains are updated one at a time during planned Azure maintenance.
With 10 instances spread across 5 update domains, each update domain will host 2 VMs. During a planned update, only one update domain is affected at a time, meaning at most 2 out of 10 VMs are impacted, and at least 8 VMs remain running, which satisfies the requirement.
`Create a single virtual machine scale set configured with 12 VM instances` is incorrect because it exceeds the requirement unnecessarily. While it would also ensure 8 VMs are running during maintenance, it's not optimal in terms of cost and resource efficiency.
`Create one availability set configured with three fault domains and one update domain` is incorrect because a single update domain means all VMs in the set could be impacted at once during planned maintenance, violating the requirement of keeping at least 8 VMs up.
`Create one availability set configured with 10 update domains and one fault domain` is incorrect because, although Azure can support this availability set configuration, it is not the best solution for this scenario. The requirement is to keep at least eight virtual machines operational during planned Azure platform maintenance for an application that runs across nine virtual machines. A single virtual machine scale set with 10 VM instances provides a more suitable and scalable design because Azure distributes the instances across update domains and updates one update domain at a time during planned maintenance. This ensures that at most two VMs are affected at a time and at least eight VMs remain operational.
