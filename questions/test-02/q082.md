## Énoncé et corrigé fourni


You have an Azure virtual machine named VM1 and an Azure Key Vault named Vault1. You plan to enable Azure Disk Encryption on VM1 and use a key encryption key (KEK) stored in Vault1.
Before configuring disk encryption, you must ensure that Vault1 is properly prepared to support Azure Disk Encryption.
Which two configuration actions must be performed on Vault1 to meet this requirement?
Réponses (plusieurs réponses possibles)
**☑** Create a new key.
☐ Select Azure Virtual machines for deployment.
**☑** Select Azure Disk Encryption for volume encryption.
☐ Configure a key rotation policy.
☐ Create a new secret.
Explication
`Create a new key` is correct because Azure Disk Encryption with a key encryption key (KEK) requires a key vault key (not a secret) to wrap the encryption key used to encrypt the VM disks.
`Select Azure Disk Encryption for volume encryption` is correct because the key vault must have the “Azure Disk Encryption for volume encryption” permission enabled. This allows the disk encryption process to access the key vault during encryption and decryption operations.
`Select Azure Virtual machines for deployment` is incorrect because this setting is related to deployment credentials for virtual machines, not required for enabling encryption.
`Configure a key rotation policy` is incorrect because although key rotation is good practice for long-term security, it's not required to prepare the key vault for Azure Disk Encryption.
`Create a new secret` is incorrect because secrets are not used in KEK-based encryption. The process uses a key, not a secret, to wrap the encryption key.
