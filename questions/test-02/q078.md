## Énoncé et corrigé fourni


You are planning to deploy a new Azure App Service application named WebApp1. The configuration must satisfy the following conditions:
- WebApp1 must support validating a custom domain name: app.bluerock.com.
- WebApp1 must be able to automatically scale up to a maximum of eight instances.
- The selected solution should keep costs low and reduce ongoing administrative overhead as much as possible.
Based on these requirements, which record type should you use to verify the domain?
Réponses:
☐ A
☐ AAAA
☐ PTR
**☑** TXT
Explication
`TXT` is the correct answer here. To verify a custom domain name like `app.bluerock.com` for an Azure App Service app (such as WebApp1), Azure requires the domain owner to prove ownership by adding a `TXT` record to the domain’s DNS zone. This record contains a unique verification string provided by Azure and is the standard method for verifying custom domains in App Service. It enables the service to confirm that you have administrative control over the domain before allowing it to be associated with the app.
`A` is incorrect because while it maps a domain name to an IPv4 address, it is not used for domain verification. It is generally used for pointing domain names to web servers or hosting environments.
`AAAA` is incorrect because it maps a domain to an IPv6 address and, like the `A` record, is used for routing rather than ownership verification.
`PTR` is incorrect because it is used for reverse DNS lookups (resolving IP addresses to domain names), which is unrelated to domain ownership verification for web apps.
