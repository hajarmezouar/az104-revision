## Énoncé et corrigé fourni


You have an Azure subscription that contains virtual machines running Windows Server, configured as shown in the table below:
You create the following DNS resources:
- A public Azure DNS zone named adatum.com
- A private Azure DNS zone named contoso.com
You then create a virtual network link between the contoso.com private DNS zone and VNET2, with auto-registration enabled.
True or False:
`"When VM1 starts, a DNS record for VM1 is created in the contoso.com DNS zone."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because VM1 is in VNET2, and VNET2 is linked to the `contoso.com` private DNS zone with auto-registration enabled. Azure will automatically register the DNS record for VM1 in the `contoso.com` zone. The DNS suffix configured inside the VM (e.g., `contoso.com`) does not affect auto-registration; Azure registers the VM in the zone linked to its VNet, not based on the VM’s internal settings.
