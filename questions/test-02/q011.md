## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that contains the resources shown in the following table.
Within storage1, you create a blob container named blob1 and a file share named share1.
Which of the listed resources are eligible to be backed up to `Vault2`?
Réponses:
☐ storage1 only
**☑** share1 only
☐ VM1 and share1 only
☐ blob1 and share1 only
☐ storage1 and SQL1 only
Explication
`share1 only` is correct because Vault2 is a Recovery Services vault located in West US and can only back up resources within the same region. share1 is an Azure file share in storage1 (also located in West US) and is eligible for backup by the Recovery Services vault. Blobs are not supported for backup in a Recovery Services vault, and VM1 is in Central US, so it cannot be backed up by Vault2.
`storage1 only` is incorrect because Recovery Services vaults do not directly back up storage accounts themselves. They can back up Azure file shares within a storage account, but not the storage account as a whole.
`VM1 and share1 only` is incorrect because VM1 is located in Central US, not West US, so it cannot be backed up by Vault2.
`blob1 and share1 only` is incorrect because blobs cannot be backed up by a Recovery Services vault. Only file shares within a storage account are eligible for backup, provided they are in the same region.
`storage1 and SQL1 only` is incorrect because SQL1 is located in East US and cannot be backed up by Vault2 in West US.
