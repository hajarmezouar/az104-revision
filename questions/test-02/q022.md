## Énoncé et corrigé fourni


Your Azure environment contains the following virtual machines:
- VM1 and VM2, both deployed in the West Europe region
- VM3 and VM4, both deployed in the North Europe region
A Recovery Services vault is already in place and is currently configured to back up VM1 and VM2.
You now need to enable Recovery Services protection for VM3 and VM4.
What is the first action you should take?
Réponses:
**☑** Create a new Recovery Services vault
☐ Provision a new storage account
☐ Set up the required extensions on VM3 and VM4.
☐ Define and configure a new backup policy
Explication
`Create a new Recovery Services vault` is correct because a Recovery Services vault must be in the same region as the virtual machines it protects. Since VM3 and VM4 are in the "North Europe" region, a new Recovery Services vault must be created in that region to back up these virtual machines.
`Provision a new storage account` is incorrect because a storage account is not required for setting up backups through Recovery Services Vaults.
`Set up the required extensions on VM3 and VM4` is incorrect because configuring extensions is not the initial step required to back up these VMs. Extensions are typically configured as part of the backup process.
`Define and configure a new backup policy` is incorrect because a backup policy does not address the requirement of having a Recovery Services vault in the correct region for VM3 and VM4.
