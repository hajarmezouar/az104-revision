## Énoncé et corrigé fourni


You have an Azure subscription with a Microsoft Entra ID P1 license. You need to enable self-service password reset for all users and ensure that, during registration, users are required to answer four security questions.
Which two settings should you use?
Réponses (plusieurs réponses possibles)
**☑** Properties
**☑** Authentication methods
☐ Registration
☐ Notifications
☐ Customization
☐ On-premises integration
Explication
Properties is the correct answer because this setting allows you to enable Self-Service Password Reset (SSPR) for either a specific group or for all users in the tenant. This directly meets the requirement of enabling SSPR for all users.
Authentication methods is the correct answer because this setting is used to configure how many and which authentication methods users must provide to reset their passwords. It specifically allows you to require users to answer a minimum number of security questions, which fulfills the requirement to answer four questions during registration.
Registration is incorrect because this setting controls whether users are prompted to register their authentication methods for SSPR and MFA, but it does not allow you to enable SSPR itself or configure how many questions must be answered.
Notifications is incorrect because this setting only manages whether users and administrators receive email notifications for password reset events; it does not configure SSPR eligibility or authentication question settings.
Customization is incorrect because this setting is used for UI branding and does not affect SSPR registration or authentication method configuration.
On-premises integration is incorrect because it is used to configure integration with on-premises Active Directory for password writeback, not to manage SSPR enablement or question requirements.
