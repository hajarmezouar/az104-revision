## Énoncé et corrigé fourni


Your organization purchases a new Azure subscription and creates an ARM template file named deploy.json, as shown in the below exhibit. The template provisions multiple resource groups and applies management locks with different lock levels to specific resource groups by using nested deployments.
After connecting to the subscription, you run the New-AzDeployment cmdlet with the template file and a deployment location of West US as shown below:
`New-AzDeployment -Location westus -TemplateFile “deploy.json”`
Based on this deployment, determine whether the following statement is True or False:
`"You can deploy a virtual machine to RG2."`
Réponses:
☐ True
**☑** False
Explication
`True` is the correct answer because the ARM template applies a ReadOnly lock to the resource group RG2. A ReadOnly lock prevents any write operations within the resource group, including creating, updating, or deleting resources. Therefore, you cannot deploy a virtual machine or any other resource to RG2 while the lock is in place.

- https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/lock-resources
- https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-syntax#copy-loop-for-resources
