## Énoncé et corrigé fourni


An Azure subscription contains eight virtual machines and the following resources:
You are required to configure network access for VNet1 while meeting these conditions:
- Virtual machines in VNet1 must be able to communicate with virtual machines in VNet2 over the Microsoft backbone network.
- Virtual machines in VNet1 must be able to securely access storage1, storage2, and Microsoft Entra using the Microsoft backbone.
To satisfy these requirements, you plan to use service endpoints.
What is the minimum number of service endpoints that must be enabled on VNet1?
Réponses:
**☑** 1
☐ 2
☐ 3
☐ 5
Explication
`1` is correct because we can use 1 service endpoint for all storage accounts deployed in the same region. Apart from this, the service endpoint is not needed for Microsoft Entra, because VMs accessing Microsoft Entra users (e.g., for user management, authentication, or authorization purposes) relies on Microsoft Entra's authentication and authorization mechanisms, and it doesn't require a service endpoint. Microsoft Entra is a cloud-based identity and access management service that operates independently of a VNet's service endpoints.
Setting up a service endpoint for Microsoft Entra can be advantageous in specific situations, like when VMs require secure access to Microsoft Entra-related APIs. However, it's not mandatory for VMs to connect with Microsoft Entra users or entities.
While it's possible to use two service endpoints for two separate storage accounts, the question asks for the least number of endpoints necessary.
