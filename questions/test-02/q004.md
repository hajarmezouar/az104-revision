## Énoncé et corrigé fourni


You are required to configure an Azure App Service web app named bluerock.azurewebsites.net so that it can host the custom domain www.bluerock.com.
What action should you perform first?
Réponses:
**☑** Create a TXT record named asuid that includes the domain verification identifier.
☐ Create a TXT record named www.bluerock.com with a value pointing to bluerock.azurewebsites.net.
☐ Create a CNAME record named asuid that includes the domain verification identifier.
☐ Create A records for www.bluerock.com and asuid.bluerock.com.
Explication
`Create a TXT record named asuid that includes the domain verification identifier` is correct because, to verify a custom domain for an Azure web app, you first need to create a TXT record with the name asuid in the DNS zone of your domain. This TXT record should contain the domain verification ID provided by Azure. This step is essential to prove ownership of the domain before configuring it to point to the Azure web app.
`Create a TXT record named www.bluerock.com with a value pointing to bluerock.azurewebsites.net` is incorrect because a TXT record with this configuration will not verify domain ownership. The asuid TXT record with the verification ID is required for domain verification.
`Create a CNAME record named asuid that includes the domain verification identifier` is incorrect because a TXT record (not a CNAME) is required for domain verification purposes.
`Create A records for www.bluerock.com and asuid.bluerock.com` is incorrect because A records are not used for domain verification. A TXT record with asuid is required for the initial verification step.
