## Énoncé et corrigé fourni


You are working within an Azure subscription and must deploy an Azure Container Instance named cont1.
The deployment must satisfy the following conditions:
- Ensure that specific configuration parameters are applied to cont1 during the container startup.
- Provide secure values to cont1 during the container startup.
What should you configure for cont1?
Réponses:
☐ a command override
☐ tags
☐ customer-managed keys
**☑** environment variables
Explication
`environment variables` is correct because they allow you to set specific configuration parameters and pass secure values (such as sensitive data or credentials) to the container instance cont1 during startup. Environment variables can be securely stored in Azure and referenced in the container, meeting both requirements.
`a command override` is incorrect because it allows you to override the default command for a container but does not handle secure values or configuration parameters needed during startup.
`tags` is incorrect because tags are used for organizing and categorizing resources in Azure but are not used to pass configuration parameters or secure values to containers.
`customer-managed keys` is incorrect because they are related to encryption in Azure and do not provide a mechanism for applying configuration parameters or passing secure values to a container instance at startup.
Reference(s):
https://learn.microsoft.com/en-us/azure/container-instances/container-instances-environment-variables
