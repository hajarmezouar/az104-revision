## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1. The subscription is associated with a Microsoft Entra tenant named bluerock.com, which is synchronized with an on-premises Active Directory domain. This on-premises domain contains the following security principals:
- User1, which is a user account.
- Computer1, which is a computer account.
In Microsoft Entra tenant, you create a user named User2.
The storage1 account contains an Azure file share named share1 and is configured to use Active Directory–based authentication for Azure Files and has the following configurations.
"kind": "StorageV2",
"properties": {
"azureFilesIdentityBasedAuthentication": {
"directoryServiceOptions": "AD",
"activeDirectoryProperties": {
"domainName": "Bluerock.com",
"netBiosDomainName": "Bluerock.com",
"forestName": "Bluerock.com"
. . .
}
}
True or False:
`"User2 can access share1 over SMB by using identity-based authentication after being assigned the Storage File Data SMB Share Elevated Contributor role."`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because User2 is a cloud-only user created directly in Microsoft Entra ID and does not have a corresponding identity in the on-premises Active Directory Domain Services (AD DS) environment.
The storage account storage1 is configured to use on-premises AD DS for Azure Files identity-based authentication, as indicated by `"directoryServiceOptions": "AD"`. When using AD DS authentication with granular share-level Azure RBAC permissions, the corresponding identity must originate from the on-premises AD DS environment and be represented in Microsoft Entra ID.
User2 exists only in Microsoft Entra ID and therefore cannot authenticate to share1 by using the configured AD DS authentication. Assigning the Storage File Data SMB Share Elevated Contributor role does not change the authentication method or provide User2 with an on-premises AD DS identity.
Therefore, User2 cannot access share1 over SMB by using the configured identity-based authentication, even after the role is assigned.
