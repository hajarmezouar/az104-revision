## Énoncé et corrigé fourni


Your Azure subscription includes the storage accounts described below:
- storage1
- Microsoft Entra authentication: Enabled
- Contains a blob container named container1 with no public access
- storage2
- Microsoft Entra authentication: Enabled
- Contains an Azure Files share named share1
You intend to use AzCopy to transfer a blob directly from container1 in storage1 to share1 in storage2.
To complete this operation, you must choose an appropriate authentication mechanism for AzCopy.
Which authentication method should you use when accessing "storage2"?
Réponses:
☐ OAuth
☐ Anonymous
☐ A storage account access key
**☑** A shared access signature (SAS) token
Explication
`A shared access signature (SAS) token` is correct because Azure File shares only support SAS as an authentication method for all operations when using AzCopy. This ensures secure access and aligns with the access control requirements for file shares in AzCopy operations.
`OAuth`, `Anonymous`, and `A storage account access key` are incorrect because Azure File shares exclusively support SAS for all types of operations with AzCopy. Therefore, these methods cannot be used in this scenario.
