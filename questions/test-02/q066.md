## Énoncé et corrigé fourni


You are working in an Azure subscription and plan to deploy a storage account named storage1 by using an Azure Resource Manager (ARM) template.
The template configuration enables several data protection features for the Blob service, including blob versioning, soft delete, container soft delete, and point-in-time restore with specific retention periods.

True or False:
`"Changes made to the data in storage1 can be rolled back after seven days"`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer because the configuration specifies a restorePolicy with the following settings:
- "enabled": true
- "days": 6"
This means the maximum duration for point-in-time recovery of blob data is 6 days. Any changes made beyond this period cannot be rolled back. The statement specifically mentions rolling back data changes after 7 days, which exceeds the configured recovery window.
The deleteRetentionPolicy and containerDeleteRetentionPolicy are both set to 7 days, but these policies only apply to deleted blobs and containers. They do not allow point-in-time recovery of modified data beyond the 6-day limit set in the restore policy.
