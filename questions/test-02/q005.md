## Énoncé et corrigé fourni


You are planning to deploy an Azure Container Instance by using the Azure Resource Manager (ARM) template shown.
{
"type": "Microsoft.ContainerInstance/containerGroups",
"apiVersion": "2018-10-01",
"name": "webprod",
"location": "westus",
"properties": {
"containers": [
{
"name": "webprod",
"properties": {
"image": "microsoft/iis:nanoserver",
"ports": [
{
"protocol": "TCP",
"port": 80
}
],
"environmentVariables": [],
"resources": {
"requests": {
"memoryInGB": 1.5,
"cpu": 1
}
}
}
}
],
"restartPolicy": "OnFailure",
"ipAddress": {
"ports": [
{
"protocol": "TCP",
"port": 80
}
],
"ip": "[parameters('IPAddress')]",
"type": "Public"
},
"osType": "Windows"
}
}
Based on the configuration provided, choose the option that correctly completes the following statement:
“Internet users ________________________________________.”
Réponses:
**☑** are able to connect to the container instance from any device.
☐ are not able to connect to the container instance.
☐ are only able to connect to the container instance from devices running Windows.
Explication
`are able to connect to the container instance from any device` is correct because the template specifies a public IP address ("type": "Public") and opens TCP port 80, which is a common HTTP port accessible from any internet-enabled device. This configuration allows internet users to connect to the container instance without restrictions on device type.
`are not able to connect to the container instance` is incorrect because the template has a public IP and open port 80, making the container accessible from the internet.
`are only able to connect to the container instance from devices running Windows` is incorrect because there is no configuration in the template that restricts access to specific operating systems.
