## Énoncé et corrigé fourni


Note: This question is part of a series that uses the same overall scenario. Each question in the series proposes a different solution that may or may not satisfy the stated requirement.
You have a Microsoft Entra tenant named Bluerock.com and an Azure subscription called Subscription1. Within Bluerock.com, there is a security group named Developers. Within Subscription1, there is a resource group named Dev.
You must grant the Developers group permissions that allow them to create Azure Logic Apps within the Dev resource group.
Proposed solution: At the Subscription1 scope, you grant the Developers group the Logic App Contributor role.
Does this solution satisfy the requirement?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is correct because the Logic App Contributor role grants permissions to create and manage Azure Logic Apps within a specified scope, such as a subscription or resource group. This role enables the Developers group to create Azure Logic Apps in the Dev resource group. While the Logic App Contributor role allows for creation and management, it does not permit assigning or modifying access to these Logic Apps, which is not a requirement in this scenario.
- The Logic App Operator role only allows actions such as reading, enabling, or disabling Logic Apps but does not permit their creation or editing, making it insufficient for the stated goal.
- The Logic App Contributor role meets the goal by enabling the necessary level of management without over-provisioning permissions.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#logic-app-contributor
