## Énoncé et corrigé fourni


You manage an Azure Storage account named dataarchive01, which contains a blob container called images. This container holds a a large collection of image files.
You plan to deploy an Azure Resource Manager (ARM) template to configure a blob inventory rule named inventoryRule1.
The configuration must ensure that a daily inventory report is generated in CSV format and stored in the images container. The report must include only those blobs whose names start with the prefix “finance”.
You need to complete the configuration of rule1, shown below.
Which value should you choose for Code Segment B?
Réponses:
☐ images/*
**☑** images/finance
☐ finance
Explication
`images/finance` is the correct answer. According to the documentation, the prefix match string in a blob policy must always start with the container name followed by the desired blob name prefix. In this case, "images" is the container, and "finance" is the required blob prefix, making images/finance the appropriate match string for blobs starting with the word "finance."
`images/*` is incorrect because it would match all blobs within the container and not only those starting with "finance."
`finance` is incorrect because it does not include the container name as required by the blob policy format.
Reference(s):
- https://learn.microsoft.com/en-us/azure/storage/blobs/storage-blob-faq#the-blob-prefix-match-string-didn-t-apply-the-policy-to-the-expected-blobs
