## Énoncé et corrigé fourni


You have two Azure subscriptions named Sub1 and Sub2. Sub1 is in a management group named MG1. Sub2 is in a management group named MG2.
The following resource groups exist in the subscriptions:
Name      Subscription
**------      --------------
RG1          Sub1
RG2         Sub2**
The following virtual machines are deployed:
Name      Resource group
**------      --------------
VM1          RG1
VM2         RG2
VM3         RG2**
You assign roles to users as shown in the following table.
Name      Role                                                Resource
**------      -----------------------------      ----------
User1      Virtual Machine Contributor      MG1**
User1      Virtual Machine User Login       Sub2
User2     Virtual Machine Contributor      MG2
User2     Virtual Machine User Login       Sub1
User2     Virtual Machine User Login       VM3
True of False:
`"User2 has the ability to administer the disks and disk snapshots associated with VM1."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because User2 has the "Virtual Machine Contributor" role assigned to management group MG2, which includes Sub2, but VM1 is located in Sub1. Therefore, User2 does not have the necessary permissions to manage the disks or disk snapshots for VM1. The "Virtual Machine Contributor" role assigned at MG2 does not apply to resources in Sub1, including VM1. As a result, User2 cannot manage disks or snapshots of VM1.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles
