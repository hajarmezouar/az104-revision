## Énoncé et corrigé fourni


**Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You manage an Azure Container Registry named corpRegistry that contains a container image called webappimage.
When you try to deploy an Azure Container Instance using webappimage, the deployment process fails with an error.
You must ensure that a container instance can be deployed successfully using the image stored in corpRegistry.
Proposed solution: `You set Admin user to Enable for corpRegistry.`
Does this solution meet the requirement?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is correct because enabling the Admin user on the Azure container registry provides credentials (username and password) that can be used to authenticate and pull images from the registry. This can resolve authentication issues when deploying a container instance, as the container instance can use the admin credentials to access the registry and pull image1. This is a quick solution to grant access, especially when other identity-based methods, such as Microsoft Entra, are not configured.

- https://learn.microsoft.com/en-us/azure/container-registry/container-registry-authentication?tabs=azure-cli
- https://learn.microsoft.com/en-us/azure/container-instances/container-instances-using-azure-container-registry
