## Énoncé et corrigé fourni


You have a Microsoft Entra tenant with the following characteristics:
- Tenant name: Default Directory
- License type: Microsoft Entra ID Free
- Primary domain: an onmicrosoft.com domain
The tenant includes these identities:
- UserA - User account
- SecGroup01 - Security group
- M365Group01 - Microsoft 365 group
You purchase a Microsoft Fabric license.
Which of the listed identities can be assigned the Microsoft Fabric license?
Réponses:
**☑** UserA only
☐ UserA and SecGroup01 only
☐ UserA and M365Group01 only
☐ UserA, SecGroup01, and M365Group01
Explication
`UserA only` is correct because in a free Microsoft Entra ID tenant, you can only assign licenses to individual users like UserA. Group-based licensing (for SecGroup01 or M365Group01) requires a paid version of Microsoft Entra ID (such as P1 or P2).
`UserA and SecGroup01 only` is incorrect because, in the free version, SecGroup01 (a security group) cannot be assigned licenses.
`UserA and M365Group01 only` is incorrect for the same reason. Group-based licensing (whether it's a security group or a Microsoft 365 group) is not supported in the free tier.
`UserA, SecGroup01, and M365Group01` is incorrect since neither SecGroup01 nor M365Group01 can have licenses assigned in the free tenant.
Reference(s):
- https://learn.microsoft.com/en-us/entra/fundamentals/concept-group-based-licensing
