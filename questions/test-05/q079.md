## Énoncé et corrigé fourni


Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You have three Azure subscriptions named Sub1, Sub2, and Sub3, all associated with a single Microsoft Entra tenant.
The tenant includes a user named User1, a security group named Group1, and a management group named MG1. User1 is a member of Group1.
Both Sub1 and Sub2 are assigned to MG1.
Sub1 contains a resource group named RG1, and RG1 hosts five Azure Functions.
The following role assignments are configured at the MG1 scope:
- Group1 is assigned the Reader role
- User1 is assigned the User Access Administrator role
Additionally:
- User1 is assigned the Virtual Machine Contributor role on Sub1 and Sub2
- User1 is assigned the Contributor role on RG1
True or False:
`"User1 can assign the Owner role for RG1."`
Réponses:
**☑** True
☐ False
Explication
`True` is the correct answer here. User1 is assigned the User Access Administrator role at the management group (MG1) level. This role grants the ability to manage role assignments (i.e., grant or remove access) on resources within that scope and all its child scopes—including subscriptions and resource groups beneath MG1. Since Sub1 is part of MG1, and RG1 is inside Sub1, the User Access Administrator permission applies to RG1 as well.
While Contributor alone does not allow role assignment, the User Access Administrator role is specifically designed to allow assigning any RBAC role, including Owner, as long as the user has this role at the appropriate level—which User1 does in this case.
Therefore, User1 can assign the Owner role for RG1, even if they are not currently an Owner themselves.
