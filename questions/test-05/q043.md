## Énoncé et corrigé fourni


You are working with an Azure subscription.
A user-defined route table named RT1 has been created.
You must add a route to RT1 that requires specifying an IP address for the next hop.
Which next hop option should you choose when configuring the route?
Réponses:
☐ Internet
☐ Virtual network gateway
☐ Virtual network
**☑** Virtual appliance
Explication
`Virtual appliance` is the correct answer here. When adding a route to a routing table and specifying a next hop IP address, the correct next hop type is Virtual appliance. A virtual appliance refers to a Network Virtual Appliance (NVA), such as a firewall or load balancer, which inspects or processes network traffic. By choosing Virtual appliance, you can specify the IP address of the NVA that will handle the routed traffic.
`Internet` is incorrect because it routes traffic directly to the public internet without specifying a next hop IP address.
`Virtual network gateway` is incorrect because it is used to route traffic to an Azure VPN gateway for on-premises connectivity.
`Virtual network` is incorrect because it routes traffic within the same virtual network and does not require specifying a next hop IP address.
Reference(s):
- https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-udr-overview
