## Énoncé et corrigé fourni


An Azure subscription contains two backup-related services:
- An Azure Backup vault named VaultA
- A Recovery Services vault named VaultB
The subscription includes the following deployed resources:
- VM01 - Virtual machine
- Disk01 - Disk
- WebApp01 - Azure App Service web application
- SQLDB01 - Azure SQL Database
You plan to configure backup protection for these resources.
Which of the listed resources can be backed up using VaultB (the Recovery Services vault)?
Réponses:
☐ WebApp01
☐ SQLDB01
☐ Disk01
**☑** VM01
Explication
`VM01` is the correct answer because a Recovery Services vault (like VaultB) is used to back up entire virtual machines (VMs) in Azure. Azure Backup supports backing up the operating system, data disks, and attached resources of the VM using a Recovery Services vault.
`Disk01`: While individual disks can be backed up as part of a VM backup, they are not directly backed up independently to a Recovery Services vault.
`WebApp01` (Azure App Service web app) and `SQLDB01` (Azure SQL Database) are not backed up using Azure Backup through a Recovery Services vault. They have their own specific backup mechanisms.
Reference(s):
- https://learn.microsoft.com/en-us/azure/backup/backup-overview
- https://learn.microsoft.com/en-us/azure/backup/backup-support-matrix
