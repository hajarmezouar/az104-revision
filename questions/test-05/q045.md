## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that includes a virtual network called VNet1.
The following users are assigned roles within the subscription:
- User1 is assigned the Owner role.
- User2 is assigned the Security Admin role.
- User3 is assigned the Network Contributor role.
You need to determine which user is permitted to carry out the following task:
“Create a new subnet within VNet1.”
Réponses:
☐ User1 only
☐ User3 only
**☑** User1 and User3 only
☐ User2 and User3 only
☐ User1, User2, and User3
Explication
`User1 and User3 only` is correct because the Owner role (User1) has full permissions, including managing resources and configurations like adding a subnet to VNet1. The Network Contributor role (User3) also has sufficient permissions to manage the network, which includes adding subnets.
`User2 and User3 only` is incorrect because although User3 (Network Contributor) has the required permissions, User2 with the Security Admin role does not have permissions to modify or add subnets in a virtual network.
`User1 only` is incorrect because User3 (Network Contributor) also has the required permissions to add a subnet.
`User1, User2, and User3` is incorrect because User2 (Security Admin) does not have permissions to manage network resources like subnets.
Reference(s):
