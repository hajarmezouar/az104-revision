## Énoncé et corrigé fourni


You have an Azure subscription that includes the following Microsoft Entra identities:
- UserA - A User
- SecGroup01 -  A Security group
- M365Group01 - A Microsoft 365 group
You plan to enable Self-Service Password Reset (SSPR) using the Azure portal.
For which of the listed identities can SSPR be enabled?
Réponses:
☐ UserA only
☐ SecGroup01 only
☐ UserA and SecGroup01 only
**☑** SecGroup01 and M365Group01 only
☐ UserA, SecGroup01, and M365Group01
Explication
`SecGroup01 and M365Group01 only` is correct because SSPR can be directly assigned only to a group of users or to ALL users but not to individual users. The setting is then applicable on all the users in that group. You can select individual users in a group if you do not want to enable the setting for all the users in that group.
Reference(s):
- https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr
