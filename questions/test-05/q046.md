## Énoncé et corrigé fourni


You have an Azure subscription named Subscription1 that includes a virtual network called VNet1.
The following users are assigned roles within the subscription:
- User1 is assigned the Owner role.
- User2 is assigned the Security Admin role.
- User3 is assigned the Network Contributor role.
You need to determine which user is permitted to carry out the following task:
“Assign a user the Reader role to VNet1”
Réponses:
**☑** User1 only
☐ User2 only
☐ User3 only
☐ User1 and User2 only
☐ User2 and User3 only
☐ User1, User2, and User3
Explication
`User1 only` is correct because the Owner role provides full access to manage the VNet and its access, including assigning roles such as the Reader role to VNet1. The Owner role allows complete control over the resource, including RBAC permissions.
`User2 only` is incorrect because the Security Admin role is focused on managing security-related policies and configurations but does not grant the ability to manage access to a VNet.
`User3 only` is incorrect because the Network Contributor role allows management of networking resources, such as creating or modifying VNets and subnets, but does not allow role assignments or access management for the VNet.
`User1 and User2 only` is incorrect because the Security Admin role does not include permissions to manage RBAC for the VNet.
`User2 and User3 only` is incorrect because neither the Security Admin nor the Network Contributor roles allow assigning roles to the VNet.
`User1, User2, and User3` is incorrect because only the Owner role (User1) has the necessary permissions to assign roles to VNet1.
