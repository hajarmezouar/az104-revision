## Énoncé et corrigé fourni


You provision an Azure virtual machine named VM1 that runs Windows Server 2019.
The current configuration of VM1 is shown in the below exhibit.
You are required to enable Desired State Configuration (DSC) for VM1.
What is the first action you should take?
Réponses:
☐ Assign a DNS name to VM1.
☐ Establish a connection to VM1.
**☑** Power on VM1.
☐ Capture a snapshot of VM1.
Explication
`Power on VM1` is correct because Desired State Configuration (DSC) requires the virtual machine to be in a running state to enable and configure it. In the exhibit, VM1 is currently stopped (deallocated), which means it is not operational. DSC operates by configuring the state of an actively running VM, and it cannot perform any operations on a stopped or deallocated VM.
`Assign a DNS name to VM1` is incorrect because assigning a DNS name is related to external name resolution and not a requirement for enabling DSC.
`Establish a connection to VM1` is incorrect because without starting the VM, you cannot establish a remote connection to perform DSC configuration.
`Capture a snapshot of VM1` is incorrect because snapshots are primarily used for backup or creating new VMs, not for enabling DSC.
Reference(s):
- https://learn.microsoft.com/en-us/azure/automation/automation-dsc-overview
- https://learn.microsoft.com/en-us/azure/virtual-machines/extensions/dsc-overview
