## Énoncé et corrigé fourni


An Azure subscription contains several resources distributed across two resource groups, as detailed in the table below. The resources include a container app and multiple Azure Key Vault instances deployed in different regions.
You intend to use an Azure Key Vault to securely supply a secret to containerApp01.
Which Azure Key Vault can be used to supply the secret to containerApp01?
Réponses:
☐ Vault1 only
☐ Vault1 and Vault2 only
☐ Vault1 and Vault3 only
**☑** Vault1, Vault2, or Vault3
Explication
`Vault1, Vault2, or Vault3` is correct because there are no Azure-imposed barriers that prevent containerApp01 from accessing Key Vaults located in different regions or resource groups. While it is generally recommended to use a Key Vault in the same region as the resource for performance and latency considerations, the question does not specify best practices, only whether the secret can be used. Therefore, containerApp01 can access all three Key Vaults—Vault1, Vault2, and Vault3—with appropriate permissions.
