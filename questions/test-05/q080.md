## Énoncé et corrigé fourni


Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You have three Azure subscriptions named Sub1, Sub2, and Sub3, all associated with a single Microsoft Entra tenant.
The tenant includes a user named User1, a security group named Group1, and a management group named MG1. User1 is a member of Group1.
Both Sub1 and Sub2 are assigned to MG1.
Sub1 contains a resource group named RG1, and RG1 hosts five Azure Functions.
The following role assignments are configured at the MG1 scope:
- Group1 is assigned the Reader role
- User1 is assigned the User Access Administrator role
Additionally:
- User1 is assigned the Virtual Machine Contributor role on Sub1 and Sub2
- User1 is assigned the Contributor role on RG1
True or False:
`"User1 can create a new resource group and deploy a virtual machine to the new group."`
Réponses:
☐ True
**☑** False
Explication
`False` is the correct answer here. Although User1 has the Virtual Machine Contributor role assigned at the Sub1 and Sub2 subscription levels, and the Contributor role for RG1, they do not have permissions to create a new resource group unless they are granted Owner or Contributor at the subscription level where they want to create that new resource group.
The Virtual Machine Contributor role allows managing virtual machines, but does not grant permissions to create resource groups. Additionally, the Contributor role assigned at RG1 only provides permissions within RG1, not at the subscription level needed to create new resource groups.
Therefore, User1 cannot create a new resource group, and thus, cannot deploy a VM to a new resource group.
