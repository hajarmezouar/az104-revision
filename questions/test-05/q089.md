## Énoncé et corrigé fourni


You manage an Azure subscription.
You need to create a custom Azure RBAC role with the following requirements:
- The assigned users must be able to perform all management operations for a virtual network.
- The permissions must adhere to the principle of least privilege, meaning no unnecessary access beyond what is required to manage the virtual network.
Which permissions should you specify in the role definition to meet these requirements?
Réponses:
**☑** "Microsoft.Network/virtualNetworks/*"
☐ "Microsoft.Network/virtualNetworks/delete"
☐ "Microsoft.Network/virtualNetworks/write"
Explication
`**"Microsoft.Network/virtualNetworks/*"` is the correct answer because it grants permission to perform all actions** on virtual networks, including read, write, delete, and other operations such as joining subnets or modifying settings. The asterisk `*` is a wildcard that encompasses all actions under the `Microsoft.Network/virtualNetworks` resource provider. This meets the requirement that users must be able to perform all actions on a virtual network.
`"Microsoft.Network/virtualNetworks/delete"` is incorrect because it grants only the ability to delete virtual networks and does not include permissions to read, write, or manage other aspects of the virtual network.
`"Microsoft.Network/virtualNetworks/write"` is incorrect because it only provides write access (e.g., create or update) but not read or delete access, and therefore does not fulfill the requirement of allowing all actions.
