## Énoncé et corrigé fourni


An Azure subscription contains several resources distributed across two resource groups, as detailed in the table below. The resources include a container app and multiple Azure Key Vault instances deployed in different regions.
You intend to use an Azure Key Vault to securely supply a secret to containerApp01.
What should you create so that containerApp01 can authenticate and retrieve the secret from the key vault?
Réponses:
**☑** A Managed identity
☐ A Private endpoint
☐ A Service principal
☐ A User account
Explication
`A Managed identity` is the correct answer. To securely provide a secret from an Azure Key Vault to containerApp01, you should create a managed identity for containerApp01. Managed identities allow Azure resources to securely access other Azure services (like Key Vault) without needing to manage credentials. Once the managed identity is created, it can be granted the necessary permissions to access the Key Vault and retrieve secrets.
`A Private endpoint` is incorrect because this is used for securing the network access to the Key Vault but does not handle authentication for accessing secrets.
`A Service principal` is incorrect because while service principals can be used to access resources, using a managed identity is a simpler and more secure method for Azure resources.
`A User account` is incorrect because user accounts are not typically used for resource-to-resource access in Azure.
