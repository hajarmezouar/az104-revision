## Énoncé et corrigé fourni


An Azure subscription contains a user named User1 along with the following resources:
- RG1, which is a resource group
- networkinterface1, which is a virtual network interface
- NSG1, which is a network security group
The network security group NSG1 is linked to networkinterface1.
User1 has been assigned the following roles related to NSG1:
- Contributor at the NSG1 resource scope
- Reader at the subscription scope (inherited)
- Storage Account Contributor at the resource group scope (inherited)
True of False:**
`"User1 can create an inbound security rule to filter inbound traffic to networkinterface1."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because User1 has the Contributor role explicitly assigned to NSG1 (Network Security Group). The Contributor role allows full management permissions over the NSG, including the ability to create, modify, and delete inbound and outbound security rules to control traffic flow.
Since NSG1 is associated with networkinterface1, any inbound security rules configured on NSG1 will apply to networkinterface1. Therefore, User1 has the required permissions to create an inbound security rule to filter inbound traffic to networkinterface1.
