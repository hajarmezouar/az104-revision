## Énoncé et corrigé fourni


You have an Azure subscription that includes the following resources, all deployed in the East US region:
- 10 virtual machines
- A key vault named Vault1
- A network security group named NSG1
All virtual machines are protected by using NSG1, which is configured to deny all outbound internet traffic.
You must allow the virtual machines to access Vault1. The solution must follow the principle of least privilege and require minimal ongoing administration.
Which destination should you specify in the outbound security rule for NSG1?
Réponses:
**☑** a service tag
☐ an application security group
☐ an IP address range
Explication
`a service tag` is the correct answer here. To allow the virtual machines to access Vault1 (which is an Azure Key Vault resource) while keeping outbound internet access blocked, you should configure the NSG outbound rule to allow traffic only to the AzureKeyVault service tag.
Service tags represent a group of IP address prefixes for specific Azure services and are automatically maintained by Microsoft, which minimizes administrative effort and adheres to the principle of least privilege. By using the `AzureKeyVault` service tag, you allow access only to Key Vault endpoints and nothing else on the internet, satisfying both security and operational requirements.
`an application security group` is incorrect because ASGs are used to group VMs and simplify NSG rules within a virtual network, not for allowing access to Azure services like Key Vault.
`an IP address range` is incorrect because allowing access via public IP ranges to Key Vault would require you to manage and update the ranges manually, which increases administrative overhead and violates the principle of least privilege.

- https://learn.microsoft.com/en-us/azure/key-vault/general/network-security
- https://learn.microsoft.com/en-us/azure/virtual-network/network-security-groups-overview
