## Énoncé et corrigé fourni


You have an Azure policy as shown in the following exhibit.
What is the effect of the policy?
Réponses:
☐ You can create Azure SQL servers in any resource group within Subscription 1.
☐ You are prevented from creating Azure SQL servers anywhere in Subscription 1.
**☑** You can create Azure SQL servers in ContosoRG1 only.
☐ You are prevented from creating Azure SQL Servers in ContosoRG1 only.
Explication
`You can create Azure SQL servers in ContosoRG1 only` is correct because the policy defines a Not allowed resource types rule for Microsoft.Sql/servers at the Subscription 1 scope. However, the ContosoRG1 resource group is explicitly excluded from this policy. This means that while creating Azure SQL servers is blocked across the entire subscription, ContosoRG1 is exempt from this restriction, allowing Azure SQL servers to be created there.
`You can create Azure SQL servers in any resource group within Subscription 1` is incorrect because the policy explicitly prevents creating Azure SQL servers at the Subscription 1 level, except for the excluded resource group ContosoRG1.
`You are prevented from creating Azure SQL servers anywhere in Subscription 1` is incorrect because the exclusion for ContosoRG1 allows creating Azure SQL servers specifically in that resource group, overriding the subscription-wide restriction.
`You are prevented from creating Azure SQL Servers in ContosoRG1 only` is incorrect because ContosoRG1 is explicitly excluded from the policy, making it the only place where creating Azure SQL servers is permitted.
