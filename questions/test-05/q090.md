## Énoncé et corrigé fourni


You manage an Azure subscription.
You need to create a custom Azure RBAC role with the following requirements:
- Users must be able to view the configuration settings of a storage account.
- The permissions must adhere to the principle of least privilege, meaning no unnecessary access beyond what is required to manage the virtual network.
Which permissions should you specify in the role definition to meet these requirements?
Réponses:
☐ "Microsoft.Storage/StorageAccounts/*"
**☑** "Microsoft.Storage/StorageAccounts/read"
☐ "Microsoft.Storage/StorageAccounts/blobServices/containers/blob/read"
Explication
`"Microsoft.Storage/storageAccounts/read"` is the correct answer because it grants users read-only access to the configuration and metadata of the storage account (such as properties, settings, keys, and networking configurations), without allowing any modifications or access to the actual data stored in blobs, queues, or files. This fully aligns with the principle of least privilege and the stated requirement to view configuration data only.
`**"Microsoft.Storage/storageAccounts/*"` is incorrect** because it grants all permissions on the storage account, including write and delete operations, which violates the principle of least privilege.
`"Microsoft.Storage/storageAccounts/blobServices/containers/blobs/read"` is incorrect because it only provides read access to blob data, not to the configuration settings of the storage account itself.
