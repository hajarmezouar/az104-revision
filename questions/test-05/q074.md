## Énoncé et corrigé fourni


You have an Azure subscription named Sub1 that contains two users named User1 and User2.
You must assign Azure role-based access control (RBAC) roles to both users so they can perform the following actions within Sub1:
- User1 must view the data in any storage account.
- User2 must assign users the Contributor role for storage accounts.
The assignment must follow the principle of least privilege.
Which RBAC role should you assign to User 2?
Réponses:
☐ Owner
☐ Contributor
☐ Reader and Data Access
☐ Storage Account Contributor
**☑** User Access Administrator
Explication
`User Access Administrator` is the correct role to assign to User2. This role allows a user to manage role assignments in Azure RBAC, including assigning others roles such as Contributor. It does not grant permissions to manage resources directly, making it ideal when the sole requirement is to delegate access control, as is the case here. Since User2 needs to assign users the Contributor role for storage accounts, User Access Administrator provides precisely the needed capability while following the principle of least privilege.
`Owner` is incorrect because although it allows full access to resources and access management, it overgrants permissions by allowing the user to create, delete, and manage any resource, which goes beyond just assigning RBAC roles. This violates the principle of least privilege.
`Contributor` is incorrect because this role allows managing Azure resources, but does not include permission to assign roles to other users. Therefore, it cannot fulfill the requirement to assign the Contributor role to others.
`Reader and Data Access` is incorrect because it only grants read access to Azure resources and data (e.g., in storage accounts), but does not provide any permissions related to role assignments or resource management.
`Storage Account Contributor` is incorrect because it grants permissions to manage storage accounts, including configuration, but it does not allow role assignments. It does not fulfill the need for User2 to assign RBAC roles to others.
