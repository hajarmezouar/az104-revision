## Énoncé et corrigé fourni


**Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You manage an Azure Storage account named datastore01.
A user named UserA must be granted permissions to view (list) the storage account access keys and regenerate those keys when necessary.
Proposed solution: `Assign the Storage Account Encryption Scope Contributor role to UserA at the scope of datastore01.`
Does this solution achieve the objective?
Réponses:
☐ Yes
**☑** No
Explication
`No` is correct because the Storage Account Encryption Scope Contributor role does not grant permissions to list or regenerate storage account keys. To enable a user to list and regenerate storage account keys, the user needs to have the Storage Account Key Operator Service Role or Storage Account Contributor role. These roles specifically allow the management of storage account keys, which is not covered by the Storage Account Encryption Scope Contributor role.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles
