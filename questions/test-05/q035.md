## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that is linked to the subscriptions shown in the following table.
You have the resource groups shown in the following table.
You assign roles to users as shown in the following table.
True or False:
`"User3 can assign User1 the Owner role for RG-Compute."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because User3 has the User Access Administrator role assigned at the Tenant Root Group scope. This role allows User3 to manage access and assign roles at any level within the tenant, including management groups, subscriptions, and resource groups. Since RG-Compute is within the tenant, User3 can assign roles such as the Owner role to User1 for RG-Compute.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#user-access-administrator
- https://learn.microsoft.com/en-us/azure/governance/management-groups
