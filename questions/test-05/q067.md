Based on the information presented, select the answer choice that completes the following statement correctly.
“To ensure that users can sign in to virtual machines that are assigned role1, modify the _____________ section.”
Réponses:
☐ actions
☐ roletype
☐ notActions
**☑** dataActions
☐ notDataActions
☐ assignableScopes
Explication
`dataActions` is the correct option because permissions like "Microsoft.Compute/virtualMachines/login/action" or "Microsoft.Compute/virtualMachines/loginAsAdmin/action" are categorized as data plane operations. These permissions determine access to the operational level of the virtual machine, such as signing in or interacting with its data, and should therefore be placed in the dataActions section.
`actions` is incorrect because this section controls management-level (control plane) operations, such as creating, updating, or deleting resources. Signing in to a virtual machine does not fall under this category.
`roletype` is incorrect because it specifies the type of role (e.g., built-in or custom) and does not influence permission assignments.
`notActions` is incorrect because it is used to exclude specific control plane operations from a role rather than granting access.
`notDataActions` is incorrect because it is used to exclude specific data plane operations, not to define permissions for logging into virtual machines.
`assignableScopes` is incorrect because this section only determines where the role can be assigned (e.g., subscription, resource group) and does not directly grant or restrict resource-level permissions.
