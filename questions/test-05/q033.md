## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that is linked to the subscriptions shown in the following table.
You have the resource groups shown in the following table.
You assign roles to users as shown in the following table.
True or False:
`"User1 can resize ProdVM01."`
Réponses:
**☑** True
☐ False
Explication
`True` is correct because User1 has the Contributor role assigned at the Corp-MG2 management group level, which includes SubC. Since SubC contains RG-Compute, and RG-Compute has ProdVM01, the Contributor role grants User1 full management rights over all resources within this scope. The Contributor role allows actions such as resizing virtual machines, making User1 capable of resizing ProdVM01.
