## Énoncé et corrigé fourni


An Azure subscription contains two backup-related services:
- An Azure Backup vault named VaultA
- A Recovery Services vault named VaultB
The subscription includes the following deployed resources:
- VM01 - Virtual machine
- Disk01 - Disk
- WebApp01 - Azure App Service web application
- SQLDB01 - Azure SQL Database
You plan to configure backup protection for these resources.
Which of the listed resources can be backed up using VaultA (the Azure Backup vault)?
Réponses:
☐ WebApp01
☐ SQLDB01
**☑** Disk01
☐ VM01
Explication
`Disk01` is correct because Azure managed disks are backed up using Azure Disk Backup, which requires an Azure Backup vault. This allows disks to be backed up independently without backing up the entire virtual machine.
`VM01` could also be backed up, but the backup would include the entire virtual machine, not just the disk. The question specifically focuses on backing up a resource like Disk1.
`WebApp01` (Azure App Service web app) and `SQLDB01` (Azure SQL Database) have different built-in backup features and are not backed up directly using Azure Backup.
Reference(s):
- https://learn.microsoft.com/en-us/azure/backup/backup-overview
https://learn.microsoft.com/en-us/azure/backup/backup-support-matrix
