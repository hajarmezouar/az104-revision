## Énoncé et corrigé fourni


**Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You manage an Azure Storage account named datastore01.
A user named UserA must be granted permissions to view (list) the storage account access keys and regenerate those keys when necessary.
Proposed solution: `You assign the Storage Account Key Operator Service Role to UserA.`
Does this solution achieve the objective?
Réponses:
**☑** Yes
☐ No
Explication
`Yes` is correct because the Storage Account Key Operator Service Role grants the necessary permissions to list and regenerate storage account keys without providing broader access to the storage account's data. This role is specifically designed for key management tasks, allowing the user to perform actions related to storage account keys.
Assigning this role to UserA will enable them to list and regenerate the keys for storage1 as required.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#storage-account-key-operator-service-role
- https://learn.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage?tabs=azure-portal
