## Énoncé et corrigé fourni


You have an Azure subscription named Sub1 that includes several blob containers, as shown in the following table.
Name           In storage account         Contains blob**
-------         -------------------         ---------------
cont1            storage1                            blob1
cont2           storage1                            blob2
cont1            storage2                           blob3
Each container resides in a specific storage account and contains one blob.
The subscription includes two users named User1 and User2. Both users are assigned the Reader role at the Sub1 subscription scope.
You have defined a condition named `Condition1` with the following logic:
- The condition evaluates to true when the requested action is not a blob read operation
OR
- The container name equals cont1
You have also defined a second condition named `Condition2` with the following logic:
- The condition evaluates to true when the requested action is not a blob write operation
OR
- The blob path matches a pattern that contains the value 2
You then assign roles to the users:
- User1 is assigned the Storage Blob Data Reader role at the Sub1 scope with Condition1 applied.
- User2 is assigned the Storage Blob Data Owner role at the storage1 account scope with Condition2 applied.
True or False:
“User1 can read blob3.”
Réponses:
**☑** True
☐ False
Explication
`True` is correct because, based on the conditions set in Condition1, User1 is restricted from reading any blob outside of the cont1 container. Although blob3 is in a different container (cont1 in storage2), the condition will allow User1 to access it. The condition in Condition1 only allows User1 to read blobs from the cont1 container in any storage account in that subscription.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/conditions-format
