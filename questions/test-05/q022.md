## Énoncé et corrigé fourni


**Note: This question is part of a set of related questions that use the same scenario. Each question proposes a different solution that may or may not satisfy the stated requirement.
You manage an Azure Storage account named datastore01.
A user named UserA must be granted permissions to view (list) the storage account access keys and regenerate those keys when necessary.
Proposed solution: `You assign the Reader and Data Access role to UserA.`
Does this solution achieve the objective?
Réponses:
☐ Yes
**☑** No
Explication
`No` is correct because the Reader and Data Access role allows a user to view storage account data and metadata but does not provide the necessary permissions to list or regenerate storage account keys. To achieve the goal of allowing UserA to list and regenerate storage account keys, the appropriate role would be the Storage Account Key Operator Service Role or a more privileged role like Contributor.
The Reader and Data Access role is insufficient for key management tasks.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#storage-account-key-operator-service-role
