## Énoncé et corrigé fourni


You manage an Azure Storage account called mediafiles01 that contains a collection of image blobs.
You plan to provision an additional storage account and configure object replication to copy the existing images from mediafiles01 to the new account.
After creating and configuring the destination storage account, you need to determine the appropriate object type that must be created within it to support object replication.
Which object type should you create in the destination storage account?
Réponses:
**☑** Container
☐ File share
☐ Table
☐ Queue
Explication
`Container` is the correct answer here. Azure Object Replication is a feature of Azure Blob Storage, and it works at the container level. To replicate blobs from one storage account to another, you must configure object replication policies between source and destination containers. This means that in the new storage account, you must create a container, as it's the fundamental object that holds blobs (such as images in this case). Without a container, the replication policy cannot be configured or function.
`File share` is incorrect because object replication does not support Azure Files. File shares are used in Azure Files, which is a completely separate service from Blob Storage, and is not part of object replication capabilities.
`Table` is incorrect because Azure Table storage is used for NoSQL structured data, and again, object replication only applies to block blobs in containers, not table data.
`Queue` is incorrect because Azure Queue Storage is designed for messaging between application components. It is not related to blob storage or object replication and cannot be used for replicating blob data.
