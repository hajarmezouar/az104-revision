## Énoncé et corrigé fourni


You are managing a tenant in Microsoft Entra.
You want to ensure that whenever a new Microsoft 365 group is created, the group name automatically follows this format:
<Department><Group name>
Which three actions must you carry out, in the correct order, from the Microsoft Entra admin center to achieve this configuration?
ACTIONS
- Set Add suffix to Attribute.
- Create a group naming policy.
- Set Add prefix to Attribute.
- Set Add suffix to String.
- Set Add prefix to String.
- Set Select type to Department.
- Customize the company branding.
Réponses:
☐ 2-6-3
**☑** 2-3-6
☐ 3-2-6
☐ 6-3-2
Explication
`2-3-6` is the correct sequence of actions.
`(Action 2) Create a group naming policy`: You need to create a group naming policy in the Microsoft Entra admin center to enforce a specific naming convention.
`(Action 3) Set Add prefix to Attribute`: In the group naming policy, set Add prefix to Attribute and choose Department as the attribute. This ensures that the department name is added as a prefix to the group name.
`(Action 6) Set Select type to Department`: Finally, ensure that you set Select type to Department to specify that the department attribute should be used when creating the group name.
Reference(s):
- https://learn.microsoft.com/en-us/entra/identity/users/groups-naming-policy
