## Énoncé et corrigé fourni


You manage an Azure App Service application called PortalApp.
The development team plans to publish updates to PortalApp using Web Deploy. They must be able to authenticate using their Microsoft Entra ID accounts when deploying the application.
The solution must follow the principle of least privilege and avoid granting excessive permissions.
Which action should you take?
Réponses:
☐ Grant the developers the Owner role on the web app.
☐ Set up application-level FTPS credentials.
☐ Configure user-specific FTPS credentials.
**☑** Assign the Website Contributor role to the developers.
Explication
`Assign the Website Contributor role to the developers` is the correct answer here. The Website Contributor role provides the necessary permissions to manage the web app, including deploying content, without giving the developers excessive privileges such as those granted by the Owner role. This ensures the solution follows the principle of least privilege.
`Grant the developers the Owner role on the web app` is incorrect because the Owner role gives full control over the resource, including the ability to delete or modify access permissions, which violates the principle of least privilege.
`Set up application-level FTPS credentials` is incorrect  because using app-level credentials does not involve using Microsoft Entra credentials and does not follow the principle of least privilege.
`Configure user-specific FTPS credentials` is incorrect  because this does not involve using Microsoft Entra credentials and provides too much access for just deploying content.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#website-contributor
