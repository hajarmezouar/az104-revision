## Énoncé et corrigé fourni


An Azure subscription includes a container group named Group1. The container group hosts two Azure container instances, as detailed in the following table.
Each container has defined CPU resource requests and limits.
You must ensure that each container cannot consume more CPU resources than it requests, and that cont2 does not negatively affect cont1.
What action should you take?
Réponses:
☐ Increase the CPU resource limit for cont1 to three CPUs.
☐ Increase the CPU resource limit of cont2 to six CPUs.
**☑** Remove the CPU resource limits configured on both containers.
☐ Reduce the CPU resource limit of cont2 to two CPUs.
Explication
`Remove the CPU resource limits configured on both containers` is the correct answer. Azure Container Instances allocates CPU resources to a container group based on the sum of the containers’ resource requests. If no resource limit is specified for a container, its maximum CPU usage is equal to its resource request. Therefore, after removing the limits, cont1 cannot use more than its requested 2 CPUs, and cont2 cannot use more than its requested 3 CPUs. This ensures that neither container can consume CPU resources beyond its request and that cont2 cannot use additional shared CPU resources at the expense of cont1.
`Reduce the CPU resource limit of cont2 to two CPUs` is incorrect because a container’s resource limit must be equal to or greater than its resource request. Since cont2 requests 3 CPUs, its limit cannot be reduced to 2 CPUs.
`Increase the CPU resource limit of cont2 to six CPUs` is incorrect because a container’s resource limit cannot exceed the total CPU resources allocated to the container group. The group is allocated 5 CPUs based on the combined requests of cont1 and cont2. Increasing cont2’s limit would also work against the requirement to prevent it from consuming more CPU than it requests.
`Increase the CPU resource limit for cont1 to three CPUs` is incorrect because this would allow cont1 to consume more CPU than its requested 2 CPUs. It would not ensure that each container is restricted to its resource request and could increase resource contention within the group.
