## Énoncé et corrigé fourni


You have two Azure subscriptions named Sub1 and Sub2. Sub1 is in a management group named MG1. Sub2 is in a management group named MG2.
The following resource groups exist in the subscriptions:
Name      Subscription
**------      --------------
RG1          Sub1
RG2         Sub2**
The following virtual machines are deployed:
Name      Resource group
**------      --------------
VM1          RG1
VM2         RG2
VM3         RG2**
You assign roles to users as shown in the following table.
Name      Role                                                Resource
**------      -----------------------------      ----------
User1      Virtual Machine Contributor      MG1**
User1      Virtual Machine User Login       Sub2
User2     Virtual Machine Contributor      MG2
User2     Virtual Machine User Login       Sub1
User2     Virtual Machine User Login       VM3
True of False:
`"User1 can sign in to VM1."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because User1 does not have the "Virtual Machine User Login" role assigned for VM1 or at the scope of Sub1. While User1 has the "Virtual Machine Contributor" role for management group MG1, which includes Sub1, the "Virtual Machine Contributor" role alone does not grant login permissions. The "Virtual Machine User Login" role is required to allow the user to sign in to the virtual machine, and this role is not assigned to User1 for VM1, Sub1, or RG1.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles
