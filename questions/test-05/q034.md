## Énoncé et corrigé fourni


You have a Microsoft Entra tenant that is linked to the subscriptions shown in the following table.
You have the resource groups shown in the following table.
You assign roles to users as shown in the following table.
True or False:
`"User2 can create a new storage account in RG-Storage."`
Réponses:
☐ True
**☑** False
Explication
`False` is correct because User2 has the Storage Account Contributor role assigned specifically to dataStore1, not to the entire resource group (RG-Storage). The Storage Account Contributor role allows User2 to manage the specific storage account (dataStore1) but does not provide the ability to create new storage accounts or manage other resources within RG-Storage.
Reference(s):
- https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles#storage-account-contributor
