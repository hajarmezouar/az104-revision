## Énoncé et corrigé fourni


You have defined a custom security attribute named Attr1 in your Microsoft Entra tenant.
The tenant includes a user account, a security group, and a service principal, as shown below.
- UserA - User
- SecGroup01 - Security group
- AppPrincipal01 - Service principal
You want to apply Attr1 to every identity type that supports custom security attributes.
To which identities can you assign Attr1?
Réponses:
☐ UserA only
☐ SecGroup01 only
☐ UserA and SecGroup01 only
**☑** UserA and AppPrincipal01 only
☐ UserA, SecGroup01, and AppPrincipal01
Explication
`UserA and AppPrincipal011 only` is correct because custom security attributes in Microsoft Entra ID can only be assigned to users and service principals (enterprise applications). Security groups are not supported objects for custom security attributes.

- https://learn.microsoft.com/en-us/entra/fundamentals/custom-security-attributes-overview
