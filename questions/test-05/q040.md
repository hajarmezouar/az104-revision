## Énoncé et corrigé fourni


You have an Azure environment that includes two virtual networks, VNet1 and VNet2, which are configured with virtual network peering.
A Network Virtual Appliance named NetVA1 is deployed in the environment.
You must ensure that all network traffic flowing from VNet1 to VNet2 is routed through NetVA1 so that it can be inspected before reaching its destination.
Which option should you implement to meet this requirement?
Réponses:
☐ Configure a local network gateway.
**☑** a route table that has custom routes
☐ Enable a service endpoint.
☐ Configure IP address reservations.
Explication
`A route table that has custom routes` is the correct answer here. To ensure that the traffic from VNet1 to VNet2 is inspected by NetVA1, you need to use a custom route in the route table. You can create a route that forces traffic from VNet1 to pass through the Network Virtual Appliance (NetVA1) for inspection before it reaches VNet2. This is achieved by setting the next hop in the custom route to the IP address of NetVA1.
`Configure a local network gateway` is incorrect because it is used for configuring connections between an Azure virtual network and an on-premises network, not for routing traffic between peered virtual networks.
`Enable a service endpoint` is incorrect because service endpoints provide secure access to Azure services but are not used for routing traffic through a Network Virtual Appliance.
`Configure IP address reservations` is incorrect because IP reservations are used to reserve public IP addresses, and they do not help with routing or traffic inspection between virtual networks.
