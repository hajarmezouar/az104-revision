## Énoncé et corrigé fourni


You have an Azure subscription that uses Azure Container Instances.
You are working on a computer where the Azure Command-Line Interface (CLI) and Docker are installed.
You build a container image named image1.
You need to create a new Azure container registry and then push image1 to that registry.
Which command should you run to add image1 to the registry?
Réponses:
☐ az acr create
☐ az container create
☐ docker pull
**☑** docker push
Explication
`docker push` is the correct answer here. This command is used to upload (push) your locally built Docker container image, such as image1, to a container registry. Once the Azure Container Registry has been created, you use the docker push command to push the image to the registry.
`az acr create` is incorrect because this command is used to create a new Azure Container Registry, not to upload an image.
`az container create` is incorrect because this command is used to create a container instance in Azure, not to push an image to a registry.
`docker pull` is incorrect because this command is used to download (pull) an image from a registry, not to upload (push) an image.
Reference(s):
- https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-docker-cli?tabs=azure-cli
- https://docs.docker.com/reference/cli/docker/image/push/
