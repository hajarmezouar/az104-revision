## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account named storage1.
You intend to apply role-based access control (RBAC) role assignments to storage1 by using conditional access expressions.
Which services within storage1 allow RBAC role assignments to be configured with conditions?
Réponses:
☐ containers only
☐ file shares only
☐ tables only
☐ queues only
**☑** containers and queues only
☐ files shares and tables only
Explication
`containers and queues only` is the correct answer. Azure supports Azure role assignment conditions for Blob Storage containers and Queue Storage. This means you can apply conditional access controls—such as limiting access by IP address, resource tags, or actions—when assigning RBAC roles to these services. This feature enhances fine-grained access control, enabling you to enforce least privilege principles more effectively.
`file shares only` is incorrect because Azure Files currently does not support role assignment conditions. You can assign roles, but not with conditional logic.
`tables only` is incorrect because Azure Table storage does not support RBAC role assignment conditions. Access is typically controlled through account-level keys or Shared Access Signatures (SAS), not conditional RBAC.
`queues only` is incorrect because while queue services support conditional role assignments, selecting this option alone ignores the fact that containers (Blob storage) are also supported.
`containers only` is incorrect for the same reason—it's incomplete. Both containers and queues support conditional role assignments, so the correct answer must include both.
`file shares and tables only` is incorrect because neither of those services supports conditional access using RBAC role assignments.
