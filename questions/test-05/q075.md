## Énoncé et corrigé fourni


You have an Azure subscription that includes a storage account hosting website content.
You need to ensure that users accessing the website are routed through the Microsoft point-of-presence (POP) that is geographically closest to them.
What configuration should you implement to meet this requirement?
Réponses:
☐ Load balancing
**☑** Routing preference
☐ Azure Firewall rules
☐ private endpoints
Explication
`Routing preference` is the correct answer. In Azure Storage, the routing preference setting allows you to specify how user traffic reaches your storage account; either through the Microsoft global network or over the public internet. To ensure that inbound user traffic uses the Microsoft point-of-presence (POP) closest to the user’s location, you should configure the routing preference to use Microsoft network routing (also called "Microsoft edge network"). This ensures that user traffic enters the Microsoft network at the POP closest to the user's location and is routed through Microsoft's backbone to the storage account, optimizing performance and reducing latency.
`Load balancing` is incorrect because while Azure Load Balancer distributes traffic across virtual machines and services, it does not apply to Azure Storage accounts or influence the routing behavior of traffic to them.
`Azure Firewall rules` is incorrect because Azure Firewall is used for controlling and monitoring traffic to/from Azure resources, based on configured rules. It is not responsible for routing user traffic through the Microsoft POPs or determining how traffic enters the Microsoft network.
`Private endpoints` is incorrect because they are used to provide private connectivity to Azure services over a virtual network. While they enhance security by avoiding public internet exposure, they do not control whether traffic is routed through the Microsoft edge network or influence the POP usage.
